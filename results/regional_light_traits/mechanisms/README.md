# 地域別の負候補と繁殖形質

対象は1992–2024年のGBIF調査日の記録率に基づく3,466種・32地域の探索。負候補696種（842種地域）は同じ地点・暦月で明るい年に記録率が低い群。数十年にわたり個体数が減った種という定義ではない。主要結果−1.902、花粉制限64種の副次解析とは対象・応答・期間が異なる。

## 地域構成をそろえた比較

matched_traits.csv は地域と観測10 km区画数の階級（3–5、6–10、11–25、26以上）ごとに同じ形質が既知の他の植物を参照群とした。負候補の種地域ごとに、その層の参照群の平均を一つ割り当て、両者の平均を算出。known は候補のうち形質判明種数、paired_species は実際に参照群もそろう種数。割合の分母は対照がそろった種地域。loo_min/max は地域を一つずつ除いた差の範囲で、信頼区間ではない。同一種の複数地域への寄与がある。family_annual_matched.csv は科と一年草区分も一致させた部分集合で同じ計算を行った。生活型に annual の記載がある種を一年草区分とし、複数の生活型の記載も含む。

直接形質台帳の中・高品質、解決済み、単一状態のみを採用。白花かつ筒・高坏・漏斗形を形態候補とし、深い花筒は別に集計した。自律自殖可能、自殖優勢・義務的自殖、自家不和合（SC/SI判定のみ）は別の形質。遺伝的自殖率はBioGeo matingの範囲内の多座他殖率を1から引き、種内中央値。GloPLは花粉添加実験の効果量の種内中央値で、調査地点の光曝露で測った値ではない。両データの種名はWCVPで一意に解決できたものを採用。蛾の訪花はGloBI v0.11の非iNaturalist訪花記録（昆虫種まで同定）の文書化率。蛾の花粉運搬は既存レビューと4種の更新を反映したレビュー内の確認率。未調査は欠測。直接形質の元台帳は再配布せず集計を収録した。

## 年次解析と予測

held_out_regions.csv は1地域ずつ留保し残りで学習したランダムフォレスト（100本、葉の最小標本20）。種地域ごとの負候補ラベルを予測。区画数と島区分のみのモデルと、これに全11形質指標を加えたモデルを同じ分割で比較した。形質欠測は独自値で表現したので、調査歴による予測も含みうる。Brier scoreは小さいほど予測がよい。留保地域に既知種が含まれうる。予測対象は新地域でのラベルで、新種の応答や年間変化量ではない。

## 捕食

candidate_plant_chain_name_matches.csv は、旧解析の捕食者–成虫蛾–植物台帳（植物56種）と今回の負候補を植物学名で照合したもの。表の地域は植物の負応答の観測地域であり、そこで捕食が観測されたことを表さない。島の候補ではナガコガネグモとホオグロヤモリに至る既知の連鎖と7植物名が重なる。旧78地域5年の実測率監査は adult_moth_predation/README.md を、捕食者自身の同一植物への送粉候補は dual_role_80/summary.json を参照。新しい32地域すべての捕食者群集調査は未実施。

再計算は scripts/analysis/alan_regional_reproduction.py に元データを置いた work ディレクトリを渡す。形質差は探索的な比較であり、系統・土地利用・観察者効果をすべて取り除いた係数ではない。
