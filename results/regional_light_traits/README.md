# 夜間光の経年変化と植物の記録率

1992–2024年の全球GBIF抽出から、植物調査日のうち各種が記録された割合を調べた。対象種が一度記録された地点・暦月では、他の植物の調査が続いた年の未検出も分母に含む。調査のない年は欠測。記録率には観察者による発見・記録の変化も入る。

1. `alan_regional_screen.py` は20年以上の調査履歴がある地点について、同じ情報源・座標・暦月で夜間光がその平均を上回った年とそれ以外の年の記録率を比べる。光の観測幅は1 DN以上。10 km区画を等重みにして、島単位・本土5度区画単位で要約した。3区画以上、全区画の過半数と平均差が同じ方向、同率を除いた区画符号のBeta(2,2)事前分布による方向確率が0.9以上を探索候補とした。8,604種に年比較があり、3区画以上は3,466種・32地域。負候補696種・842種地域。
2. `alan_regional_traits.py` はWCVPの生活型と研究の形質台帳を照合する。参照群は同じ地域・区画数階級にある、その符号の候補以外の植物。欠測は形質ごとに除く。
3. `alan_regional_decline.py` は既存の年次推定表 trajectories を用いる。同一地点・暦月で5年以上の観測、最初と最後が20年以上離れた系列で、光と記録率の年に対する傾きをそれぞれ推定。月・情報源を平均して座標ごとに集約。同じ地域・100 km区画内で増光地点と横ばい・減光地点がある場合に両群を比較した。比較可能な3区画以上がある負候補は83種地域。うち11種地域は、増光側の記録率傾きと群間差がともに負で、過半数の区画でも両条件を満たした。残る759種地域は比較区画不足。短期的な明暗との関連と長期の時間傾向は異なる問いである。

`priority_species_regions.csv` の bright_rate と ref_rate は増光地点と対照地点での記録率変化（ポイント／10年）。両群とも区画を等重みにする。bright_n と ref_n は座標数、joint_blocks / paired_blocks は両条件を満たした区画数／比較区画数。I_15 はグレートブリテン島、M_36_28 は東経0–5度・北緯50–55度の本土。正負の全判定は all_regions.csv.gz、負候補の比較可否を含む表は negative_temporal_check.csv。

この順位付けは同じデータを使った探索で、多重比較補正後の有意種という判定はしていない。土地利用・気候・記録慣行の経年変化が残りうる。二つの地域で異なる種が選ばれており、島と本土の応答差の推定には使えない。従来の主要結果と花粉制限の副次結果は別の解析である。
