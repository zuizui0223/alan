# 同一調査で比較した自律自殖能と夜間光の年次応答

母集団は地域の負候補・正候補・その他を含む既存の3,466種・32地域。元の探索で当該種に3区画以上の情報があった地域に限定。直接形質台帳の自律自殖能が中または高品質、解決済み、単一状態の autonomous / absent に確定したものだけを使う。補助を要する型、混在型、未判定は含めない。自家不和合性や野外集団の自殖率とは別の指標である。

同じ資料・座標・暦月で各群から少なくとも1種がいずれかの年に記録され、年次光観測に変動があることを要求。種リストはその地点・月の観測期間全体で固定。各調査月年の群記録率は種別記録日数の和／（群の種数×植物調査日数）。調査があった未検出日はゼロ、調査のない日は欠測。各地点は20年以上の調査履歴を持つが、各暦月で20年分の観測があることは要求していない。地理的な地域数に実質的な標本数の偏りがある。

annual_contrasts.csv は情報源別地点×暦月、および島・本土別の年固定効果と調査日の平均記録種数の対数で調整。各地点・暦月・年を等重みとした線形記録率モデル。DN 10単位増加あたりの記録率変化（ポイント）。同一100 km区画の観測間依存を許すスコアから95%区間を算出。島−本土の差でも両側にまたがる空間区画を統合した。

hierarchical_species.csv は同じ月年ごとの「自律自殖可能群−不能群」記録率差に対する群平均応答を求める。種ごとに正規分布する光の傾き偏差を認め、地点・月の固定種リスト内の種数の逆数（不能群は負号）でランダム傾きを群記録率差に反映。種の傾き分散は島と本土で別々に制限最尤法で推定した。年および調査種数を調整し、地点・暦月内の光の偏差を使用。これは群差の階層モデルで、種ごとの潜在占有や検出率の分離は行わない。区間は推定した分散成分を固定した近似的な空間クラスタ区間。分散の大きさを個々の種の感受性とは解釈できない。固定効果推定値は別形式の混合モデル正規方程式でも照合した。

regional.csv は全対象地域の支持数と3空間区画以上の地域内推定。hierarchical_regions.csv はこれらの推定で標準誤差が推定可能な地域のランダム効果統合。島では3地域しか残らない。島の調査月年17,099のうち14,714はグレートブリテン島。都市化・土地利用の変化、発見しやすさ、実際の自殖率の経年変化は分離できない。

再計算は scripts/analysis/alan_annual_autonomy.py に入力を含む work ディレクトリを渡す。主要結果−1.902と花粉制限の64種による副次結果は別の応答・標本に基づく。
