# 全球抽出から島・本土の長期応答を比較できるまで

全球GBIFスナップショット全10,346分割を対象にした。元の抽出は世界の既知種目録を分母にしていない。1992–2024年、位置・日付・分類・記録種別などの条件を満たした維管束植物148,786種キーを全件保持。原資料、品質条件、地域偏在は ../global_gbif_annual/README.md に記載。all_species.csv.gz は148,786行。傾き欠測は情報不足。

地域別明暗比較では、比較可能な年をもつ8,604種のうち、同一地域で10 km区画3個以上が3,466種。島と本土の両側でこの条件を満たす1,370種は種名が共通する集団。2地点の観測時期、光、気候が一致しているという意味ではない。

長期速度解析は別経路。地点×暦月に少なくとも5調査年、最初と最後で20年以上を要求する。5,572種に少なくとも1座標の系列。調査が継続した未検出を含み、月内で記録日割合・光・調査種数の年に対する傾きを求めて座標へ集約する。全球の取得範囲を統合した既存の427種の推定を再利用。同じ関数を島と本土で個別に適用し、20座標以上・調整後の光変動をもつ100 km区画10個以上の支持を各側に要求。初期光と調査種数の変化、空間区画固定効果を調整。両側93種で島−本土の差を求めた。共通の100 km区画のスコアを差し引いたクラスタ標準誤差、両側の情報区画数の小さい側−1の自由度、93検定でBH補正を用いた。

傾きは増光速度が10 DN／10年大きい地点での植物記録率の変化速度の差（ポイント／10年）。負の関連でも増光地点で記録率そのものが下がったとは限らない。pooled slope が負の246種のうち186種で増光地点の平均記録率傾きも負。地域ごとの光範囲や気候帯・土地利用は厳密には一致させていない。点推定の符号集計は探索用。同じデータで選んだ種の方向割合を独立な再現率とは解釈しない。今回の検定で有意差が出なかったことも島と本土の同等性を意味しない。

paired.csv は全93種の推定値と区間。paired.png は横軸が本土、縦軸が島、破線が等値線、青緑は全地域統合の傾きが負の種。paired_moth_evidence.csv は既存台帳に4種の証拠更新を反映したもの。蛾による花粉運搬の報告は地域を問わない種レベルの情報で、島における送粉者交代の観測ではない。この93種で既存台帳の夜間遮断の値があるのは0種。

再実行は scripts/analysis/alan_long_term_land_contrasts.py に annual.duckdb の親ディレクトリと results ディレクトリを渡す。
