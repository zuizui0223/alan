# 427種・93種の長期傾きの形質メタ回帰

対象は全域の長期増光応答を推定できた427種、および両側を個別推定できた93種。各種の島・本土平均と差を区別する。島・本土平均が負でも両側が負とは限らないため、両側の符号が一致する群はprofile_composition.csvに別集計した。種別の推定に先立つ負の種の選択は行わない。profileは推定値の符号による記述分類であり、真の群が存在することを示すものではない。

平均および回帰は種別分散の逆数重み。各種の100 km空間区画別のクラスタスコアを、全種で共通の区画索引で加重合計して標準誤差を得た。95% t区間はその比較に含まれる種の最小有効区画自由度を用いる。対象はこれらの種における加重記述平均と回帰。種の系統や対象外の種に対するランダム種効果は推定しない。種等重みの平均、1科ずつ外した推定値の範囲も付した。

形質別に判明分母を使用。蛾は既存のレビュー対象内で花粉運搬が確認済みか未確認かの比較。白色と筒形・高坏形・漏斗形は両方が判明した組合せ。自律自殖能は可能対不能、SIはSI対SC。一年草は生活型の記述による。花粉制限は既存台帳にある花粉添加効果量。実測していない依存度や局所での形質変化には置き換えない。単一形質と3応答の推定可能な16比較にBH補正。3形質同時モデルは別途探索用（欠測と組合せの偏りあり）。joint_trait_support.csv は完全データの組合せを示す。不確実性は共有調査区画に関するもので種集合自体は固定した。
