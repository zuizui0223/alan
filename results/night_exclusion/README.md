# 夜間だけ訪花を遮断した実験と、夜間光に対する植物種の応答

2026-11-11。共通544種のうち、終日開放区に対する昼間のみ開放区の繁殖成績を数値化できたのは12種。指数の計算に使った原著は17報。主要結果は −1.902、64種の花粉制限は副次結果として扱い、この比較は探索的な機構の検討とした。

## 文献の範囲

[Kendall & Nicholsonの公開抽出表](https://doi.org/10.6084/m9.figshare.26004538.v1)には原著別・処理区別の値があり、[解析用の版](https://github.com/liamkendall/bumble-bat/tree/1945b7c114ad87000608ce6018d0280001c04ef1)の全植物名をWCVPと544種のリストに照合した。北米の白花マンテマの研究に用いられた旧名 Silene alba を S. latifolia に含めた。日中訪花、夜間の袋掛け、同じ実験の終日開放対照、結実・種子生産の数値を確認対象とした。時刻別の花粉付着、訪花だけの観察、終日閉鎖だけを対照とする研究はこの比較に使っていない。検索は総説の引用文献、作物・野生種の補足検索を含むが、全言語・異名の系統的レビューではない。各種の不明をゼロに置換していない。[544種の照合](coverage_544.csv)

公開表から9種、追加の原著から3種を採用した。アカクローバーの4群は原著では撮影された訪花者による分類だった。ハナダイコンの野外開放群は昼間のみ開放した実験配列と栽植条件が異なる。ニュージーランドのブルーベリー実験で遮断処理を行ったのは V. virgatum の品種であり、同論文で他の測定に使われた共通種 V. corymbosum に結果を割り当てていない。[アカクローバー](https://doi.org/10.1098/rsbl.2022.0187)・[ハナダイコン](https://doi.org/10.1111/j.1365-2435.2008.01517.x)・[ブルーベリー](https://doi.org/10.1007/s11829-025-10135-3)

## 算出法

各比較の相対低下率は 1 − 昼間のみ開放区の値／終日開放区の値。負の値も保持した。既刊研究の処理値は公開抽出表を使用し、論文・図表・転記法を記録した。基本的に結実率を用い、該当する値がなければ種子生産を用いた。花数を分母にできない株あたり果実数と総種子数が併記された旧研究では後者を優先した。地点・年・品種・性型などが一致する区を対にし、同一研究内で等重み平均、次いで種内で研究を等重み平均した。原著のデザインや数値の単位を確かめられなかった指標は種別指数から外した。全測定対と採否は表の used 列で追跡できる。[処理区別の値と原著](experiments.csv)

追加3報では、ラズベリーは元データの結実花数／対象花数、ソバは図5の種子形成率の中央値を軸から読んだ近似値、パパヤは査読前原稿の表S1で著者が報告した開放／昼間の調整済み結実数比1.58を用いた。パパヤでは処理あたりの標識花数をそろえる設計だが、処理を実施した地点は年で異なる。これらの測定は、有効な送粉者の種別や晴天・暗夜下での送粉依存度を一律に示すものではない。[ラズベリー原著](https://doi.org/10.1111/jen.70019)・[公開データ](https://doi.org/10.6084/m9.figshare.29930195.v1)・[ソバの図5](https://doi.org/10.1007/s11829-024-10117-x)・[パパヤ原稿](https://doi.org/10.64898/2026.07.17.739175)

## 78地域での検証

元の5年・10,698地点年の同じ行キー、年×地域の固定効果、島・本土のバランス重み、環境・観察努力の共変量を用いた。種別応答は各地点年の観察種構成に占める当該種の割合（百分率）。各種の夜間光の島−本土交互作用を相対低下率に等種重みで回帰した。地域内で共有する誤差を維持するため、同じ回帰を種の重みの線形対比として当てはめて78地域のクラスタ区間を算出した。種別係数からの回帰と、地域年ダミーを明示した別実装でも係数が一致した。

低下率が10ポイント大きいと島−本土の傾き差が +0.00233 ポイント変化した（95%区間 −0.00224～+0.00690、名目 p=0.314）。予測した負の関連は確認できなかった。12種のいずれかが撮影されたのは島22・本土104地点年、24地域で、そのいずれかを両側で記録した地域は6。区間は今回の12種と文献指数を固定した地域間の不確実性を表す。実験間のばらつき、図からの読み取り誤差、未知の532種を含む種間の一般化はこの区間に含まない。[種別の係数・支持地点数](species.csv)・[モデル出力](contrast.json)
