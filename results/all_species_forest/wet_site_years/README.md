# 複数資料を夜間光の地点年に戻したときの観察範囲

再実行は解析環境で python scripts/analysis/alan_wet_network.py --site-years。入力は wet_network の固定版3資料・植物種名・訪花者リスト、および wet_water の調査履歴と有効水面年。両側に湿潤候補と比較種を含むという元の調査単位の条件を再現した。島・本土の区分と開水面状態は元の座標集計を使用した。

coverage は同じ植物種の訪花を、元の調査があった座標の半径内・同じ暦年で数えたもの。両群の地点年は重複しうる。confirmed_wet はEuPPollNet・DoPIで訪花場所が河岸・湿地・塩性湿地と明記されたもの。GloBIの訪花を生息場所不明のまま含むのは any_habitat のみ。半径は両観察から共通の植物調査座標への距離として適用した。年をまたぐ区間と0°,0°を除き、完全な暦日が分からない年単位の記録も含めた。

nearby_diet は両群の既知の訪花者に対する近隣の食性記録で、地域の植物への訪花は追加条件ではない。shared_site_years_any_prey は被食種の一致を要求する前の同一地点年。chain_site_years は被食種と訪花昆虫が一致した地点年。照明値や観察努力を備えた捕食実験の登録簿ではない。candidate_visit_support の複数年は植物調査地点の周囲での年の反復で、訪花調査の方法・時間の一致は未確認。
