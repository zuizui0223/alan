# 湿潤な両群に共通する成虫の訪花者と捕食者、水面距離と記録率

主結果は増光地点で記録率が低下した候補に湿潤種が多いこと。以下は候補58種と比較305種を出発点にした機構の探索である。

## 両群に現れる具体的な組合せ

[GloBIの出典別訪花者](../wet_partner_composition/README.md)に捕食者と被食成虫の種名を復元し、候補側と比較側で同じ訪花者種・同じ捕食者種・同じ訪花出典と食性出典の組を要求した。両群に共通する組合せは272通り。そのうち239通りでは、Pladias上の適地が一つも重ならない候補植物と比較植物にも接続した。種名による接続で、各調査地点に両方の相互作用が存在する頻度は不明。食性記録は摂食を含み、生きた成虫への攻撃の直接観察に限定していない。[組合せ別の比較](shared_adult_chains.csv)・[植物・相手・出典の全記録](plant_chain_records.csv.gz)

ホソヒラタアブ Episyrphus balteatus とカニグモ科 Misumena vatia の組合せは候補11種・比較23種、適地が重ならない候補と比較の16種対に現れた。例は Succisa pratensis（候補）と Allium schoenoprasum（比較）。両植物への訪花はEuPPollNet、クモの食性はiNaturalistに収録された。8組ある共通出典の組合せはすべて少なくとも一方にiNaturalistを含み、8つの独立した捕食研究とは数えられない。セイヨウミツバチ Apis mellifera とツマアカスズメバチ Vespa velutina は候補10種・比較34種、適地が重ならない48種対。こちらは両段階からiNaturalistを除いても共通出典の組合せが残った。全272通りのうち、この条件を満たすのは2通り。これらは共通の調査候補で、比較群に比べた増光感受性の原因とは判定していない。

以前に Misumena vatia につながった植物対の割合（候補同士51/63、混合246/303、比較同士222/283）は、左右の植物で異なる訪花者も許した。今回は訪花者の種も一致させた。[前回の分母と集計](../wet_partner_composition/tests.csv)

## 水面近傍で群間差が広がるか

1999–2023年の[同一地点・同一年の群間比較](https://github.com/zuizui0223/alan/tree/6a9a484/results/all_species_forest/wet_water)を使用した。20年以上にわたり5年以上の植物調査が継続し、両群を期間中に調査した地点を採用。地点別に対象期間中に一度以上記録された種を固定し、調査継続中の未記録年を含む年次記録率から傾きを計算した。起点の1999年に[GLAD Landsat](https://storage.googleapis.com/earthenginepartners-hansen/waterC2/download.html)で水検出率50%以上の最近接画素中心までの距離を求め、1 kmで打ち切った。半径1 kmの95%以上が有効画素であることを要求した。これは植物個体から水際までの実測距離ではなく、細い水路、一時的な湛水、湿った土壌を捉えきれない。

1,707地点のうち境界1地点を除く1,706地点（候補58種と比較301種）で距離を算出した。100 m以内148地点、100–500 mが417地点、500 m–1 kmが306地点、1 km以内に該当水面を検出しなかったのが835地点。距離効果のモデルでは区画内に夜間光変化のばらつきがある1,674地点・53区画を使用した。増光速度、近さ（1−距離km）、両者の積、気候・市街化・調査努力・開始年・調査季節・島本土・各群の種数などを入れ、100 km区画内で比較し、区画クラスタで名目95%区間を算出した。水文調整には地点付近の水面割合・水検出頻度の初期値と経年変化を加えた。[距離の収録範囲](distance_support.csv)・[種別地点数](species_coverage.csv)

増光速度10 DN/10年あたりの、候補−比較の記録率傾き差（ポイント/10年）を評価した。調整後、1 km端で−1.97［−3.63, −0.32］、水面直近のモデル端で＋1.92［−0.85, ＋4.69］。近傍−遠方の差は調整前＋3.78［＋0.48, ＋7.08］、調整後＋3.90［＋0.68, ＋7.11］。増光地点だけでは316地点・33区画、対応する差は＋1.89［−9.10, ＋12.88］。水辺に近いほど候補が相対的に強く減少するという予測を支持しなかった。主解析で選抜した候補を一部同じ年代の記録で比較しているため、これらは独立した減少の再現ではない。照度・水面反射は現地で測定していない。[群別推定と区間](effects.csv)

英国Environment Agencyの観測井から1 km以内で、植物調査と地下水位が同年に5年以上かつ20年以上の期間でそろうのは15地点・11井戸。増光地点は1地点のみ。区画内で比較可能な11地点は2区画で増光地点がなく、水位を加えた距離効果は推定できなかった。湖沼・河川の水面標高および植物位置での湛水期間は未測定。[年別地下水位](groundwater_years.csv.gz)・[照合年数](well_support.csv)

再計算は scripts/analysis の alan_wet_shared_chains.py、alan_wet_shore.py、alan_seven_wells.py --wet-shore、alan_wet_shore_fit.py を使用する。
