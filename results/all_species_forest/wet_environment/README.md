# 湿潤種が減少候補に多い理由をどこまで絞れるか

2026年11月17日。種の湿潤性は、その種がふつうどの土壌水分環境に生えるかを表す。増光地点の湿度、水位、岸からの距離は別の量である。以下は固定済みの主要結果を説明するための副次検証である。

## 環境をそろえた種間比較

元の3,901評価種・283候補をそのまま使用した。既知の湿潤性と地域・島割合・観測規模の共通支持がある候補158種、参照1,419種、49層、12の主要調査地域で比較。種ごとに元の全調査座標における増光・気温・降水の経年傾き、市街地変化の中央値を計算した。層内で参照種の重みの総和を候補数に合わせ、層固定効果の重み付き線形回帰を行った。応答は種の湿潤性指標。いずれの比較も単位は植物種である。95%区間は主要調査地域を一つずつ除くジャックナイフと自由度11のt近似。各種が複数地域にまたがること、系統的類似、候補の事後選択の不確実性はこの区間に含まない。[集計](environment.csv)・[調査地点入力の作成法](https://github.com/zuizui0223/alan/blob/b780370/scripts/analysis/alan_all_species_forest.py)

- 同じ種集合で元の差＋0.592を再現し、4変数の同時調整後は＋0.534（近似95%区間＋0.158～＋0.910）。候補には比較的湿った土壌に生える種が偏る。水面に接する絶対的水生種に限られず、元の指標分布で候補と参照の差が大きいのは7超～9以下（22.8%対12.8%）。9超は12.7%対9.4%。[元の指標分布](../decline_traits/moisture_distribution.csv)
- 12地域のうち7地域で正、5地域で負。候補158種のうち94種が主要調査地域を上位2区画に持つ。この2区画を同時に除くと残り64候補で重み付き差＋0.335。全球一様の反応とは判定できない。[地域別結果](regions.csv)
- 候補×各環境の交互作用を同時に推定。種の調査地点群における環境の四分位範囲あたり、候補・参照の湿潤性差は増光＋0.094、気温変化＋0.354、降水変化−0.446、市街地変化＋0.116。気温の名目区間＋0.055～＋0.652、4比較Holm補正 p=0.098。その他3変数の区間は0を含む。温暖化との重なりは再検証候補。ある地点が明るくなると植物がどう応答するかを直接推定するモデルではない。[尺度](exposure_scale.csv)
- 土壌水分、排水、刈取り、富栄養化、湿地の消失はこの4変数で調整しきれない。元の1,707地点で初期開水面の広さが増光との負の関連を強める結果も得られていない。[開水面による効果修飾](https://github.com/zuizui0223/alan/blob/b780370/results/all_species_forest/wet_water/open_water_light_interaction.csv)

## 公開照明実験の再解析

スイスの6草地ペア（夜間照明区・暗区）で日中に同時観察したデータを使用。著者の簡約混合モデルに従い、昆虫群、植物量の対数、植物種×照明、草地ペア×調査回のランダム切片を使用した。植物量を調整した昆虫群別 log(1＋昼の訪花数) の照明差を再推定。原資料の21分類群をすべて結果表に残した。このうち二名法の完全一致で評価済みなのは10種、湿潤指標も分かるのは4種、減少候補は1種。属・集合種を特定種に割り当てていない。[原論文](https://doi.org/10.1038/s41467-021-22011-8)・[原データ](https://doi.org/10.5281/zenodo.4540407)・[全分類群の再推定](giavi_diurnal.csv)

*Cirsium oleraceum*（指標7.2）は6ペアすべてで明暗両側に出現し、昼の訪花の照明差は−0.261（モデルの名目Wald 95%区間 −0.442～−0.080）。訪花数そのものの減少率に換算しない。反復単位を厳しく見た別集計では、両側で調査された24回について昆虫群を合計し、草地ペアごとに log(1＋訪花総数) の差を平均した。6ペア中5ペアで負、6ペアの符号反転による両側 p=0.156（64通り、ペア内交換可能性を仮定）。こちらは植物量補正を含まない。既報の同種の結実低下と整合するが、昼の送粉補償量・捕食の媒介効果は推定していない。[ペア別](cirsium_meadow_pairs.csv)・[結実実験](https://doi.org/10.1038/nature23288)

同じ湿潤種でも、比較群の *Filipendula ulmaria*（7.9）の昼間訪花差は−0.324（−0.690～＋0.041）。この実験だけで湿潤種と乾性種の差や、減少候補固有の送粉機構を一般化できない。

## 一次研究が支持する経路と反例

| 経路 | 実際に測定されたもの | 今回の主結果との接続 |
|---|---|---|
| 湿地水文と土地利用 | 英国の水路・草地で湿潤指標は水深、平均地下水位とその変動に対応。全球では農地転換・排水に伴う湿地消失が再構成されている。[水位の実測](https://doi.org/10.1006/jema.1993.1045)・[湿地消失](https://doi.org/10.1038/s41586-022-05572-6) | 土壌が湿る期間の短縮は、岸や開水面が残る地点でも起こりうる。照明と並行した生育地変化は有力な代替説明。 |
| 水面付近の光と偏光 | 都市湿地で雲が水中の夜間照度を変化させた。橋灯に誘引されたカゲロウは河面の偏光の手掛かりから逸脱。トンボ・カゲロウ・アブでは反射面への誘引に必要な偏光度を野外測定。[湿地の分光測定](https://pubmed.ncbi.nlm.nih.gov/29117235/)・[橋の実験](https://doi.org/10.1371/journal.pone.0121194)・[分類群別の閾値](https://doi.org/10.1016/j.jinsphys.2009.08.013) | 水面の広さ、植物の葉に届く光量、昆虫が向きを決める偏光は異なる。衛星の上向き放射から各経路の寄与は分離できない。 |
| 生産者・フェノロジー | 流水の付着藻類でバイオマス減少。一方、浮遊性のウキクサ *Landoltia punctata* は照明下で葉数・葉面積が増えた（処理は各1箱）。海草では夜の光勾配に沿う時計遺伝子と成長の差。草地では種によって被度・開花時期の変化が異なる。[付着藻類](https://doi.org/10.1002/lno.10607)・[ウキクサ](https://pubmed.ncbi.nlm.nih.gov/37927782/)・[海草](https://doi.org/10.1038/s41598-023-37261-3)・[草地](https://doi.org/10.1111/1365-2664.12927) | 湿った場所で植物への直接作用は起こりうるが、成長の方向は一定でない。海草・藻類を陸上の湿潤植物と一括しない。 |
| 食害と競争 | 5年の草地実験では多数種のバイオマスは変わらず、*Lotus pedunculatus* は白色LEDで低下した。この種は本解析では比較群（7.9）。水生植物の実験では植食性巻貝の有無が関わり、非食害区では照明が外来 *Myriophyllum aquaticum* の成長を促した。[草地実験](https://pubmed.ncbi.nlm.nih.gov/35949540/)・[水草・巻貝](https://doi.org/10.1002/ecy.70458) | 在来湿潤種は自身の光応答が小さくても、競争相手や食害の変化で相対的に減りうる。減少候補への採否と個体の実験応答も一対一ではない。 |
| 羽化・再分布 | 水路の照明実験で羽化・岸への飛来・捕食者群集が変化。別報の水生双翅類では羽化減少と成虫の誘引が共存する。地上付近の蛾の減少と灯具の高さでの活動増加も同時に観察されている。[水路の調査](https://doi.org/10.3389/fenvs.2017.00061)・[双翅類](https://doi.org/10.1007/s00027-025-01161-7)・[蛾](https://doi.org/10.1111/gcb.13371) | 岸の灯具に集まる成虫数と、花に届く成虫数の方向は異なりうる。同じ水路施設に由来する研究を独立な反復に数えない。 |
| 送粉・種子食 | スイスの照明実験で夜の訪花と焦点種の結実が低下。一方 *Silene latifolia* では光色間で受精花の割合に差がなく、緑光で受精胚珠割合が低下し、白・緑光では果実への種子食者の侵入が増えた。照明時間や配置によって受粉成功に正の応答を示した実験もある。[夜の訪花と結実](https://doi.org/10.1038/nature23288)・[種子食者兼送粉者](https://pubmed.ncbi.nlm.nih.gov/33110135/)・[照明時間](https://doi.org/10.1002/ecs2.2550) | 夜の訪花、昼の補償、種子食を区別して初めて繁殖への正味の影響が分かる。アザミの結果はこの経路の種別例。 |
| 捕食 | 湖岸の照明区でクモ網の捕獲餌数が139%増加。河川ではコウモリの活動応答は種間で異なり、ヒキガエルの囲い実験では照明時に胃内容物が増えた。[クモ](https://doi.org/10.1371/journal.pone.0240138)・[コウモリ](https://pubmed.ncbi.nlm.nih.gov/31284209/)・[ヒキガエル](https://pmc.ncbi.nlm.nih.gov/articles/PMC7162902/) | 獲物の集中だけでも捕獲数は増える。訪花昆虫の被食率、捕食者自身の送粉、種子生産まで同じ岸で測定する必要がある。今回の地点年照合で連鎖は0件。[照合表](https://github.com/zuizui0223/alan/blob/b780370/results/all_species_forest/wet_site_years/coverage.csv) |

## 検索範囲とメタ解析の可否

Europe PMCで水辺と光、植物繁殖・季節性と光、湿潤性指標と水文の3検索を実行し、193書誌レコードを取得。検索式、書誌IDとタイトルを保存した。分野別の追加検索と原著・実験データの確認で、水文学・偏光等の索引漏れを補った。書誌レコード数にはプレプリントや関連性の低い研究が含まれる。上表は機構別に直接測定と反例を整理した重点レビューであり、全文二重選別や出版バイアス評価を完了した系統的レビューではない。[検索式と件数](queries.csv)・[検索一覧](literature_search.csv)

文献間で検証したい効果は、同じ研究・同じ応答（例：結実割合）での照明対暗区の差が、湿潤種で乾性種より大きいかという交互作用である。今回の照合で、同じ植物種・湿潤分類・比較可能な応答・独立な照明反復・分散がそろう複数の独立研究までは確認できなかった。訪花、網の捕獲数、結実率、地下水位を単一の効果量に変換して平均する根拠はなく、文献をまたぐ統合値は算出していない。スイスの訪花と結実も別の応答なので独立な同一効果として数えない。

次にマクロで識別力がある対比は、調査を継続した同一地点で、水位・湛水期間が安定した年と乾燥が進んだ年を区別し、湿潤種と同所の他種の記録率を比べること。河岸・湿地の消失が説明するなら、水位・水文期間の変化に沿った差が期待される。反射が説明するなら、岸の方位・光源・方向別放射に沿った差が追加で必要になる。送粉経路については *C. oleraceum* のように同じ種で、開花期間の花量、夜と昼の訪花、受精・結実まで実測した場所を優先する。
