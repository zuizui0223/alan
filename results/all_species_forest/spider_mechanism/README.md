# 湿潤植物の記録率とクモを介した経路

主要結果は環境変化を調整しても残る湿潤性の偏り。以下はその機構についての副次解析である。

**花上での待ち伏せ。** Romero et al. (2011) の公開 Table S1 から、predator taxa = Crab spider、category = Live、応答が訪花率の行を全て抽出した。死体・模型・過去の捕食痕は含めない。5文献14対比の log(クモあり／対照) と標本分散を使用。各文献内は逆分散で平均し、共通対照等に由来する未知の相関を0、0.5、1とした。文献を単位にPaule–Mandel法と修正Hartung–Knapp区間（分散補正の下限1、自由度4）で統合した。相関0.5で訪花率比0.724（95%区間0.517～1.015）。相関0で0.739（0.558～0.977）、1で0.718（0.504～1.024）。方向は共通だが区間の結論は依存の扱いで変わる。湿地・照明操作に限定した値ではなく、2011年の資料を範囲とした再解析。ハナアブ科に明示された生体クモの行は1対比のみで、ハナアブ固有の統合効果は推定しない。[原表・出典](https://doi.org/10.1371/journal.pone.0020689.s005)・[抽出値](live_crab_spider.csv)・[統合値](pooled_visits.csv)

**網での捕獲。** 湖岸の照明実験ではアシナガグモ科の網に捕獲された餌が139%増えた。橋の明暗パネルでも造網性クモの捕獲餌数増加が観察された一方、野外の *Nephila pilipes* では照明下で蛾が網にかかる率が低下した。湖岸の値は網の餌数で、岸に飛来した訪花昆虫を分母にした捕食率ではない。網への捕獲と花上での回避には異なる測定が必要で、これらの数値の掛け算から媒介効果を求めることはできない。[湖岸](https://doi.org/10.1371/journal.pone.0240138)・[橋](https://pmc.ncbi.nlm.nih.gov/articles/PMC7083158/)・[蛾の捕獲](https://pubmed.ncbi.nlm.nih.gov/29250464/)

**対象植物との接続。** 固定したGloBI v0.11と生息場所付き訪花資料を使用。水辺で確認された訪花昆虫と、成虫段階・出典が判明する食性記録（trophiCHを除く）を種名で接続した。花上で待ち伏せする *Misumena vatia* に結びついたのは候補7/9種、同じ解析の湿潤な比較植物14/17種。水辺に関係する幼虫微生息場所が知られたハナアブを介するのはそれぞれ4種と5種。アシナガグモ属 *Tetragnatha* に限定すると両群で0種。属についての比較で科全体の記録有無は判定していない。既知の食性と訪花を介した種レベルの接続であり、現場の捕食・その時間帯や頻度を意味しない。[群別集計](wet_links.csv)・[元の地点年照合](https://github.com/zuizui0223/alan/blob/b780370/results/all_species_forest/wet_site_years/coverage.csv)

**植物への正味の効果。** 花上のカニグモは送粉者を遠ざけても、花を食べる昆虫の除去によって植物に利益をもたらす場合がある。岸辺での検証には、照明・暗区ごとに花上のクモの有無、岸への飛来数、網での捕獲、花への到達、食害、柱頭の同種花粉、結実を区別する。これにより訪花の減少が植物の繁殖低下にまで届く条件を調べられる。[アブラナ科植物を用いた実験](https://doi.org/10.1038/s41467-018-03792-x)
