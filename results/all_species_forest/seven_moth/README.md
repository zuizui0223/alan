# 湿潤な減少候補は、同じ種類の湿地や訪花者を共有するか

主結果「気温・降水・市街化の変化をそろえても、増光地点で記録率が低下した候補に湿潤性の高い植物が多い」を受けた探索。湿潤指標>7の58候補と比較305種を出発点とした。形質資料は主に欧州の情報であり、長期観察地点も欧州に偏る。

## 生育地と繁殖形質

[Pladias](https://pladias.cz/en/) の種別ページに「2 – optimum」と明記された狭義の生育地を[種ごとに抽出](habitat_optima.csv.gz)した。情報が得られたのは48/58候補、176/305比較種。ハンノキ湿地林（15/48対27/176）、富栄養な止水のヨシ群落（10/48対20/176）、窒素に富む湿地の一年草群落（10/48対17/176）は候補に繰り返し登場する。地域・島の地点割合・調査地点数をそろえた比較で、65生育地区分のうち多重比較補正を通るものはなかった。種別記載は各GBIF地点の植生の実測とは異なる。[生育地別比較](habitat_prevalence.csv)

生育地、花粉媒介様式、交配様式、種子・栄養繁殖の4項目それぞれで記載集合のJaccard距離を計算し、等重みで平均した。全項目がそろった199種（候補42、比較157）の[2次元NMDS](habitat_nmds.png)のストレスは0.214。図は概観に用い、検定には次元圧縮前の距離を使った。地域・島割合・地点数の組合せに両群がいた38候補と75比較種を使い、13層内で候補ラベルを9,999回置換した。候補同士の平均生育地距離は0.929（帰無平均0.927、類似する側の片側p=0.592）、4項目の平均距離は0.733（帰無平均0.706、p=0.897）。湿潤性という大きな共通点から、特定の群落や繁殖型へは絞り込めない。[候補全体の検定](candidate_similarity.csv)・[全363種の収録状況](ordination_support.csv)

蛾の花粉運搬が確認された7種も全種入った。主要調査地域の内訳を保ち、記載がそろった湿潤な昆虫媒の減少候補26種から7種を選ぶ置換と比べると、生育地の平均距離0.856（帰無平均0.900、片側p=0.101）、4項目0.631（帰無平均0.647、p=0.352）だった。[7種の検定](similarity_tests.csv)・[21対の距離](focal_distances.csv)

## 訪花者と捕食者

同一調査の蛾の体表花粉では、7種中6種でヤガ科が最多だった。Epilobium hirsutum は14件中13件、Mentha aquatica は15件中14件がヤガ科で、残り各1件はシャクガ科。対照的に Iris pseudacorus の2件はシャクガ科とコウモリガ科に分かれた。同じ蛾科に花粉が付着していても柱頭への送達量と結実への寄与は不明である。[Waltonらの一次資料・付表S3](https://doi.org/10.6084/m9.figshare.12203336.v1)・[抽出表](pollen_carriers.csv)

[GloBI v0.11の既存の種名照合・抽出](https://github.com/zuizui0223/alan/tree/b780370/results/all_species_forest/wet_network)に戻り、推定相互作用を含み得るtrophiCHを外し、植物対ごとに双方を収録した出典内で訪花者名を比較した。21対中13対が照合でき、13対すべてに共通訪花者がいた。例として Iris pseudacorus と Epilobium hirsutum には8出典で計99種の共通訪花者（両者の和集合185種）がいた一方、蛾の体表に載った両植物の花粉の科別構成は異なった。未照合8対の重複数は欠測とした。訪花者の記録には昼行性昆虫を含み、共通出典の収録は同一調査地点や同じ時刻を保証しない。[出典をそろえた種対の比較](partner_similarity.csv)

既存の湿潤種マクロ比較では、訪花昆虫からクモへの接続の記録割合は地域・調査条件をそろえた候補96.6%、比較98.8%（29候補、p=0.824）。出典・成虫段階まで確認した蛾とクモの経路が Iris と Mentha にあるが、植物調査と捕食・訪花を同年10 km以内で同定できなかった。クモによる捕食は検証対象に残るものの、候補に偏る証拠、現場での捕食率、蛾の送粉低下による媒介割合は得られていない。[クモの資料と独立した実験の統合](../spider_mechanism/README.md)

## 同じ地点での記録率

7種と他の湿潤な昆虫媒植物133種を母集団とし、地点ごとに同じ植物調査系列で一度以上記録された両群を比較した。20年以上にわたる5年以上の調査を要求し、調査が続いた年の未記録は年当たり記録率の分子をゼロとした。年次記録率（検出した調査／植物調査）の傾きを種・地点ごとに求め、同地点での群間差を増光速度に回帰した。100 km区画内で比較し、気温・降水・市街化、出発時の明るさ、調査努力・期間・季節構成等を調整。区間は空間区画でクラスタ化した名目95%区間。表は増光速度が10 DN/10年大きい場合の記録率傾きの差（ポイント/10年）。同じ期間に選抜した候補を含み、独立した再現検定ではない。

7種を等重みで平均しても長期推定は+0.03 [−1.02, +1.08]。群間差の負方向は全期間では Stachys palustris と Mentha aquatica の2種で、種別7比較の補正後に明瞭な種はなかった。水域資料のある地点では島の方が正方向で、その差は水域調整前から存在した。衛星の1 km圏の水検出頻度から各個体の湛水日数は確定できない。[群別・種別結果](site_contrasts.csv)・[島−本土](island_minus_mainland.csv)・[種等重み](equal_species.csv)

[英国Environment Agency](https://environment.data.gov.uk/hydrology/doc/reference) の実測地下水位は、1 km以内で同じ調査年がそろった27地点・20井戸・5区画、すべて英国側。増光地点は4地点。水位調整後の全地点推定は−27.81だったが、1区画ずつ除くと3回は推定不能で、残る2回は−5.03、+14.95。地下水位調整後の向きも島と本土の違いも確定できない。[井戸の照合](nearest_wells.csv)・[区画除外](well_influence.csv)
