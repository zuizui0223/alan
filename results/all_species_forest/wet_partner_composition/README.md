# 湿潤な363種の訪花者・捕食者組成

唯一の主結果は、増光地点で記録率が低下した候補に湿潤な生育地を好む植物が多かったこと。ここでは両群を湿潤種に限り、同じ調査出典に記録された相互作用の組成を探索した。

## 58種と305種の定義

1992–2024年に評価できた3,901種のうち、増光地点での平均記録率変化と光の局所予測応答がともに負で、空間検証で光変数の追加とモデル全体に予測改善があった283種を候補とした。欧州の生育環境水分指標MOISTが7を超えるものを両群から抽出し、候補58種とその他305種になった。比較群には光との関連が不確かな種も含む。全363件は元のスクリーニングで区別した植物名で、WCVP受容名を共有する比較群の4件（2組）はネットワークへの二重割当を避けて照合対象から外し、名簿には保持した。[全学名・指標・群・記録範囲](species.csv)・[候補の選定法](../decline_traits/README.md)

## 資料と比較法

[GloBI v0.11をWCVPで照合した固定抽出](https://github.com/zuizui0223/alan/tree/b780370/results/all_species_forest/wet_network)から記名訪花者を採り、同名の訪花昆虫の食性記録を介して捕食者へ接続した。trophiCHを除き、訪花は同一データセット名、捕食は訪花・食性の両データセット名をそろえた。出典の共通性は個別調査や地点年の一致を保証しない。同じ捕食者種へ別々の訪花者から接続する場合も捕食者の共有として数える。食性記録の被食者が成虫と明記された場合も別集計した。

1. [収録範囲](sources.csv)は候補／比較の順に、訪花24/83種、捕食24/76種、成虫限定23/70種。ゼロ件には資料不足を含む。両群がいる出典内で植物間のJaccard類似度（共有する相手種数／相手種の和集合）を求めた。各植物対で共有出典の平均を取り、植物対を等重みとした。
2. [NMDS](nmds.png)は出典ごとに独立に実施。両群各2種以上、計6種以上、相手3種以上で距離に変異のある資料から、訪花12、捕食29、成虫限定11の配置を得た。同じJaccard距離には同順位を課した。図は各層で植物数が最多の出典を表示。2次元ストレスは順に0.348、0.181、0.196で、特に訪花の2次元配置には大きな歪みがある。[全出典の適合度](ordination_sources.csv)・[全座標](ordination.csv)
3. [比較検定](tests.csv)には元の距離を用い、候補同士と候補・比較の混合対の平均類似度差を検定した。主要調査地域と当該層での記録相手種数（1–4、5–19、20以上）内で植物の群ラベルを1,999回置換し、同じ植物に全出典・全ペアで同じラベルを使用。候補がより似る方向の片側検定6本をBH補正した。「生育地が異なる」は両植物に[Pladiasの適地](../seven_moth/habitat_optima.csv.gz)が記載され、その区分に共通項がないこと。現地の植生と世界全体の生育地を直接測定してはいない。

|適地が重ならない植物対|候補同士|候補と比較|比較同士|片側p|
|---|---:|---:|---:|---:|
|訪花者|0.050（84対）|0.038（440対）|0.047（446対）|0.302|
|訪花者の捕食者|0.450（69対）|0.397（329対）|0.394（307対）|0.125|
|成虫と明記された訪花者の捕食者|0.197（63対）|0.234（303対）|0.258（283対）|0.688|

全生育地を含む比較も含め、6検定で最小q=0.272。捕食者は発育段階を限定しない場合に広く共有されたが、候補に特有の組成を支持する差は確定しなかった。訪花者と捕食者では記録の対象・出典ごとの種数が異なり、両層の類似度の大きさをそのまま生態的な効果量として比較できない。

適地が重ならない候補対で、Bombus lucorum は10/84対、成虫記録を介したカニグモ科 Misumena vatia は51/63対に共通した。同じクモは混合対246/303、比較同士222/283対にも共通した。相互作用データは水辺に限った観察ではなく、捕食者の存在量、局所の攻撃率、照明応答や送粉成功を測定していない。[相手別の共有数](shared_partners.csv)・[種対別の共有出典数と類似度](pairs.csv.gz)

再計算はルートで scripts/analysis/alan_wet_partner_composition.py、次に scripts/analysis/alan_wet_partner_nmds.R を実行する。[使用した実在記録の接続表](links.csv.gz)の捕食者は、別の食性資料との接続に由来する。
