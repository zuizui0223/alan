# 同じ内陸湿地における候補植物と比較植物の年次記録率

主結果は、気温・降水・市街化をそろえても、増光地点で記録率が低下した候補に湿潤性の高い植物が多かったこと。ここでは既に選抜した58候補と305比較種を出発点に、同じ湿地の状態変化を探索した。

## 地点と記録率

1999–2023年の長期調査1,707地点に、調査初期の[CORINE 2000](https://land.copernicus.eu/en/products/corine-land-cover/clc-2000)を点で重ねた。欧州1,706地点中、内陸湿地411または泥炭地412のポリゴン内に18地点があった。北米の残り1地点には米国[National Wetlands Inventory](https://www.fws.gov/program/national-wetlands-inventory)の湿地ポリゴンが重ならなかった。周囲2 km四方に沿岸・汽水域の分類がある1地点を除き、17地点（内陸湿地12、泥炭地5、8空間区画）を淡水湿地の地図上の近似とした。塩分の現地計測、個体位置、調査期間中の湿地境界の不変性は確認していない。[地点とポリゴンID](habitats.csv)・[沿岸の除外](coastal_screen.csv)

17地点すべてで両群が同年に一度以上記録されている。期間中に実際に入ったのは候補33種・比較134種。151調査地点年、244調査日があり、127地点年で両群が検出された。地点別に種の名簿を固定し、各年の各群の検出種・日数を「名簿種数×植物調査日数」で割った。調査継続中の未記録年の分子はゼロ、植物調査がない年の値は欠測とした。元データの照合キーは調査系列・地点・年・種。記録率は検出努力や調査目的の変更の影響を受け得る。[地点種名簿](roster.csv.gz)・[年別の調査](survey_series.csv.gz)

## 冠水と水面後退の衛星指標

[GLAD Landsat](https://storage.googleapis.com/earthenginepartners-hansen/waterC2/download.html)の30 m年別・月別水検出率を各座標を中心とする約1 km四方で集計した。各月、観測の半数以上が水だった画素を水面とし、連続2か月の両方で有効な画素（全域の80%以上）のうち、非水面→水面と水面→非水面になった割合を別々に数えた。年ごとの水面の出入りは月数の偏りを抑えるため四半期を等重みにし、6か月対以上かつ4四半期すべてに観測がある場合に限った。年別水検出頻度は別途年合成値から計算した。水面の後退は自然の水位低下を含み、排水工事や草本の下の湛水の直接観測ではない。[月別の拡大・後退・有効率](monthly_water.csv.gz)・[年別の環境](annual_environment.csv.gz)

## 植生と草刈り

2000–2023年のTerra MOD13Q1（250 m、16日）で品質良好のNDVIを抽出し、4–5月・6–7月・8–9月すべてに観測がある年に限って各期間の中央値を等重みで平均した。1999年にはこの植生指標がない。植生全体の緑の濃さを扱い、植物種ごとのバイオマスを測定していない。[16日観測と品質フラグ](vegetation.csv.gz)

2017–2023年の[Copernicus GRAMD](https://land.copernicus.eu/en/products/high-resolution-layer-grasslands/grassland-mowing-dates-2017-present-raster-10-m-europe-yearly-4-layers)の10 m草刈り日4バンドとマスクを公開WMTSから元の整数で取得した。17地点×7年のうち、112地点年は非草本域フラグ、3地点年は対象だが刈取り検出なし、4地点年で刈取りを検出した。4件はすべて英国サマセットの同一地点。非草本域を草刈りゼロには数えない。[全地点・全年度の値](mowing.csv)

この4件についてSentinel-2 L2Aの赤と近赤外（10 m）から、晴天の植生・地表クラスのNDVIを計算し、同日複数シーンは中央値とした。処理ベースライン04.00以降は公式仕様に従い反射率DNのオフセットを適用した。[Copernicusの処理仕様](https://sentiwiki.copernicus.eu/web/s2-processing)・[シーン別資料](postcut_sentinel.csv.gz)

## 夜間光が同程度なら状態変化の大きい地点ほど候補は減ったか

1999–2023年の年次夜間光を全17地点・全25年に付け、調査年の値が植物データの明るさと一致することを確認した。全期間の夜間光の傾きが正は1地点、ほぼ不変1地点、負15地点。調査のあった年だけで回帰すると正は2地点になる。増光速度が同程度の**増光地点同士**の比較は成立しない。[全地点の光と記録率の傾き](site_trends.csv)

1. 地点間では、増光速度と湿地の型（内陸湿地・泥炭地）を調整し、状態変化と各群の記録率の傾きの関係を推定した。水検出頻度の長期変化速度の絶対値が1ポイント/10年大きい地点で「候補−比較」の記録率の傾きは−12.22ポイント/10年（区画クラスタ名目95%区間 −38.45～＋14.02）。NDVIの長期変化速度の絶対値が0.01/10年大きい場合は−1.19（−15.44～＋13.07）。8空間区画の1区画除外で符号が変わる。
2. 状態・応答を使わずに、同じ湿地型、同じ明暗変化方向、長期光傾きの差1 DN/10年以内で、重複しない地点対の数を最大化し、次に光傾きの合計距離を最小化した。6対すべて暗化地点。水検出頻度の長期変化が異なる5対のうち、変化の大きい方で候補が相対的に強く低下したのは3対（対差中央値−1.49ポイント/10年）。NDVIでは4/6対。[地点対](light_matched_pairs.csv)
3. 年単位では、地点・年固定効果、夜間光の水準・前年変化、気温・降水、調査日数と夏季調査割合を調整。前年に完結した水検出頻度の変化幅が1ポイント大きいと、翌年の候補−比較の記録率差は−1.15ポイント（141地点年、−3.85～＋1.55）。さらに、植物調査が2年連続した65対（16地点）の実際の記録率変化を比較した。同期間の水検出頻度の変化幅1ポイント当たり、候補群−1.44（−6.51～＋3.63）、比較群＋0.54（−2.36～＋3.43）、その差−1.97（−4.68～＋0.74）。こちらは夜間光・気象・調査努力の年変化を調整し、地点と同じ100 km区画を共有する年対の依存を区画クラスタで扱った。同年の衛星値は植物調査後の撮像も含む。いずれも探索的な関連で、群間差の多重比較補正後に明瞭な効果はなかった。[全係数と区画除外](contrasts.csv)・[調査年パネル](annual_survey.csv.gz)
4. 雲等で月間の方向を判定できない年が多い。四季をカバーした拡大・後退量は425環境地点年のうち22地点年、植物調査と同年にそろったのは8地点年。対象期間を夏季に限り6–8月の3か月対のうち2か月対以上を要求しても、前年夏の指標と翌年の調査がそろうのは26地点年・12地点で、指定モデルでは方向別の効果を識別できなかった。年合成の水検出頻度は425地点年、季節をそろえたNDVIは351地点年。近隣の英国実測地下水位との既存照合で、この17地点に重なる地点は0。

湿潤種の偏りが主要結果。当地での水文変動の推定は候補が相対的に下がる方向を示す場合があるが、規模・不確かさ・増光方向の不足により、水文変化が増光下で候補の減少を説明するとは結論できない。地域の選抜と同一年代の候補選定にも依存する。
