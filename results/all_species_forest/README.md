# 全維管束植物を母集団にした環境変化の種別ランダムフォレスト

対象は全球GBIFスナップショットから既定の品質条件で取得した1992–2024年の148,786種キー。世界の既知種目録ではない。長期傾きの線形モデルで有意か、傾きが推定可能か、蛾の訪花記録があるかを選抜条件にしていない。未推定を含めた all_species.csv.gz で全種を確認できる。調査設計と衛星照度の元資料は [年次データベース](../global_gbif_annual/README.md)、環境データのダウンロード元と原資料ハッシュは [環境変数の仕様](../long_term_land_contrasts/environment_forest/README.md)。

## 応答と環境の時間範囲

情報源・記録種別・座標が同じ地点で、適格な植物調査（その日に5種以上の維管束植物を記録）が5年以上あり、最初と最後の調査が20年以上離れている場合に対象とする。その地点で期間内に一度でも検出した各種の「その年の記録日数／植物調査日数」の傾き（ポイント／10年）を推定し、同じ座標に重なる情報源の傾きを平均した。対象種を最後に記録した後の植物調査も含み、調査のない年をゼロにしない。全月を使うため調査季節構成の経年変化（春夏秋の調査日比率、冬はこれらに従属）も説明変数に加えた。暦月による一致に限定した以前の427種解析とは推定対象が異なる。

比較した変化指標は調和済み衛星夜間光、年平均気温・降水率（NOAA/NCEP再解析）、建物等の被覆面積（JRC GHSL）。光・気候は実際に調査された同じ年に対応させた傾き。GHSLは1990–2020年の2時点の変化。各変化指標を除く場合でも、基準時の光・市街化、期間平均気候、調査年数・期間・開始年・努力・調査季節の変化、島区分は残した。推定対象は生息個体数ではなく記録率。全要因を測定した比較ではない。

greenup/ は北緯30度以上で衛星NDVIから得た春の緑化日を同じ観測年に照合した追加解析。GIMMS3g v1 Method 4（植生の年振幅の50%通過、1992–2014年、開始日1–366日）。緑化日の10年変化を第5の比較指標、平均緑化日を基礎変数とした。有効な衛星値のある年だけで調査履歴、検出種リスト、光・気候・記録率の傾きをすべて作り直した。建物は1990・2015年のGHSLで近似した。期間と座標が変わるため、主解析との違いを緑化日だけに帰属できない。[緑化日の元研究](https://doi.org/10.1038/s41467-019-10235-8)・[GHSL 2015](https://jeodpp.jrc.ec.europa.eu/ftp/jrc-opendata/GHSL/GHS_BUILT_S_GLOBE_R2023A/GHS_BUILT_S_E2015_GLOBE_R2023A_54009_1000/V1-0/GHS_BUILT_S_E2015_GLOBE_R2023A_54009_1000_V1_0.zip)。

## 種判定と読み方

各種に別々の回帰森林を当て、100 km区画を分割単位として検証（最大5分割、2–4区画でも探索値を記録）。訓練側2座標未満、応答が一定、独立に外せる区画が足りない等の場合は状態を保存。全変数の森林と各変化指標を一つ外して再学習した森林を、同一の未使用区画で比べる。評価時は各空間区画を等重みにする。skill は訓練平均のみの予測に対するMSE改善割合。gain_light は光を外した時のMSE増加を同じ訓練平均モデルの検証MSEで割った値（値が0.05なら基準MSEの5%分）。全変数の説明率や光による因果寄与率ではない。topは比較した変化指標の中の独自予測寄与順位で、初期条件や調査努力は順位の対象外。

初回に「光が単独1位、寄与が正、モデルのskillが正」を満たす全種を、別の100 km区画の組み合わせ・別乱数・64本の森林で再評価（初回24本）。candidates.csv は両方の分割で同条件、かつ両方で5分割中4以上で光追加により予測改善し、局所予測差の符号も両方で一致する種。局所予測差はテスト地点で他の変数を固定し、その地点を挟む訓練側の光の隣接五分位点で予測を比較したもの。強さ（gain_light）、方向（light_response）、増光した地点で観測された平均記録率変化（observed_at_brightening）を区別した。net_agreesは実際の平均変化の方向も一致したかを示す。再分割は同じ資料内の安定性確認であり、多重検定を通過した因果効果・時系列外挿・別の観測網での独立再現は検証していない。

## 再実行

scripts/analysis/alan_all_species_forest.py に work と出力ディレクトリを渡す。緑化日版は末尾に --green を付け、greenup を出力先に指定する。公表済みの年次データベース、NOAAとGHSLの原資料、緑化日版ではwork/gbif_macro/pheno配下の各年のラスタが必要。
