# 湿潤植物の送粉・繁殖様式と蛾・クモの仮説

固定した湿潤指標 >7 の減少候補58種と、同じスクリーニングで得た他の湿潤種305種を対象とした。[全363種の種別台帳](species.csv)には、公開種別ページ、花色・対称性、利用可能な送粉・交配・栄養繁殖の分類、蛾の花粉運搬、関連する捕食記録を収録した。地域の植物誌による種の分類と、特定の集団・年に実測された繁殖や訪花は区別する。具体的な自殖率を測定したものではない。

## 種の特徴

Pladias の種ページでWCVP受容名、次いで元の種名の見出しが完全一致する場合を採用（272/363種、残り91種は種ページ未照合）。送粉様式はBiolFlorに由来し、風・水・昆虫・同株内花粉移動などを併記できる。地域・観測規模・島地点割合をそろえた種間の両側置換で比較した。Pladiasの「自家花粉が移動しうる」、自家和合性、訪花者なしに自動自殖できる能力は異なる。分類は一部重複し、掲載割合を足して100%にはならない。[種情報と定義](https://pladias.cz/en/download/features)・[全比較と多重比較補正](contrasts.csv)

種間比較で明瞭な偏りは得られなかった。白＋筒状等の形態を既存台帳で判定できた候補は10種で該当0種。開花時刻・匂い・蜜・花筒長を含む蛾媒シンドロームや専門性を判定するには不足する。Pladiasの訪花者群では蛾が蝶と一括されるため、ここから蛾の利用を推定していない。開水面維持地点で先に抽出した6候補でも、*Eleocharis palustris*、*Juncus bulbosus*、*Alnus incana* は風媒、*Schoenoplectus lacustris* は風・昆虫媒、*Rorippa palustris* は昆虫媒・自家花粉移動、*Thysselinum palustre* は昆虫媒と記載される。

## 同じ長期調査地点で昆虫媒群の記録率が特に下がったか

全湿潤種から送粉様式が判明する種を使い、減少候補への選抜に条件づけず計算した。同じ調査座標で昆虫媒（風媒の記載なし）と風媒（昆虫媒の記載なし）が共に出現履歴を持つ場合に、それぞれの植物について元の年別の調査あたり記録率の10年傾きを使い、群内種を等重みにして地点内差を求めた。自家花粉移動・水媒の併記を許容。両群の調査環境・努力の入力が同一の座標に限定した。地点内差を応答に、100 km区画内の地点間で増光の強さを比較。気温・降水・市街地変化と初期環境、調査時期・期間・努力を調整し、区画クラスタによる近似95%区間を算出。値は増光速度10 DN/10年あたりの群間の記録率傾き差（ポイント/10年）。同一種の訪花前後や受粉量を直接比較したモデルではない。[入力の作成](https://github.com/zuizui0223/alan/blob/b780370/scripts/analysis/alan_all_species_forest.py)・[結果表](within_site.csv)

昆虫媒123種と風媒85種の4,579地点・95区画で差は−0.46（−2.21～＋1.29）。島区分では−0.05、本土では−1.24でいずれも区間が0を含んだ。昆虫媒群内で厳格な他殖分類（allogamy または allogamy self-incompatibility の単独記載）と、自殖・任意自殖・混合交配の記載を持つ分類を比べると、4,128地点で＋1.00（−0.32～＋2.32）。ここでは任意他殖のみは比較から除外した。本土のみの探索では＋2.53（＋0.79～＋4.28）で「他殖群がより減る」という予測と逆。部分群の区間は多重比較未補正で、島・本土差の検定ではない。湿潤種全体を一律に送粉者不足で説明する証拠は得られていない。

## 蛾が運ぶ花粉と、クモが食べた蛾

Walton et al. の英国農業景観の池周辺研究で、付表S3の植物種×蛾の科の個体数を再抽出。末尾の脚注記号を除き、原表の Iris psuedacorus は I. pseudacorus として照合した。*Mentha aquatica*（15個体）、*Epilobium hirsutum*（14）、*Ranunculus sceleratus*（5）、*Stachys palustris*（3）、*Iris pseudacorus*（2）、*Solanum dulcamara*（2）、*Lythrum salicaria*（2）の花粉運搬を確認。従来の候補4種に3種を追加し、比較群も1種から2種に増えた。7/58と2/305は発見できた証拠の下限。両群を均等に実験した割合ではない。付表が示すのは蛾の体からの検出であり、花への訪問回数や柱頭に付いた和合花粉数は含まない。既存台帳で昼の訪花を許して夜だけ遮断した効果量の照合は0/363種。[原研究](https://doi.org/10.1098/rsbl.2019.0877)・[一次付表](https://doi.org/10.6084/m9.figshare.12203336.v1)

種名でGloBIの訪花・送粉記録と、成虫段階の明示されたクモの食性記録（trophiCHを除く）を接続できたのは、訪花者種の記録を持つ候補6/32種と比較8/139種。地域・調査規模をそろえた既記録率差は＋12.6ポイント（名目 p=0.118）。生息場所の明記された別の河岸訪花資料まで含めると候補2種、比較1種で湿地の植物－蛾－クモの組合せが残った。この探索とGloBI単独の探索は母資料が異なる。[GloBI両辺の出典](moth_spider_sources.csv.gz)・[水辺資料と食性の接続](habitat_labelled_moth_spiders.csv)

候補での具体例は *Iris pseudacorus* の花粉に結びつくシャクガ *Xanthorhoe montanata* とハエトリグモ *Attulus terebratus*、*Mentha aquatica* とヤガ *Autographa gamma* とカニグモ *Misumena vatia*。植物と蛾の種名ペアは英国DoPIのWalton研究に由来する花粉分析（分類2）、蛾とクモは別の場所を含むiNaturalistの食性資料。付表S3の種×科と、DoPIの種×種の解像度も区別した。GBIF・衛星の元の1,707地点での同年近距離の連鎖は前回の照合で0件だった。[DoPI原資料](https://doi.org/10.5281/zenodo.15224385)・[地点年照合](https://github.com/zuizui0223/alan/blob/b780370/results/all_species_forest/wet_site_years/coverage.csv)

クモに関わる量には別々の根拠がある。湖岸の明暗実験は照明区でクモの網の餌数が139%多かった。花上に生きたカニグモがいる場合の訪花率比0.72（0.52～1.01）は、公開付表の5文献14対比から、文献内の効果量の相関0.5を置いた再統合で得た。期間中に飛来した蛾を分母にする攻撃・捕獲率はどちらからも求められない。照明下で蛾の網への捕捉が減ったクモの実験もある。植物が受け取る総花粉量が減る経路としては、飛来・訪花回数が減ることと、1回の訪花で届く和合花粉が減ることを分ける必要がある。自殖・栄養繁殖できる植物でも種子生産や遺伝的な他殖機会は変わりうるが、それが長期の記録率低下に及ぼした寄与率は未推定。[湖岸実験](https://doi.org/10.1371/journal.pone.0240138)・[カニグモ再統合](../spider_mechanism/README.md)・[逆向きの捕捉実験](https://pubmed.ncbi.nlm.nih.gov/29250464/)・[灯火と蛾の花粉運搬](https://doi.org/10.1111/gcb.13371)

## 生態学的な識別点

水辺は、水中から成虫が供給される場所、昆虫が灯火に集中する場所、花と網がある場所が隣接する。この位置関係から、灯具の近くで虫が増えても、開花株での夜の訪花は減りうる。クモ媒介なら同じ光条件でクモへのアクセスが異なると捕獲・訪花が変わるはずで、光が直接蛾の飛行を変えるだけならクモのいない区でも変わる。7候補中、既存台帳で花粉制限まで数値照合できるのはエゾミソハギ1種（0.222）で、英国の花粉調査とは別の資料である。風媒群にも減少候補が含まれるため、水位・湛水期間・植生管理という共通の生育地経路を並行して扱う。
