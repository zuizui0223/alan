# 水辺の植物・訪花昆虫・捕食者の照合

湿潤指標 >7、減少候補58種と同じスクリーニングの他の305種を固定した。direct_inventory は対象植物を起点・終点の両方で探索し、WCVPで一意に解決した植物種に対するGloBIの関係語・方向・相手名を保存する。species の列はその関係の既記録を表す。資料にない組合せの生態的な有無は不明。

- [GloBI v0.11](https://zenodo.org/records/22691479) の全 interpreted parquet をMD5照合した。訪花接続は visitsFlowersOf / flowersVisitedBy と pollinates / pollinatedBy。捕食側は eats / eatenBy と preysOn / preyedUponBy を含む。昆虫と動物の学名は種レベルの二名法の完全一致とし、捕食記録で被食者が Insecta であることを要求した。食性記録は胃内容物などを含み、生きた獲物への攻撃が観察されたとは限らない。宿主関係や花上での共出現を捕食に読み替えていない。
- [EuPPollNet v1.3.0](https://doi.org/10.5281/zenodo.15183272) の河岸2区分と、[DoPI](https://doi.org/10.5281/zenodo.15224385) の河岸・湿地・塩性湿地を水辺の訪花とした。DoPIで花上の捕食者・盗蜜などを示す区分4を除外し、区分1のみを柱頭への移送または種子形成の直接証拠とした。出典データベース間で重複する組合せは種数を増やさない。
- [EuPollTrait](https://doi.org/10.5281/zenodo.18032357) の幼虫微生息場所が on_water_plants または submerged_sediment で yes のハナアブを種名で照合した。現場での羽化、絶対的な水生依存、成虫の夜行性を意味しない。
- wet_flower_diet は水辺と明記された花の観察と、場所を問わない食性の接続。wet_guild_evidence では複数の訪花者を介する例、セイヨウミツバチを除いた例、被食昆虫を成虫と明記した例、水辺性幼虫のハナアブを介する例を区別した。成虫判定は prey_stage が adult、adults、Adult(s) または imago の場合に限定した。トンボ類の幼虫・成虫で餌と捕食場所は異なり、捕食者の発育段階と採餌時刻はこの集計で限定していない。
- same_coordinate_day は明示された暦日と数値座標が一致した訪花記録と食性記録。記録の地点精度・日付精度に依存する。原資料の集計地点・期間、異なる場所での検出、データベース間の重複は直接観察の代わりにならない。照明条件、訪花昆虫の母数、捕獲数、訪花努力、受粉成功を同時測定した資料はこの照合では特定しない。
- comparisons の比較は主要5度区画、島地点割合、植物の調査地点数で層をそろえた両側置換。wet_degree_adjusted はさらに水辺で記録された訪花者種数を1、2–4、5–15、16以上の層で調整した。matched は比較可能な候補植物数で、候補と比較種の調査文献が同量である保証はない。掲載するp値は探索的な値。
食性については、推定リンクを含む可能性がある [trophiCH](https://webapps.wsl.ch/trophiCH/) を除外し、他出典かつ成虫段階を明示した組合せも別集計した。
