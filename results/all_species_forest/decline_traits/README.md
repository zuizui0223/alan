# 283種の形質と生育環境

1992–2024年のRFで、増光地点での平均記録率変化と光の局所予測応答がともに負、空間検証で光追加の寄与と全体の予測改善がともに正だった283種を固定。候補の絞り直しはしていない。

母集団は同じ解析を評価できた3,901種。種ごとに寄与座標数最多の5度区画（同数なら小さい区画番号）、島の座標割合（25%以下、25–75%、75%超）、座標数（10、30、100、300、1,000を境界）を割り当てた。各形質の既知種内で同一層の候補以外を比較群とし、候補種を等重みにして参照平均を標準化。比較対象は全評価種、増光地点での平均記録率が低下した種のみ、同じ科内の3通り。層ごとに候補数を固定して種ラベルを3,999回並べ替え、両側検定のp値を算出。比較ごとに推定可能な17形質のBH補正を実施。置換は層内の種の交換可能性を仮定し、全系統と調査地点共有による依存をモデル化していない。島座標割合は標本構成で、島と本土の個体群間の効果差ではない。

WCVPで受容名が一意の種のみを接続。ヨーロッパの環境指標は [Tichý et al.](https://doi.org/10.1111/jvs.13168) の [著者配布CSV](https://www.sci.muni.cz/botany/juice/NET/sources/EIV_Europe.csv)（SHA256 ffeb2a5f45c95886625f970734e431098587c65baad7def786d35364a761dbba）。x と NA は数値を与えず、WCVPで同じ受容名となる複数行で指標が矛盾する場合も欠測。MOISTは生育環境の水分傾向、LIGHTは日中の生育環境の明るさの指標。土地利用・水位・排水の経年変化の直接観測値ではない。WCVP生活型、既存の単一状態の直接形質台帳、GloBI訪花記録、蛾の花粉運搬レビュー、夜間遮断実験、GloPLの種内中央値を併用。訪花記録は文書化率、運搬確認率はレビュー済み種のみ。原台帳の個別形質は再配布せず集計のみ収録。

traits.csv は主解析と2種類の参照群、moisture_checks.csv は湿潤性についての追加探索（別の学名照合、初期光量区分追加、島座標割合別）。追加解析のp値は未補正。moisture_region_influence.csv は主解析で各地域を一つ除いた差。moisture_evidence.csv.gz と moisture_distribution.csv は公開環境指標の種別照合と重み付き分布。cohort.csv は未照合・未測定種を含む全283種。

scripts/analysis/alan_rf_decline_traits.py に work と results のパスを渡す。EIV_Europe.csv は work/gbif_annual に置く。本研究の主結果は283種の減少候補における湿潤環境の種の過剰である。
