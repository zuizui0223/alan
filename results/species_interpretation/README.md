# 544種別に読める結果

旧GloBIで蛾による訪花が記録され、元の5年間に島・本土双方で一度以上撮影された544種を全件収録した。各種が何を根拠に分子に入り、既存の係数に何ポイント寄与したかを分けて読める。種の順位ごとに個体数の増減、送粉者の交代、照明による因果効果を認定する用途には適さない。

## 旧主要結果を種に分解する

既存の10,698地点年・78地域・195地域年の重み、固定効果、共変量を使用した。種ごとの応答は 100 × 地点年でその植物が写真に含まれる指標／その地点年に撮影された全植物種数。回帰はこの応答に線形なので、同じデザインから島・本土の係数への各観測の重みを1回求め、各植物の記録地点について重みを足した。新しい種別の共変量・モデル・有意性判定は導入していない。単位は「log(1＋同年VIIRS)あたり、撮影種構成に占める百分率のポイント」。island_pp と mainland_pp が各側、gap_pp が島−本土。difference_if_relabelled_v011_pp はラベル更新によるこの種の寄与の差で、残った種は0、分子から外れた種は元の gap_pp の符号を反転した値。種の記録地点と構成比は更新前後で同じである。[元の固定設計](../../scripts/analysis/alan_globi_crossland_light_robust_20261111.py)・[既存の寄与分解](https://github.com/zuizui0223/alan/pull/43)

| 544種の内訳 | 種数 | 負／正の種数 | 島−本土への寄与の合計 |
|---|---:|---:|---:|
| 旧で陽性、v0.11で種IDの陽性記録なし | 310 | 179／131 | −2.39651 |
| 両版で陽性 | 234 | 123／111 | +0.38924 |
| 全体 | 544 | 302／242 | −2.00727 |

旧の分子には、島または本土の片側だけに記録された種の寄与 +0.10555 も含まれ、合わせて −1.90172 になる。v0.11には旧の544種以外から新たに入る種もある。544種の寄与だけから新版の全係数は計算できない。種別の正負の個数は選択した標本の記述に限る。群集構成比は観察努力、共に写った種、照明と相関する生育場所、分布や栽培・撮影の偏りにも反応する。島の陽性記録が1地点年だけの種は243、同じ5°地域・同じ年の両側で記録されたことのない種は301。後者にも固定した全地点の構成比への寄与はあるが、同じ地域・年に自種を追跡した島本土比較とは解釈できない。

## 種の機構を検討できる範囲

- 種別表の glopl_median_log_response_ratio は既刊実験の花粉追加による繁殖応答の中央値。sc_source_class は自家和合性資料の分類。glopl_cases=0 は対応実験が見つからなかった状態で、花粉制限の値は欠測のまま。未確認53種の既存一次文献レビューを反映し、花粉制限既知の64種で蛾の花粉運搬確認は17種。544種全体で確認49種、未確認495種。43種は元調査、6種は花粉制限既知の種に絞った再確認で追加された。証拠のない495種に同等の追加調査は実施されていない。transport_source と transport_evidence から体表花粉、花粉塊、単回訪花による柱頭への移送などを追跡できる。[元証拠と測定定義](../moth_pollen_evidence/README.md)・[53種の一次資料と再分類](../pl_transport_species_review/review_53.csv)
- 日中の訪花を許し夜だけ遮った day_only_relative_loss は 1 − 昼のみ開放／終日開放。0は観測上の等値、負の値はその研究の昼のみ開放区で相対的に高い繁殖成績、欠測は使える対照実験がないことを示す。*Silene latifolia* で +0.672（5研究）、*S. nutans* で +0.871（1研究）に対し、構成比寄与はそれぞれ −0.0547、−0.00436。どちらも同地域・同年の両側で撮影された例はない。*Asclepias syriaca* にはSI・蛾の花粉運搬・強い花粉制限の記録があり、構成比の寄与は −0.2174（島5／本土30地点年）。同種の夜間遮断相対低下は −0.436（1研究）。この植物で花粉の不足が、どの時刻・どの訪花者に依存するかは別の問いである。[種別実験](../night_exclusion/experiments.csv)・[*A. syriaca* の野外実験](https://doi.org/10.1007/BF00379521)
- *Lonicera japonica* では夜間のスズメガの単回訪花あたり花粉付着を調べた独立研究があり、旧版のみで陽性、島1／本土25地点年、構成比の寄与 −0.0143。*Lantana camara* はモーレアの記録で蛾が運んだ花粉を確認、両版で陽性、島4／本土15地点年。島・本土それぞれの構成比の傾きは −0.0070、−0.0527 なので差は +0.0457 になる。この正値を「島の明所で増えた」とは読めない。[スイカズラ原著](https://kyushu-u.elsevierpure.com/en/publications/why-does-the-flower-of-lonicera-japonica-open-at-dusk/)・[モーレアの調査報告](https://anthony.darrouzet-nardi.net/works/mothpaper.pdf)
- 共通544種で独立植物形質の判定可能範囲も集計した。色と形の両方が分かった103種のうち、白＋筒状・高杯状・漏斗状に該当したものは4種（旧のみ2/58、両版2/45）。441種はこの形態分類が不明。深さも判定できた34種では白＋上記の形＋深い花筒の該当は0、残る510種は不明。直接出典で単一値が確定した種だけを集計し、情報欠落と陰性を区別した。PR #44が公開するのは形質の集計なので、個別種の形質を配布せず、種別表の direct_flower_form_status は公開範囲を示す。群別の形態候補数だけでは蛾のスペシャリストへの依存率を推定できない。[544種の形態集計](morphology_counts.csv)・[元の全種解析と形質定義](https://github.com/zuizui0223/alan/pull/44)

## 照合と再実行

全8,581撮影種から、旧の受容名への一致とv0.11のWCVP受容IDへの一致を別に復元した。全種の積上げが元係数 −1.901720622 と新版 +0.750257336 に一致、既出の夜間遮断12種の種別係数・島陽性地点数と既出のPL64種の種別傾きの線形対比 −0.019380046 に一致した。さらにPR #43の旧新差寄与上位・下位各20種のうち対象544種と重なる36種で個別寄与の差が 8×10⁻¹⁵ 以下だった。544種の photos は写真枚数、regions は撮影地域数、flowering_annotations は公開観察単位の開花注釈の付いた写真記録数。これは月別観察時間の測定ではない。[写真出典](../phenology_support/README.md)・[同一地点・直接照合結果](../globi_v011_fiveyear/comparison.json)

実行例は次のとおり。原本の座標や種別の直接形質行は出力しない。

```
python scripts/analysis/alan_shared_species_contributions.py INPUTS SIGNED results/species_interpretation direct_species_trait_ledger.csv.gz
```
