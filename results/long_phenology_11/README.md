# 同一地点での夜間光変化と、春の緑化から開花開始までの間隔

## 母集団と再現方法

島側の固定5年の構成比傾きが負だった283種のうち、元の同じ地域・年の島と本土でUSA-NPNが開花陽性を記録した11種・3地域を全て含めた。母集団はその種・地域で元の5年に1回以上開花を実測した全定点。新たに2012～2025年の各年の個体別 Open flowers を再取得した。遡及取得で生じる新規定点を追加して母集団を変えていない。

- 同一個体の最初の陽性と30日以内の直前陰性から開始日の中点を求め、同一種・地点・年の個体中央値とした。秋咲きの Hamamelis は年の後半で開始を判定。観察努力と実際の開花時刻の不確実性は残る。
- 開花開始がある地点年で同一座標のMOD13Q1.061（Terra、250 m・16日）を取得。名目合成開始日でなく画素の採用日を使用し、データ範囲内かつ信頼度0の画素を使用。暦日80日までと160～240日に良品質データが各2回以上あり、夏＞冬の場合に、冬夏中央値の中点を45～180日の間に初めて上向きにまたぐ日を求めた。32日以内の連続する良品質観測間だけ線形補間した。応答は開花開始日からこの緑化日を引いた符号付き日数。[NASA MOD13Q1.061](https://doi.org/10.5067/MODIS/MOD13Q1.061)
- 夜間光は同一地点・同年、1・4・7・10月のVIIRS月別値（雲なし2観測以上）のうち有効3月以上の中央値を採用。露出は log(1＋非負放射輝度)。未取得年は補間していない。
- 明るくなった地点ほど日数が変化したかは、3年以上完全な種・地点系列で、実測年から夜間光と日数のTheil–Sen経年勾配を別々に算出し、島と本土で勾配同士を比較した。併せて、2年以上ある系列について種×定点固定効果と暦年固定効果を置き、同じ種・地点の明るい年と暗い年における日数の差を推定。島と本土で光の係数を変え、島−本土差も算出した。各種・定点年を等重み、標準誤差は定点クラスタ、区間は名目95%。少数の島定点・非連続年・気候等の交絡に注意。季節指標の誤差や同一種に由来する定点間相関は区間に含まない。
- 元版GloBIの植物別訪花蛾から、GBIFで種名が完全照合できた分類群について、定点の緯度・経度±0.025度、成虫と明記された日付付き記録を検索。元の種名と返された種名が一致した記録日に限定し、同一種地点年で最短日差と同日記録を集計。同じ植物での訪花時刻やトラップ努力のデータではない。
- 実行順は scripts/analysis の alan_extended11.py、alan_extended11_ndvi.py、alan_extended11_moths.py、alan_extended11_report.py。各スクリプトに既存の phenology_run ディレクトリを渡す。旧GloBI種名表は元の実行環境と同じ ../v011/old に置く。

## 結果

開花開始・緑化・夜間光がそろったのは2015～2025年の211種地点年（島47、本土164）。同じ種・定点が反復した193種地点年に限定し、1＋放射輝度が10%高い年の間隔差は島 −5.64日（名目95%区間 −9.54～−1.73）、本土 +0.20日（−2.18～+2.58）、島−本土 −5.84日（−10.01～−1.67）。島は9定点・4種の42種地点年で Gaylussacia baccata が34を占める。本土は33定点・8種の151種地点年。種と地域の構成は両側で異なる。各定点の実測強度幅に近い10%を例示し、倍増への外挿値は主要な解釈に使用しない。

3年以上に限った長期勾配の比較では島8定点中6点が Gaylussacia。Kalmia latifolia の1点は3年しかなく、夜間光の年間増加も間隔の短縮も突出した。勾配同士の順位相関は島 −0.286、本土 +0.187。重なった開花・成虫観察は132種地点年、同日記録17種地点年。成虫の季節的検出努力は不明で、送粉者とのずれが変化したかは推定していない。
