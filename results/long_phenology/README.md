# 島で負の植物の長期開花・植生・成虫記録

主要結果 −1.902 と64種の花粉制限の副次結果を固定し、2012～2025年を独立の定点観測として照合した。元の固定5年で島側が負の283種について、USA-NPN Open flowers の開花陽性を元の地域枠・両陸域・同年で照合すると11種・3地域。このうち両側に複数年の定点記録がある東西の例として Hamamelis virginiana と Holodiscus discolor を選んだ。2種×各陸域1定点であり、283種・78地域の経年効果ではない。元の構成比を観測した写真格子と同一であることは要求していない。地域内でも緯度・気候・植生・観察者が定点間で異なる。[全11種](frozen_flowering_pair_screen.csv)

## 時間と空間の照合

- [USA-NPN](https://www.usanpn.org/data) で4定点の各年・対象種・Open flowersを再取得。0と1の個体記録を保持し、不明は開花陰性に数えない。同じ個体の初回陽性とその前30日以内の直近陰性の中点を開花開始の推定日とし、定点年内の個体中央値を用いた。秋咲きの Hamamelis は当年の後半で開始を判定。撮影日や初回陽性を無条件で開始日とはしない。観察者、個体、訪問日の変化や中点の区間誤差は残る。開始日と最終陽性日から開花ピークや全花期を補っていない。
- [NASA MOD13Q1.061](https://doi.org/10.5067/MODIS/MOD13Q1.061) のTerra 250 m、16日合成を定点座標で抽出。ORNLまたは同製品のPlanetary Computer COGから、NDVI、信頼度、画素採用日を取得。NDVIは1万分の1に換算。最良品質の画素（reliability=0）に限定し、各開花陽性日の前後16日以内で最も近い画素採用日を選び、年ごとの中央値を算出。NDVIは周囲の植生の緑量を捉える。個々の種の開花を捉える指標として使っていない。[16日ごとの原値・採用日・品質](ndvi_16day.csv)
- 春の緑化と開花までの間隔も別に計算。冬（年初～80日）と夏（160～240日）の良品質画素が各2日以上、夏の中央値が冬より高い年に限る。45～180日内で冬夏中央値の中間を最初に上向きにまたぐ隣接2観測（間隔32日以内）を線形補間し、開花開始日との差を求めた。植物と背景植生の暦の差であり、蛾とのずれとは異なる。
- 同年同座標のVIIRS夜間放射輝度は元解析に合わせ1・4・7・10月のうち、雲なし観測2回以上の月が3か月以上ある場合の中央値。2012・2013年のリクエストでは有効値が得られず欠測。年別の有効月数を併記した。
- 元GloBIの記録で訪花した成虫蛾の候補について、各定点を中心に経緯度±0.025°の範囲で日付付きGBIF成虫記録を照合。対象は Hamamelis の Spoladea recurvalis、Pyreferra citrombra と Holodiscus の Ctenucha rubroscapus。記録日の重なりは、対象植物への訪花や有効送粉を意味しない。欠測日を活動ゼロとせず、トラップ努力の分母がないデータから飛翔ピークや季節重複率を算出していない。
- [全56定点年](station_year.csv)・[定点ごとの経年勾配](station_trends.csv)・[時系列図](annual_series.png)。勾配は実測年についてのTheil–Sen推定、区間は系列相関・観測日の区間誤差を考慮しない記述値。島と本土の明暗処理や照明効果の独立反復はない。

再取得は既存の非公開作業ディレクトリ（npn/individual_visits.parquet など）を引数として alan_long_ndvi_download.py、alan_long_ndvi_cogs.py、alan_long_light_moths.py を実行する。続いて alan_long_phenology.py、alan_long_phenology_summary.py、引数なしの alan_long_phenology_plot.py を実行する。再取得した原データはキャッシュし、公開表には個体番号・座標を掲載しない。

## 結果

地上994個体観察（陽性・陰性）、NDVI 1,249定点×合成期間。開花確認・開花時の良品質NDVI・同年の夜間光がそろうのは23定点年。NDVIの取得には2023～2025年に欠けた期間があり、全期間を補間していない。

*Holodiscus discolor* では同じ年に両側で開花開始を推定できた5年間の島−本土差が −19、−5.5、+26.5、−13.5、+63日。両側の夜間光は経年的に上昇したが、島で一貫して開花が早まった傾向は確認できない。開花と春の植生緑化の間隔を両側で比較できた2021年は島34.6日・本土43.0日。蛾 *Ctenucha rubroscapus* の近傍成虫記録は両定点とも0件。

*Hamamelis virginiana* の本土では2013～2025年中12年の開花開始が記述的に0.94日/年早まった。島で比較可能なのは2023～2025年のみで、島の開始が本土より27～34.5日遅かった。島画素では採用基準を満たすNDVIがなく、花と蛾の記録が両方あるのは2年。最も近い成虫観察日から開花確認日まで53日（2023、開花2日）と40日（2025、開花1日）が空いた。観測日の少なさ、春と秋の異なる時計、近傍成虫の実際の訪花と検出努力の欠測を踏まえ、送粉ミスマッチの成立や強化を示す値には使えない。
