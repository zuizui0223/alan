# 全球GBIFの年別植物記録率と夜間光、候補種の開花と衛星緑化

## 結果

実際に20年分以上の植物調査がある地点で、全調査日から作った年別記録率を推定できたのは66種。Ranunculus repens の記録率は同じ地点の明るい年ほど低く、衛星夜間光10 DN当たり −6.46ポイント（95%区間 −8.58～−4.34、BH q = 0.00469）だった。32座標・716地点年を含み、対象種の未記録は360地点年、最終検出後も植物調査の続いた年は79地点年。比較に寄与した100 km区画は10で、うち1区画に調整後の光変動の54%が集まった。期間の長さだけを求めた広い群では、この種の傾きは −0.70、q = 0.780。ヘラオオバコの傾きは、実調査20年群で −1.04（q = 0.917）、広い群で +0.59（q = 0.772）だった。

広い群の全調査日モデルでは2,065種を推定でき、負方向は Draba verna、Poa pratensis、Carex nigra、Rhinanthus minor、Urospermum picroides、Hydrogalium palustre の6種。正方向は Hyacinthoides non-scripta、Juncus balticus、Rubus ulmifolius、Stellaria crassifolia、Foeniculum vulgare、Viola ruppii の6種。負方向6種のうち、同じ暦月に限った比較でも傾きを推定できた5種はすべて負方向だったが、その5種は同月比較の多重検定補正を通過しなかった。

| 対象・推定法 | 推定できた種 | 負方向 q < 0.05 | 正方向 q < 0.05 |
|---|---:|---:|---:|
| 20年以上を覆う地点、全調査日による年別記録率 | 2,065 | 6 | 6 |
| 20年分以上の実調査、全調査日による年別記録率 | 66 | 1 | 0 |
| 20年以上を覆う地点、同じ暦月の調査 | 1,807 | 3 | 5 |
| 20年分以上の実調査、同じ暦月の調査 | 66 | 2 | 0 |
| 地点ごとの長期増光速度と記録率の長期変化 | 427 | 0 | 0 |

実調査20年・同月比較では Matricaria discoidea と Capsella bursa-pastoris が負方向。R. repens も −4.37 ポイントと負方向だが q = 0.073。広い群の同月比較で負方向の3種は Polygonum aviculare、Tragopogon minor、Pseudodictamnus hirsutus。補正は各問い・各対象群での両側検定に個別に適用した。いずれかの比較で補正を通った23種は解析別の探索候補であり、統合23種に対するFDRは算出していない。地点間の長期速度比較では最小 q = 0.077。年ごとの明るさと記録率の共変動から、数十年の増光による個体数の減少は結論できない。

## 開花とNDVI緑化日の比較

候補から島と本土の両側で開花時期を比較できたのは、スウェーデンの Draba verna だった。スウェーデン観測網で訓練を受けた観察者による開花開始（指定段階53、10〜20花以上が開いた時期）をMOD13Q1.061の250 m画素に対応づけた。2012、2015、2016、2017、2020、2021年の共通6年で、年ごとの絶対日数差の「島−本土」は順に −15.9、+20.2、+3.3、+19.3、+12.2、+19.9日。共通年を等しく重み付けした平均は +9.82日だった。全照合年で開花は周囲の春の緑化に先行した。絶対日数差の平均は島31.0日（ゴットランド島の2座標・6地点年）、本土23.3日（8座標・12地点年）。この2つの全照合年平均の差と、共通年だけの差では年の重みが異なる。

同じ座標の反復年で夜間光が変動したのは両側1地点ずつ。島の変動地点での絶対日数差は0 DNの2年が平均45.5日、6〜7 DNの2年が31.9日。本土の変動地点は0 DNの4年が20.8日、7 DNの1年が12.1日だった。この小標本では明るい年にずれが拡大する方向は見えず、島一般と本土の光応答差は推定できない。各地点の開花と衛星値は同じ地点・年であり、この250 m照合に元の長期GBIF調査地点と同一座標・年のものはなかった。

両側で開花開始を記録したほかの候補は Carex nigra と Epipactis palustris。250 mの品質・季節条件を満たした数はそれぞれ島0／本土0地点年、島3／本土0地点年だった。R. repens では独立した長期の粗解像度照合で本土14地点・55地点年、島0地点年。開花は植物種の地上観察、緑化日は周囲の植生画素の季節変化であり、開花と送粉者の時間的一致、結実、花粉制限は測っていない。候補に含まれるシダ Asplenium septentrionale に開花指標は適用できない。

## 分母とモデル

- 2026年11月1日版の全球GBIF全10,346分割・3,887,364,403行から維管束植物を抽出。1992〜2024年の全33年、緯度経度・年月日・種名キーがあり、位置不確実性が0〜1,000 m、所定の座標エラーがなく、PRESENTである人による観察、観察、保存標本を用いた。1月1日は精度不明の便宜的日付の影響を避けるため調査の復元から除いた。対象134,288,599行、148,786種。全種を候補台帳に残した。[GBIFスナップショット](https://doi.org/10.15468/dl.jeesns)・[59提供データセットとDOI](sources.csv)
- 調査地点は提供元・記録種別・公表座標の組合せ。同じ日の異なる維管束植物5種以上を1調査日の代理とし、重複の種記録は1回にまとめた。公表座標には格子中心が含まれる。一つの座標は複数の調査者・観察範囲を代表し得る。実測努力時間のない植物リストから推定するのは記録率である。観察者、収集方法、生育地の変化は残る。
- 調査日が20年以上を覆った提供元別地点は15,116。陸域・同年夜間光を照合できたのは14,393地点・14,328座標（島6,853、本土7,475）・67,335地点年・89,453調査日。このうち3,788地点は異なる2年のみ、実際に20年分以上を含むのは38地点。境界・湖沼など未分類の点を陸域に強制配分しなかった。GSHHG L1・L2を用い700万 km²超を本土とした。国・大陸の概要用のNatural Earth 1:50mで欧州に帰属したのは13,340座標、国境・海岸等で未帰属855座標。地域の代表性は不均一。[調査年数分布](history.csv)・[年別分母](year_coverage.csv)・[国別分布](countries.csv)・[地点区分](geography.csv)
- 種が当該調査地点で1回以上記録されれば、その地点のすべての適格な調査年を採用。年別分母はその年の植物調査日数。全調査日のモデルは1,103万1,346種地点年を含み、調査済み未記録が735万2,782種地点年、最終検出より後が312万8,831種地点年。未調査年は補完しない。その地点で全期間に一度も記録されない種を不在と仮定していない。[調査継続と未記録](surveyed_nondetections.csv)
- 全調査日の年別モデルでは、各提供元別地点年を等重みとし、種別の記録日割合（%）を、同じ地点・年の衛星光10 DN、地点・年固定効果、平均記録種数の対数、月別調査日構成で説明した。別の同月モデルでは同じ種が少なくとも一度記録された地点・月で、該当月に調査のあった全反復年を照合。地点×月・年固定効果と記録種数を使用。いずれも20座標・10情報区画以上、100 km等積区画クラスタのt区間、両側のBenjamini–Hochberg補正。光は現地照度ではなく調和済みDMSP/VIIRS DN（0–63）で、明るい画素では飽和し得る。[衛星夜間光](https://doi.org/10.6084/m9.figshare.9828827.v10)
- 長期速度は同じ月の実測5年以上・期間20年以上から年別系列の線形勾配を算出。地点ごとに月別勾配を平均し、同一座標の提供元をまとめ、同一100 km区画内で記録率変化速度を増光速度で回帰。初期光と記録種数の変化速度を調整した。光量と生育地・土地利用・気候の共変動を切り分ける因果推定ではない。
- 開花の長期照合は北緯30度以北の1992〜2014年に限り、GIMMS3g Method 4（年のNDVI振幅の50%通過）を使用。地上の開花開始は観測網固有の定義を保持。米国は最初の開花陽性と直前30日以内の陰性の中点、日本は当日有効な官署座標・正規種構内観測、スウェーデンは登録観測者による開始。ドイツ気象局の種はドイツ国内のPEP725重複を除外。属レベルの観察から種を推定しなかった。候補ごとに同一地点の光が変動するか、島と本土に共通年があるかを別々に検証した。250 m照合はスウェーデンで両側の開始観察が存在した候補を全件対象とし、観測日のNDVI・信頼度0、冬・夏それぞれ良品質2観測以上、32日以内の上向き通過を要求した。衛星画素を補間して海岸の欠測を埋めていない。[GIMMS緑化日](https://doi.org/10.1038/s41467-019-10235-8)・[NASA MOD13Q1.061](https://doi.org/10.5067/MODIS/MOD13Q1.061)
- 実測資料は [SWE-NPN](https://researchdata.se/en/catalogue/dataset/2022-86-1)、[Chronicles of Nature](https://doi.org/10.5281/zenodo.3607556)、[DWD](https://opendata.dwd.de/climate_environment/CDC/observations_germany/phenology/annual_reporters/wild/historical/)、[PEP725](https://pep725.eu/dataset/) と[草本・矮性低木の公開抽出](https://zenodo.org/records/21979471)、[MeteoSwiss](https://opendatadocs.meteoswiss.ch/a-data-groundbased/a9-phenological-observations)、[USA-NPN](https://www.usanpn.org/data)、[気象庁](https://www.data.jma.go.jp/sakura/data/)。追加でPhenObsの2019〜2023年実測開始日を候補名で照合したが該当した3種はすべて本土の園だった。英国の公開研究にはブルーベルの長期資料があるが、地域別集計を個々の定点の開花日には転用していない。[PhenObs](https://doi.org/10.5281/zenodo.15411418)・[英国の一次研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC8808087/)

## 再利用

同じスナップショットから全33年を取得したローカルDBは work/gbif_annual/annual.duckdb。obsビューは隣接するsnapshotのParquetを参照する。共用版には集計値を保存し、個別観察者や生物の詳細位置は公開していない。取得は alan_global_gbif_source.py の --annual、構築は alan_annual_survey.py、種別は alan_annual_species.py を通常と --all-visits の両方で実行し、alan_annual_trajectories.py に続く。地上開花、種名、季節差、細解像度再照合、要約はそれぞれ alan_annual_flowering.py、alan_annual_names.py、alan_annual_gap.py、alan_annual_swedish_modis.py、alan_annual_summary.py。気象庁・DWD・USA-NPN用の取得処理は同じscripts/analysis内。観測原本・照合用衛星は各提供元の引用・利用条件に従う。

全148,786種の年別結果は [期間20年](year_span20.csv.gz)・[実調査20年](year_observed20.csv.gz)、同月比較は [期間20年](screen_span20.csv.gz)・[実調査20年](screen_observed20.csv.gz)、長期速度は [全種表](long_term_screen.csv.gz)。推定不可、推定できたが判定に至らない種、正負の候補を区別する。原稿の主要結果 −1.902 と64種の花粉制限の副次結果は従来の解析を参照する。
