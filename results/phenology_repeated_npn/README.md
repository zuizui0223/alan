# Repeated open-flower observations from USA-NPN

The National Phenology Database supplies visit-level presence, absence and unknown statuses for individually monitored plants. For Nature's Notebook, the status refers to one or more fresh open flowers. The optional intensity is an ordered class for the proportion of fresh floral structures that are open. It is recorded separately from the status. [Official data portal](https://data.usanpn.org/observations/) · [USA-NPN phenophase definitions](https://usanpn.org/files/npn/reports/USA-NPN_Plant_and_Animal_Phenophase_Definitions_v2.1.pdf) · [Official status-data API client](https://usa-npn.github.io/rnpn/reference/npn_download_status_data.html).

The acquisition script reads the public species and phase catalogs, resolves plant names to accepted WCVP IDs using the same conservative unique-name resolution as the frozen analysis, and selects exact “Open flowers” phase definitions (201, 205, 210, 494 and 501). It retrieves all months nationwide in 2019, 2021, 2023, 2024 and 2025, before applying any geographic filter. The raw source is the [USA-NPN observation service](https://services.usanpn.org/npn_portal/observations/getObservations.json). Cultivation and transplant history are not determined. The 137 accepted species in the catalog are listed in species_crosswalk.csv. Some catalog species have no informative visit in these years.

The assembly script excludes unknown status and keeps only observations identifiable to an individual, date, site and valid coordinates. Concordant same-day observations of the same individual are collapsed. Discordant same-day records are discarded, as are individual-date records with inconsistent coordinates. This lets observation dates recur for different plants without treating multiple reports on one plant as repeated visits. Raw locations and individual histories are retained in the private cache. Monthly input checksums in summary.json refer to the query extracts retaining observation IDs and analysis fields.

The exact-cell table takes land class and the within-region-year relative VIIRS split from the parent historical-photo site-year table. An individual is “repeated” if observed on at least two distinct dates in that year, “both statuses” if at least one open-flower presence and one absence are present, and “bracketed” if a visit with no open flowers precedes its first open-flower record and another follows its last. The last category is an upper bound on usable flower-duration series: widely spaced checks and multiple floral bouts can still prevent precise interpretation. A region-year requires records on both land classes under both light conditions for the same species. The exact-cell check does not exclude other monitoring stations in the same 5-degree region from the separate regional analysis.

Run alan_npn_open_flowers.py with the private query-cache directory and the directory holding wcvp.zip. Then run alan_npn_frozen_support.py with that cache and the frozen phenology frame's universe.parquet. The nationwide individual_visits.parquet output in the cache is the input to the broader region-based station match.
