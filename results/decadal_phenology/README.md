# 長期夜間光・植生・動物季節暦

元の11種・3地域の開花陽性94定点（島21、本土73）の座標を固定した。各製品の実測期間のみ結合し、地上観測開始前に種の開花・動物の出現を補間しない。主要結果 −1.902、64種の花粉制限の副次結果とは別の探索的解析。

|[植生](site_year.csv)|MCD12Q2.061の500m画素の第1生育周期における春の中間緑化日、当年の日付かつgood/bestを使用。夏NDVIは前回取得済みMOD13Q1の実採用日160～240日の良品質画素が2回以上ある地点年の中央値で、長期緑化日とは対象期間・抽出量が異なる。|

[植生・繁殖の係数](within.csv)は、反復ある地点（木本は画素、開花は種×地点）の固定効果と暦年固定効果を用い、光＋島×光を推定。区間は定点（木本は画素）クラスタの名目95%。季節差は各群で種ペア×定点・暦年固定効果、定点クラスタで推定した。両論点ともDN10単位当たり。DN63の飽和、センサー交代、空間解像度と土地利用の影響が残る。[センサー期別の植生係数](sensor_eras.csv)。対象の選択は近年の開花観測に基づくため歴史的な植物分布を表さない。

同じ環境で再取得する順序は、scripts/analysis の alan_decadal_light、events、green、birds、fruit、moths、report、calendar（いずれも .py、引数 ../phenology_run）。夏NDVIと2012年以降のGBIFには前回の取得済みデータを併用する。原回答は非公開キャッシュに置く。

緑化は取得できた221/282の8年単位のリクエストをファイル名・SHA256で固定。全94定点の緑化を完備した解析ではない。春緑化日は73定点1,684地点年、開花開始日は55定点359種地点年で比較可能。夏NDVIは45定点290地点年。木本量は63画素1,071画素年。各指標で島−本土の95%区間はゼロを含む。木本量のセンサー期別推定では島と本土の符号が交代する。島の草本現存量・個体サイズを直接測った長期系列は今回結合していない。

蛾の最古の同所近傍の記録は1998年、本土・島ともにその年から連続した努力付き調査は存在しない。開花との同年一致は2016年以降に限られる。蝶3種の81組中74組が Danaus plexippus に集中し、鳥の花暦との37組はすべて Archilochus colubris。蝶・鳥の同時系列はこの照合ではすべて本土。蛾・蝶・鳥のどの群でも、同じ種ペア・定点における動物と植物の観察日中央値の差と夜間光の関係は名目95%区間がゼロを含む。[蛾の年別観察暦](moth_calendar_year.csv)・[植物との重複日](paired_dates.csv)
