# 更新した緑化日と同地点・年に限定した照合

全282取得単位のMCD12Q2中間緑化日が品質条件を満たす定点年に限った。植物と動物は元の11種・3地域の固定母集団。木本量は元の約4.63km画素内で重複する定点の夜間光と緑化日を平均し、画素年1行に戻した。蛾の成虫観察は定点を中心に緯度経度±0.025°。蝶・鳥は植物と同定点のNPN観察。動物と植物の観察日中央値の符号付き差と絶対日差を別々にモデル化した。摂食記録は餌部位を特定できないので、成熟果実との比較は代理指標である。

島・本土を分け、2年以上ある同じ種ペア×定点（木本は同じ画素）と暦年の固定効果を含む回帰を実施。誤差は定点（木本は画素）でクラスタ化。3クラスタ未満、自由度またはランク不足では区間を推定しない。予測変数は夜間光10 DN、緑化日10日、および両者同時。少数クラスタの区間は記述的で、日付は飛翔・開花ピークの推定ではない。

島の蛾30ペア地点年のうち、同じ種組合せと場所で繰り返したのは1組2年。島の蝶・鳥は照合なし。木本・緑化・夜間光・動植物暦が同時にそろうのは本土103ペア地点年、島0。島の蛾と花が重なった年は2021～2024年で、木本データの最終年2019年より後。島で動植物の季節差が広がるという経路は判定できない。木本量と光の関係、本土の動植物の絶対日差と緑化日の関係はいずれも名目95%区間が0を含む。
