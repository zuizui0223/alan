# Abonyo/Oduor2024: nutrient and competitor factorial

[Primary Methods2.2–2.3, Results3](https://doi.org/10.1111/1365-2745.14235) read2026-11-20. Outdoor Kenya experiment:17 focal species,544 pots, six illuminated and six unlit plots. Pots rotate within plots; four pots per treatment combination are not four independent lighting replicates. Models describe species nested within invasion status, but no plot random effect.

The recorded percentage changes are author-reported group contrasts, not newly fitted effects. Competition with Ocimum gratissimum and nutrient supply modify biomass responses; a negative native-plant response under high nutrients without competition changes direction with competition. Flowering fraction and flower number are not seed production or pollination efficiency. Flower counts are conditional on flowering. No plot-level variance is available, so no meta effect is adopted.
