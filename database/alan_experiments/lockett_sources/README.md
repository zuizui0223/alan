## 効果量を追加する前に解決する点

1. **４本の処理ラベルが表間で異なる。** 木ID 14・91は生物量表で暗区、Growth・PCAで
   照明区。ID 7・60は逆である。群の総数12/11は変わらないため、総数の確認だけでは
   発見できない。多数決で元ラベルを置換せず、全表の値を保存した。
2. **収穫時には23区画でも、最初は18区画を共有していた。** ５つの元区画から各２本が
   収穫対象に入る。23本を独立照明反復として分散を計算しない。初期・移動後の区画を
   ともに扱う必要がある。
3. **昆虫の解析フラグは全ての段階に共通ではない。** `Use4ALAN=Yes`の117袋には
   通常の成功104袋と`REZERO`13袋が含まれる。`FAILED=YES`33袋のうち32袋でフラグは
   欠測、１袋は`No`。117袋だけでは産卵失敗を含む分母にならない。
4. **保存済み指標と論文の定義が異なる。** メタデータでは`LERPPROD`列と論文で用いた
   指標の違いが説明されている。別の標準化列も最大値で割る、１へ切り詰めるなどの
   変換を含む。名前だけで生存率・生産率と解釈しない。

`harvest_allocation_crosswalk.csv`、`treatment_label_discrepancies.csv`、
`shared_origin_trees.csv`、`psyllid_allocation_and_flags.csv`に対応関係を保存。
位置変数にも表間の表記差があり、そのまま接続していない。

## 論文内での位置付け

これは植物の過去の照明履歴と、植食者が経験する現在の照明を分けて操作した候補であり、
植物側を通じた作用を検証するうえで有用。ただし過去の処理は親世代の産卵期も含むため、
純粋に植物だけを介する効果と同一視しない。実験は水路近くの屋外施設で、鉢の給水も
管理されている。野生湿地全般の処理差や、湿潤候補58種の減少を実証したものではない。

割付・段階別分母・移動前後の依存性を整理するまで効果量の主台帳投入は保留。
取得できたデータは保持し、結果が不都合だから除外したとは扱わない。
初回監査では効果量追加は０。本文確認は新規１報として更新した。下記の追加抽出は
移動前の補足値であり、最終収穫の保留を解除していない。

## 追加抽出：移動前の記録幹径

収穫時の表間ラベル問題は未解決である。論文Fig.2の配置図も番号を記していないため、
配置図だけで４本を修正しなかった。一方、移動前の最終観測である18週目は、
初期24区画に144本すべての正の幹径値があり、初期処理と区画の対応が確認できた。
最終収穫の代用とせず、時間窓を限定した補足効果を抽出した。

各区画６本の平均幹径を１週目と18週目で求め、
`(照明区の18週目/１週目)/(暗区の18週目/１週目)`を計算した。
各群12区画で、同じ区画の初期値と18週目の共分散を保持した。
比は**0.9656（デルタ法・t11近似95%区間0.7982–1.1681）**だった。
この期間の記録幹径の比例的変化に、明瞭な処理差は認められなかった。

病弱フラグのある６本も原コホートの記録値として含めた。フラグは死亡・矮小化・損傷・
病気を区別しないため、死亡や生存バイオマスへ置き換えない。著者の138本に限った
モデルを再現した結果ではない。区画の照明配置も無作為ではなく、市松状の系統配置。
区画間誤差の独立を仮定した記述的区間で、空間相関は推定していない。

これは同じ１実験系列の補足値で、湿潤性の効果、最終生物量、個体群成長率、
昆虫を介した効果ではない。主台帳108行へは加えない。
元の`diam_change`は絶対増加量でなく幹径の比だったため、初期値・後期値から再計算した。
原表の長さ単位は変換せず、共通の単位倍率に依存しない比を示した。
