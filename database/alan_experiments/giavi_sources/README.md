# Giavi2021：原データからの対応を保持した抽出

原著 https://doi.org/10.1038/s41467-021-22011-8 、著者データ https://doi.org/10.5281/zenodo.4540407 。公開readmeとMD5を確認したRDataを使い、`extract_giavi.R`で再抽出。原著MethodsもEuropePMC PMC7966740から取得・確認した。

12草地、6明暗ペア、37の同時調査回（各回6巡回）。1,884行は21の植物ラベルと3昆虫目に対する反復記録で、独立nではない。原著が出現回数と訪花記録数で選抜した植物に限定されたDATを使用するため、全植物・全訪花昆虫の群集総数とは呼ばない。

同じ草地の調査回ごとに選択植物への訪花数を合計し、草地内で調査回平均を取る。照明・暗区を同一ペアで並べ、6ペアを単位に各群の平均・SD・対応共分散を得た。3昆虫目とその合計の4応答を保存した。各群のlnRRは平均照明／平均暗の対数。分散は対応する草地間共分散を含む一次デルタ法、4応答間の共分散も同じ6ペアから計算した。合計と構成3目を独立効果として同じモデルへ投入しない。

全3目の訪花数は調査回当たり照明32.60、暗30.99、比1.052（lnRR0.05056、標本分散0.008428）。これは花量未調整の生の訪花数比であり、花当たり送粉効率、結実、原著の調整済みlog(1+訪花数)効果ではない。照明の有益性や機能補償の証拠に昇格しない。個別の植物に負の応答があっても選択植物を合計した値と矛盾しない。

実験設定：2016年スイスPrealpsの非管理ruderal meadow。4000 K LED、6mポール。照度は花高70cmで灯直下75.73±1.54 lx、約10mで2.67±0.19 lx（原著記載）。各草地100mの調査線。土壌水分・地点座標・EIV照合はこの抽出では未取得で、湿潤／乾燥の分類は未確定。Knop2017との地点・年重複は未解決なのでprogrammeを保守的に共有候補とした。

検証：入力MD5、各植物調査回3目の完全性、明暗で同一37回、6ペア、共分散の対称性・半正定値性を確認。別Python計算でも4応答の対応分散を`var(lit/mean(lit)-dark/mean(dark))/6`から照合し、12草地の合計が3目の和と一致した。これは計算検証であり、人による独立再抽出一致率ではない。
