Worms were replenished with three individuals per inoculated unit on day16; final survivor counts are not an unreplenished cohort survival endpoint.

Litter removal reported as0.66±0.26g lit and0.46±0.20g dark is Reimann-corrected, R=(M−m)S/M, using worm-free controls. It is not simply the gross litter loss or a control-subtracted difference. SD versus SE for these values is unspecified. Control matching and covariance are unavailable. The rounded ratio1.435 is not silently substituted for the authors'42.4% increase or assigned a sampling variance. The text's P=.049 concerns survival-associated removal within the lit treatment, not the lighting main effect or a test of differing slopes. Dark-treatment P=.271 does not by itself establish such an interaction.

The supplement contains figures and TableS1, not raw observations. `reported_respiration_tests.csv` records all four ANOVA rows: treatment P=.3000 at day29 and .4771 at day36; treatment-by-survival P=.2531 and .2559. These are unsigned tests, not zero effect estimates. Earlier time-specific respiration differences must not be substituted for a final effect selected for significance. Neither model replay nor a decomposition meta-analysis is claimed.
