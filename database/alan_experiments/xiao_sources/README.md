## 種名照合による支持範囲

一次論文Table 1の12植物種を、学名二名法の完全一致で照合した。
58減少候補・305比較ラベル（361受容種）の湿潤植物名簿との一致は０種だった。
同じ欧州EIVスナップショットで数値MOISTが得られたのは４種：

| 種 | MOIST |
|---|---:|
| Amaranthus retroflexus | 4.6 |
| Artemisia annua | 4.1 |
| Ambrosia artemisiifolia | 4.0 |
| Cenchrus spinifex | 1.5 |

Lolium perenneとDatura stramoniumは名前が一致するが値は`x`で、数値を補わなかった。
残り６種はこの完全一致では対応しない。異名照合をしていないため、これを
生態学的な不一致や湿潤性の欠如と断定しない。数値MOISTが得られた４種についても、
温室の実際の土壌水分や水面までの距離とは区別する。

したがって、この実験は今後の植物×食害の環境一般的な比較候補であり、現時点で
湿潤な減少候補58種の反応を直接検証する資料ではない。原表回収後も温室層として
保持し、種ごとの照明効果と食害による修飾を区別する。

## 次の抽出に必要な条件

植物成長実験は３明暗区画対。288鉢を独立照明反復にしない。
原表の区画ID・対応関係、死亡４鉢の配置、植物・養分・食害処理の区画内分布を
確認してから集計する。別の摂食試験は１区画対であり、そのサブ区画や幼虫数で
照明反復を増やさない。蛾の幼虫の植食と成虫の送粉を同じ応答として扱わない。

本文の座標は東経125°24′03″・北緯43°59′49″。温室の位置であり、その周囲の
衛星水面頻度を実験鉢の水分状態とは解釈しない。区画対の番号対応は図から確定できなかった。

`python database/alan_experiments/xiao_sources/audit_sources.py`で資料ハッシュと
