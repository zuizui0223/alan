最初の選別には対象を植物・節足動物の直接応答に狭めた除外があったため、野外の生存・成長・繁殖・活動を調べる脊椎動物等を分類群名だけで除外しないよう27件を明示的に再判定した。4件の波長比較も除外から別枠へ移した。初回判断は担当範囲別CSV、変更は`screening_adjudications.csv`、現行判断は`screened_records.csv`に残す。全文では対象植物との相互作用段階、群集・個体群、直接生理作用のどれかを再分類し、異なる機構を一つのメタ効果へ混ぜない。

**521は論文数・実験数ではない。** DOI完全一致による重複はこの出力で検出されなかったが、DOI欠損のPMC・AGR・preprint等がある。正規化タイトルが一致する28レコードを重複候補として別表に保存した。タイトルだけで自動統合しない。異なるタイトルの再報告・同一実験施設・同じ対照の再利用も、全文のprogramme対応で確認する。最終PRISMAの「重複除去後研究数」はまだ確定しない。

## ファイルと再現

- `europepmc_manifest.json`：取得時の検索条件・件数。`screened=0`は取得時点の状態を保持する。
- `europepmc_pages.csv`：APIリクエストと生応答SHA。
- `europepmc_records.csv`：書誌情報と出典ID。抄録本文は外部キャッシュのみ。
- `screen_*.csv`：割当範囲別の個別予備判断。`*.md`：候補研究メモ。
- `screened_records.csv`：範囲確認後の結合台帳。
- `possible_title_duplicates.csv`：重複照合待ち。
- `screening_summary.json`：現在の判断別件数、支持範囲。

```powershell
python database/alan_experiments/search_europepmc.py ../gbif_annual/alan_experiment_sources/search_20261120
python database/alan_experiments/assemble_screening.py
```

API再実行時に索引が変われば件数や順序も変わり得る。既存の選別割当をそのまま流用せず、新しい検索スナップショットとして保存・再対応する。今回の抽出・選別は既存の正の結果だけを起点とした文献一覧から、再現可能な索引検索へ範囲を拡張した段階である。全文未取得・独立性未確認のレコードから統合効果量は算出していない。
