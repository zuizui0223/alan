# Li2024: soil network evidence and recoverable sequence metadata

Reviewed 2026-11-20. DOI10.1016/j.scitotenv.2024.171129. [Publisher abstract/data statement](https://www.sciencedirect.com/science/article/pii/S0048969724012683) distinguishes incubation from a field survey. Competition/facilitation is proposed from network patterns, not established as directly measured pairwise interaction strength. Full Methods/Results remain unread; treatment allocation, incubation setting, independent lamps and network uncertainty are unresolved. Do not substitute sequence samples or network edges for lighting replicates.

[Vienna institutional metadata](https://ucrisportal.univie.ac.at/en/publications/artificial-light-at-night-causes-community-instability-of-bacteri/) links https://phaidra.univie.ac.at/o:2083459 . Retrieval returned an Anubis challenge page, not the article; no bypass attempted. Open-access metadata is not full-text recovery.

The publisher identifies PRJNA971512 for incubation and PRJNA893212 for field samples. Public ENA run metadata was recovered:200 unique samples/runs and29 respectively. These counts are archive inventory, not analytical inclusion counts or independent n. Some incubation titles encode ALAN status; exact treatment/day mapping must come from Methods/sample metadata. No sequence files downloaded and no network reanalysis performed.

Decision: full-text/design hold. No finite interaction effect added; primary-read count unchanged. Keep field and incubation evidence separate. No inference that altered networks mediate wetland-plant decline.
