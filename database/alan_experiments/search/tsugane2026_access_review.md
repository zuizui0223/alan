# Tsugane2026: community response, not verified predation

Reviewed 2026-11-20; DOI 10.1016/j.marpolbul.2026.120085.

[Final primary abstract](https://pubmed.ncbi.nlm.nih.gov/42413369/) establishes a 24-week eastern-Hokkaido subtidal settlement-panel experiment comparing white night illumination with an unilluminated control. The reported community response changes with succession; predator attraction is proposed, not established as a measured pathway by the accessible abstract.

[Publisher](https://www.sciencedirect.com/science/article/pii/S0025326X26008726) and [related SSRN manuscript](https://ssrn.com/abstract=6478623) full-text requests returned 403. Neither complete Methods/Results nor raw data was recovered. Lamp replication, treatment allocation, panel nesting, repeated-measure covariance and terminal means/dispersion remain unverified. No finite effect is extracted; no full-review count increment. Do not substitute panel count for independent illumination replication or use an early significant time point as the prespecified terminal response.

The publisher preview identifies GAME 2023 as project context. Shared programme context is an overlap-check lead, not proof of shared experimental units. SSRN is a related-version lead, not an independent experiment. Final version reconciliation remains pending.

A separate agent independently confirmed the access and design limitations; this is not independent human re-extraction. Retain as potentially eligible community-response evidence, not a verified predator-mediated effect or wet-versus-dry contrast.
