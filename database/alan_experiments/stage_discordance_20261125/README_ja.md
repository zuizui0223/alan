## 定義と原資料

各測定指標 j の照明応答を RR_j = mean(lit)/mean(dark) とし、同一区画を測定した2指標の段階差を log(RR_j) - log(RR_k) とする。Var(diff) = Var(j)+Var(k)-2Cov(j,k)。比の比は測定指標の相対応答差であって、実際の捕食率や資源移送効率ではない。

Parkinson2016 (DOI 10.1371/journal.pone.0240138): 著者の固定commit 6985359fd29dfe321c740691bf97ea9d564db769 の Aquatic and Terrestrial Invertebrate Inputs.csv を新たにconnector経由で取得、Git blob 4e2b7065d67e0604ca121ea26c96b5db6d64de94 を確認。既存の独立抽出20メソコスム unit_values.csv (blob bcd72974776d1e3f46056bab525aa98eb3813f85) と ID、照明処理を全20一致させた。著者集計値、36科再集計、Ephydridae除外、さらに優占Caenidae除外、Caenidae+Leptoceridae除外の5条件×最終日/3観測日平均。後者2時点のクモ指標は独立データではない。10明/10暗の多変量デルタ分散、便宜的保守 t9、4指標6対比のBonferroni同時区間（各選択条件内のみ）。元の魚操作の割付は未回収。1泊pan捕獲とクモ観測窓は異なる。未測定の捕食率に換算しない。

Sullivan2013 (DOI 10.1002/eap.1821): 既存原データ認証済みの3物理ブロック×4照明色の凍結lnRR JSON (blob 349ecebb168f1bfdaedf533c7066a764d69c4f89) を読み、色ごとの平均とSEを全12対比で再照合。色等重み、同じ3ブロックにおける3指標の完全な標本共分散を推定。t2と3対比Bonferroni区間、全4色leave-one-out。今回新規Dryad原TSV取得はDNSで失敗。既存原データ由来値の再解析であり、Sullivanの優占Chironomidae除去は未実施。実験内反復を研究数へ水増ししない。

## 結果：水生昆虫の過大な相対応答は優占科に敏感

| Parkinson2016（3日平均のクモ指標） | Ephy除外 | 加えてCaenidae除外 | 加えてLeptoceridaeも除外 |
|---|---:|---:|---:|
| 水生起源捕獲の照明/暗比 | 6.652 | 3.513 | 3.544 |
| 水生捕獲/陸生捕獲の比の比 | 5.125 [1.667,15.757] | 2.706 [0.964,7.596] | 2.731 [0.966,7.718] |
| 水生捕獲/クモ個体数の比の比 | 3.303 [1.443,7.559] | 1.744 [0.828,3.674] | 1.760 [0.829,3.736] |
| 水生捕獲/網内獲物の比の比 | 2.773 [1.311,5.865] | 1.464 [0.761,2.818] | 1.478 [0.771,2.833] |

区間は6対比の各条件内Bonferroni 95%。除外前には3指標の水生捕獲との差が区間上も明瞭だが、優占Caenidaeを除くとすべて1を含む。符号が消えるわけではなく、点推定と精度が減衰する。最終日の水生捕獲/網内獲物は除外前でも補正区間を跨ぐ（2.252 [0.606,8.376]）。時点選択・科除外は事後の感度であり、全探索を通じた確認的多重性を制御していない。

Sullivanは水生羽化トラップ捕獲2.587、陸生節足動物捕獲1.045、クモ網数0.353。水生/網数の比の比7.322（未補正t2 1.465–36.588、3対比補正0.419–127.850）。陸生/網数2.960（補正0.092–95.053）。4色leave-one-outの水生/網数点推定5.892–9.651。Parkinsonではクモ数が増え、Sullivanでは網数が減るが、クモ数と網数を同じ効果とみなさない。両研究に水生資源の相対的増大の候補はあるものの、同じ捕獲方式・同じ捕食関連指標ではないためメタ統合しない。

## 独自の次段階

同一実験内で A=水生起源の飛翔捕獲、E=羽化トラップ、W=網構築、S=クモ個体数、P=網内獲物、I=実際の摂食、F=花粉送達・繁殖を分離し、同一測定定義の log(RR_A)-log(RR_E)、log(RR_P)-log(RR_A) 等を別々に統合する。比較可能な2以上の独立プログラムと対応共分散が揃ったレーンのみ探索メタを実行。優占科を一律の事前規則で感度分析し、非同調の大きさが分類群構成に依存するかを検証する。今回の結果は候補形成で、湿潤植物の因果的媒介や代替送粉の実証ではない。
