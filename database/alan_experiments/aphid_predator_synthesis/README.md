# 捕食者によるアブラムシの照明応答の変化：探索的メタ解析

2026-11-20。自前抽出した２実験系列から、捕食者あり・なしの照明応答を比較した。
湿潤種の偏りの主マクロ結果、108効果量の台帳、最終採択の未了状態は変更しない。

## 推定対象

`(捕食者ありの照明/暗区比)/(捕食者なしの照明/暗区比)`。
応答はアブラムシの計数である。比が１未満なら、捕食者ありの処理で照明応答が
相対的に小さいことを示す。直接測定した捕食率や、植物への媒介効果ではない。

Penrynは琥珀色と白色の２対比、Miller2017は非加温条件の捕食者C7とCMの２対比を
それぞれ対数尺度で等重み平均した。したがって実験ごとの照明・捕食者構成に関する
平均であり、同じ捕食者種・照度・光色に統一した比較ではない。４対比を４研究に
数えず、共有暗区・共通の捕食者なし群・区画対の共分散を保持した。

## 結果

| 実験系列 | 応答比の比 | 近似95%区間 | 対比の集約 |
|---|---:|---:|---|
| Penryn | 0.902 | 0.0564–14.40 | 琥珀色・白色、各セル６区画 |
| Miller2017非加温 | 0.602 | 0.1207–3.003 | 捕食者２種、４対応ブロック |
| ２系列の探索的統合 | 0.648 | 0.00194–216.05 | REML・修正Knapp–Hartung、自由度１ |

系列別区間はそれぞれt5・t3、統合区間はt1とmax(1,q)に基づく。
統合の研究間分散推定値は０だったが、２系列だけで同質性が確認されたことを意味しない。
元の４対比には、Penryn琥珀色の１を上回る点推定も含めた。統合区間は１を含み、
捕食者の存在によって照明応答が一貫して小さくなるとは確定できなかった。
効果が存在しないと結論する結果でもない。

## 原資料・選抜範囲

- Penrynのアブラムシ数は３分間の探索計数で、2013-09-12は最初の報告の最終観測日。
  実験系列全体の終了日ではなく、回収済みの2014-2015年追跡とは区別した。
  最初の報告を採用する規則で保持し、長期最終効果とは呼ばない。
- Millerは導入９日後のケージ内計数。加温条件の割付不一致を推測で修正せず、
  完全な非加温24ケージを用いた。加温による効果を推定していない。
- 探索計数と全数計数の比較は、処理間の相対的な検出の違いが効果を生まないとの
  仮定を要する。捕食者回収の不完全性、実験期間・宿主植物などの違いも残る。
- Penrynの後年の植物生物量・ナメクジの期間平均は同一系列で測定されており、
  別の独立研究としてこの統合へ加えていない。被食者数と植物生物量を混ぜていない。

湿潤性・水面距離・島と本土による効果差、蛾の捕食、送粉機能をこの比較からは推定しない。
これは最終採択前の補足メタ解析であり、主要な機構が解明されたとの主張には使わない。
