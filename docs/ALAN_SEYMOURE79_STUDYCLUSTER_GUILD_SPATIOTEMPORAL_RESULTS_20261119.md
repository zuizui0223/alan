## 1. ギルド差の大きさを数量化した場合

原研究の4フラグのうち「強度減少」「強度増強」の二つを使う。増強と減少が両方記録される場合は混合として分離し、一方だけを**厳密な二値方向**と見なす。原表が示すのはレビュー著者による分類であり、実験の同一効果量を同じ尺度で測ったものではない。

| 元レビューの相互作用 | 増強だけ | 減少だけ | 両方向 | いずれも記録なし | 全行 |
|---|---:|---:|---:|---:|---:|
| 捕食者―被食者 | **19** | **13** | 2 | 21 | **55** |
| 植食 | **2** | **7** | 0 | 3 | **12** |

厳密方向の行だけの**増強対減少のオッズ比は5.115**。原研究を1文献の単位で扱う2×2表 `[[19,13],[2,7]]` の両側Fisher正確検定は**p=0.06695**（探索的・多重検定未補正）。**有意な普遍的ギルド差を確証したとはいえない**。また、捕食者―被食者55件と植食12件に共通論文はゼロなので、少なくともこの2群の文献ID重複はない。

別の記述指標として、強度の方向スコアを論文ごと `+1 = 増強だけ, −1 = 減少だけ, 0 = 両方または未記録` と定義。捕食者―被食者 **+0.1091**、植食 **−0.4167**、差 **+0.5258**。各群から**独立論文単位**で7,999回再標本化した記述的95%パーセンタイル区間は**[+0.0333,+0.9788]**。Fisherとの見かけの違いは**分母に「両方・未記録」を含むか否かが異なる**ためであり、片方だけを採用して有意性を主張しない。ゼロは生物学的に「変化なし」ではなく、元原表の両方向・非記載を含む便宜的コード。

空間27・時間7、空間と時間の差は**20/79 = 25.3パーセントポイント**。Discordant pair（24対4）に対する探索的McNemar正確検定は**p=0.000180**。これは**同一資料で空間のミスマッチがより多く分類された**という統計であって、空間的な機構が時間的な機構より強いというランダム化された因果比較ではない。ほとんどの研究は時間軸を直接測定していない可能性があり、元レビューでは「非記載」と「実証的な不在」は区別できない。

## 3. 研究年・方法の組成を考慮すると、ギルド差は縮小

原データの出版年をそのまま使い（照明処理年ではない）、2020年より前／2020年以降を事後的に分割した。

|  | 2020年より前 | 2020年以降 |
|---|---:|---:|
| 独立論文数 | **35** | **44** |
| 捕食者―被食者 | 29 | 26 |
| 捕食者の増強だけ／減少だけ | **14／6** | **5／7** |
| 植食 | **2** | **10** |
| 植食の増強だけ／減少だけ | **0／2** | **2／5** |
| 元method記載がある独立論文 | **9** | **7** |

ギルドごとに `(増強だけ−減少だけ)/全相互作用` とした記述スコア差（捕食−植食）は**2020年前 +1.276**、**2020年以降 +0.223**。古い時期の植食は2件しかなく、年度条件付き相互作用の統計的な再現性は不足する。これはALANの生態学的影響が時代とともに変化した証拠でも、ギルド×年の因果交互作用でもない。収録生息地・手法・捕食者と被食者の分類群の変化で説明される可能性がある。

**原資料の追加品質情報**：出版年は1991:1、1996:1、2012:2、2014:3、2015:3、2016:5、2017:9、2018:4、2019:7、2020:15、2021:14、2022:14、2023:1で、**2022-12-21検索のレビューにも「出版年2023」1論文が元表に含まれる**。このメタデータを恣意的に2022へ修正しない。原著本文の「2020年以降46論文」と元原表の**44論文**にも差が残り、著者の掲載年の扱いなどを再確認するまで両者を別に報告する。

**方法情報が極端に不足**：元表の `method` 欄が空白なのは**81相互作用中65件**、研究単位では**79中63論文（79.7%）**。捕食者―被食者55件では40、植食12件では11、送粉6件では6が空欄。したがって、空白研究を「非実験」とは呼べないし、記載16研究だけを使って「操作実験の効果」を代表させることもできない。各原著への独立照明区画・測定段階の紐付けが先。

## 4. 修士論文／投稿研究の位置づけ

前回mainの確定結果は**ALAN増加地点で長期記録率の低下候補に湿潤植物が多い**という種群構成であり、相互作用メタ効果ではない。今回の原レビュー再集計は、ALANが多種の相互作用の遭遇率や機能に及ぼす影響が**条件依存である可能性**を定量的に整理するのに有効。

次に一段強い主張へ進むには、**元の照明操作独立区画と生物学的に同じエンドポイントを持つ原研究**（訪花・花粉受領・網獲物・種子出力）を別々に揃える必要がある。現時点で「世界で空間ミスマッチが時間より強い」「捕食者が植物を守る／損ねる」という因果的メタ係数を提出しない。
