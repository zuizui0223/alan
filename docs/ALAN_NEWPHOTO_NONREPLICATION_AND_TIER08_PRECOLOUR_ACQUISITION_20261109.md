# ALAN｜独立写真での再現不成立とtier08次期実データ取得（2026-11-09）

## 結論を区別する

ALANの2026-11-08 historical-mainは、実際に撮影された花領域の白色ROIと同年VIIRS人工夜間光の空間的関連について、島面積の交互作用が正であることを示した（大陸海岸距離調整後、島均等モデルで厳格44島 +5.384 pp、名目95%CI [+2.678,+8.089]；広義95島 +2.939 pp、CI [+0.833,+5.045]）。この結果は**実測上の肯定的観測結果**であり、光が白い花を選択的に失わせたという因果性は示さない。

2026-11-09に**本当に異なる観察UUIDと写真IDを持つ**tier06 8,942枚＋tier07 27,507枚について、73の署名つき原本写真ROI9測定結果を復元した。36,449枚中13,842枚が真正9色測色成功、22,607枚が技術的unknown。厳格基準（5写真試行、3真正測色成功、3実測受理種）では**1,137のユニーク島嶼撮影セル×年、75島**。独立した島内2撮影地点・夜間光の違いがあるのは35島・1,089セル×年。

**独立新規写真の面積×夜間光は正に再現しない**：島均等・海岸距離と気候/人口/観測年調整済みで **−1.0905 pp**／島面積10倍（名目CI [−4.3333,+2.1523], p=.4990）。セル均等では −0.2890（CI [−2.7186,+2.1406], p=.8104）；最大島除外は −1.3126（CI [−4.9489,+2.3237], p=.4679）。全て非有意であり、新規標本が反対方向の因果効果を証明するわけでもない。**既存の正の効果を別標本まで普遍化できるという主張は現在未支持。** 独立した植物個体群・native判定・夜行性送粉は観測されていない。

## 次の科学的問い

**「島が小さいほど人工夜間光への白色ROI勾配が負に見える」という旧写真記録の傾向は、地理的・種組成的・撮影機会的に比較可能な標本で成り立つか？ どこまでが取得設計依存か？**

これを評価するためには、旧/新の同年×同島×同種共有範囲、撮影観測者・月・季節・accepted taxa、VIIRS/WorldPop・面積分布・相対写真採用率、島ごとの実測成功率、真正夜間光勾配と島面積の共通サポートを事前に監査する。写真が多くても光勾配のない島は面積交互作用を識別できない。

## 次の取得：93.2m既存原本写真インデックスの独立tier08

既存の著作権配慮済みMOISの**source metadata-only** release \`mois-complete-93209351-original-photo-target-tiers-v1\` から、従来tier06・tier07と互いに排他的な**tier08**（観察UUIDハッシュ確率区間 [0.0256,0.0512)）の16個の原本tarを読み、署名つきSHAを厳密照合。旧canonical 1,032,882観察UUID、tier06 8,942 UUID、tier07 27,507 UUIDを全て除外し、各新UUIDに対し**花色を見ないハッシュ**で元写真IDを1枚決定する。GSHHG島、WCVP accepted taxa、2019/21/23/24/25同年**既存観測セルに実数がある**VIIRS、WorldPop、気候・標高を突合。未知の場所へ環境数値を補間することも新色ラベルを生成することもない。

取得候補の２つの**互いに重複のない標本枠**：

1. **参照枠**：条件を満たす元UUIDから、地理・花色を見ないSHA順で256件（対照枠を除いた母枠の条件付きハッシュ抽出）。無作為な世界植物相の調査ではない。
2. **対比枠**：同じ島・同じ観測年の異なる0.05°撮影地点２か所で、実測同年log(1+VIIRS)に**0.05以上の差**がある島を事前選別。各地点は少なくとも**10枚の元写真機会と4 WCVP accepted taxa**を保有すること。面積の小・中・大の各第三群から最大12島、各地点最大12枚。撮影数・受理種数は実測ROI成功とは別で、真の測色が失敗したらそのままunknownとする。

tier08は**画像の取得前に原本写真UUID、地点、選択方式を固定する段階**である。新しく数値ROI9が得られた、あるいは旧効果が再現した、とはこのワークフローが成功するまで（および将来RGBジョブが真正成功するまで）決して主張しない。新UUIDの全適格母枠、色盲参照256件、対比枠件数、対象島・年と原本SHAをActions artifactに保存する。

**解釈の注意**：撮影ROIは生体花弁の色を同定するわけではない。VIIRS衛星上向き放射輝度は花の夜間照度とは異なる。夜行性送粉の減少も生物学的な種交代も直接には測れていない。色を見た後で「都合のよい島だけ」を追加することを避け、成功しない写真も台帳に残し、島・撮影セルを独立な単位として扱う。
