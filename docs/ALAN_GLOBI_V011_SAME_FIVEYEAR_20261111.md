# GloBI v0.11で蛾訪花植物を更新した同地点・同モデル検証

2026年11月11日。固定済みの[5年主要結果](ALAN_GLOBI_PRIMARY_RESULT_FREEZE_20261111.md)について、元の地点年・種数の分母・夜間光・共変量・重みを保ち、記録源と種名照合を更新した。主要結果を得た旧定義では島−本土の傾きの差が −1.902 pp、v0.11の記録と一意に解決できたWCVP受容種では +0.750 ppだった。新推定の95%区間は −1.076～+2.577。新旧の応答差を同一設計に回帰した係数変化は +2.652 pp［+1.021, +4.282］。単位はいずれも log(1＋同年VIIRS) あたりの構成割合のポイント差。

|---|---:|---:|---:|---:|---:|
| GloBIの種集合全体・新旧とも同じWCVP照合規則 | 1,980 | 1,440 | 1,093 | 347 | 887 |
| モデルに実際に出現した種・新旧とも同じWCVP規則 | 1,166 | 744 | 619 | 125 | 547 |
| モデルに実際に出現した種・公表済み旧ラベルからの変更 | 1,325 | 744 | 612 | 132 | 713 |

元の分母には8,581受容種が含まれる。公表時のラベルから更新すると、分子の種数が増えた地点年は637、減った地点年は4,708、同数は5,353。記録上の入れ替わりにはデータ源、抽出規則、分類解決の変更が含まれる。植物や送粉者の生物学的な出現・消失を意味しない。

## 出典と照合

SHA256固定の[GloBI v0.11完全走査](https://github.com/zuizui0223/alan/actions/runs/42924993614)で全24,453,954行を処理し、既存の植物・鱗翅目・科・植物二名法の抽出条件に適合した蛾の訪花・送粉関係10,195行から、全出典込みの陽性名1,651を取得した。両向きの関係を含む。旧版は蛾7科・蝶5科の61,967件から蛾陽性名2,362を取得したもの。v0.11で旧定義の全対象が保存されるという包含関係は仮定しない。

元写真の分類照合と同じKew WCVPアーカイブ（SHA256は入力目録参照）で種階級の学名を完全一致させ、異名を含め候補がすべて同じ受容種IDを示すものを採用した。旧1,996名、新1,441名が解決。未解決は旧366名、新210名。これらを解決済みの種に割り当てず、各名の判定を記録した。公表時の旧照合は写真側のWCVP受容名と旧訪花植物名との一致であり、比較表では旧ラベルそのままの系列と双方に同一WCVP規則を適用した系列を区別した。

## 同一設計の確認

元解析の地域・年内の島本土均衡重み、地理ブロッククラスタ分散、t区間を用いた。対象は2019・2021・2023・2024・2025年、島933＋本土9,765地点年、195の年×地域、78空間ブロック。全地点に新旧分子を付与した後、同じ行から全推定を算出した。再構成した旧係数と区間は公表原表に小数点以下10桁以内で一致し、各年の5係数と区間も個々に照合した。v0.11の推定値と標準誤差は195固定効果を明示したWLSで独立に確認した。非公開の元地点年ファイルそのもののバイト一致は検証していない。最終モデルの地点キー集合のハッシュを結果に保存した。

| 蛾ラベル | 島−本土の傾き（名目95%区間） |
|---|---:|
| 旧公表ラベル | −1.902［−3.706, −0.098］ |
| 旧記録・一意WCVP解決 | −2.006［−4.095, +0.084］ |
| v0.11・一意WCVP解決 | +0.750［−1.076, +2.577］ |
| v0.11・同名候補に唯一の受容名があればそのIDを優先 | +0.392［−1.248, +2.032］ |
| v0.11・旧公表時と同じ受容名直接一致 | +0.464［−1.064, +1.991］ |

旧公表ラベルからv0.11へ更新したとき、本土の傾きは +1.374 から +0.006、島の傾きは −0.527 から +0.756。データ更新後も負の島−本土差が再現するという支持は得られず、正の差も新しい区間では識別できない。

## 再実行

入力照合は `config/alan_v011_fiveyear_input_sha256.json` の全ファイルに適用する。入力フォルダ名は同目録に従う。写真・WCVP対応表・放射輝度・人口は[元のALANデータ取得仕様](../.github/workflows/alan-native-fiveyear-replay.yml)を使用。MOIS run 41976552977 の旧GloBI表、ALAN run 42924993614 のv0.11種名フラグ、Kew配布の `wcvp.zip` を加える。年別の光・人口データから既存の年×セル×陸塊キーを回収する。2025年は当時の既知陸地の数値表におけるセルの一意性を使用する。

```sh
python scripts/analysis/alan_globi_v011_same_fiveyear.py INPUTS SIGNED OUTPUT
```
