# Giavi12草地：JRC水面背景の実データ抽出

2026-11-20。公開済み12地点座標から、JRCラスタの値を取得して `database/alan_experiments/giavi_landscape/giavi_water_context.csv` に保存した。**2016年の同年環境ではなく、1984–2024年の長期景観背景**である。実験後の年を含むため、2016年の事前共変量としてそのまま因果調整に使わない。主結果・本体効果表は変更していない。

## 版と取得経路

既存scriptsとdatabase内でJRC抽出コードを検索したが、今回の座標抽出に再利用できるコードは見つからなかった。隣接キャッシュのfreshwater_yearlyは別地域の表で、12草地の原画素ラスタではない。

[JRC公式配布ページ](https://global-surface-water.appspot.com/download)を確認したところ、現時点ではv1.5を推奨し、旧v1.4のoccurrenceおよび2016–2021年の年次水面判定の修正を案内している。そこで旧版を黙って使用せず、v1.5 occurrenceを採用した。公式リンク先の公開オブジェクト一覧から該当タイルを確認し、HTTP Range応答206を検証した。

原URLは `source_manifest.json` に保存。[取得した10度タイル](https://s3.waw4-1.cloudferro.com/swift/v1/global-surface-water/download2024/Aggregated/VER1-5/occurrence/occurrence_0E_50N_v1_5_2024.tif)のLast-Modifiedは2026-11-10、全体サイズ41,967,829bytes。必要範囲だけを元画素のまま読み、リポ外 `../gbif_annual/alan_experiment_sources/giavi_landscape/occurrence_v15_1984_2024_swiss_subset.tif` に保存。部分画像SHA256は `8f2e686011b4178bb28316f1dca80ff3c9b4a19311a99fc44f849119aec1fd9e`。これは取得部分のハッシュであり、未取得の全タイルのSHA256ではない。元URL、ETag、範囲要求、元ウィンドウ、取得範囲、版を再現用に保持した。

EPSG:4326、0.00025度画素、公称30m。当地の画素は約19.1m×27.8mになる。距離はSwiss LV95（EPSG:2056）に変換した画素中心で計算した。元TIFFのNoDataタグは未設定だが、[公式Data Users Guide](https://storage.googleapis.com/water-world/downloads_ancillary/DataUsersGuidev2024_v.5.pdf)の値255を明示的に欠測とし、0は検出水面なしとして区別した。0–100/255以外の値がないことを確認した。

## 計算した変数と支持条件

- 地点のoccurrence、半径100/500/1000m内の面積加重平均occurrence、および検出水面割合。
- 検出定義はoccurrence>=1%と>=50%の2通り。前者はわずかな過去水面検出も含み、後者を「永久水面」とは呼ばない。
- 最近接検出画素の探索は半径5km。探索域を完全に覆う取得範囲と欠測の位置を確認する。検出できない場合は距離0や無限大でなく、5km右打切りとする。
- 比率は有効面積95%以上で計算する。実際には12地点すべて探索円内の有効画素率が100%だった。
- 原座標は100m調査線を代表する地点であり、線の方向・端点が不明。距離に±100mと画素半対角長約16.9mを加えたシナリオ範囲を併記した。これは測定誤差の信頼区間でも、GPS精度の推定でもない。

## 抽出結果

| 項目 | 結果 |
|---|---|
| 12地点の点occurrence | 全地点0% |
| >=1%水面の5km内距離 | 11地点で35.4–4690.0m、1地点で右打切り |
| >=50%水面の5km内距離 | 9地点で425.7–4993.0m、3地点で右打切り |
| 500m内>=1%検出水面割合 | pair1暗区4.0595%、ほか11地点0% |
| 欠測・取得端による距離保留 | 0地点 |

ここで0%は**この分解能・期間・閾値での地表水検出**である。土壌が乾いている、湿性植物がいない、小河川や樹冠下水面が存在しない、という意味ではない。点occurrenceは全地点同じなので、それ自体を12地点の効果修飾を説明する変数にできない。500m水面割合もほぼ1地点だけの対比であり、広い湿潤勾配を網羅したとは言えない。反応との関連モデルは今回計算していない。

## 2016年同年データのアクセス境界

修正版の公式GEE assetは `projects/global-surface-water/assets/GSW1_5/YearlyHistory_2016_2021`。今回確認した公開GeoTIFF一覧は集約製品および近年のMonthlyHistoryであり、修正版2016年の直接ファイルを確認できなかった。公式ページは旧FTPに修正版年次データがないことも説明する。旧FTPディレクトリへのアクセス自体は成功したが、既知の修正前2016データを無断で代用しない。GEE経由での認証付き計算は今回実施していない。

したがって2016年水面割合・同年最近接水面距離は**未計算**のまま残す。長期occurrenceを2016年と表示しない。次は修正版年次分類への正式な解析アクセスを確保するか、この12地点解析を長期景観背景に限定する必要がある。

`extract_water_context.py` は実行・キャッシュから再実行済み。12地点、一意ID、元座標、NoData判定、取得域、距離打切り、部分画像ハッシュを確認した。EIV MOISTとの結合や湿潤／乾燥への自動分類は行っていない。
