## 研究の設計

- 元のGlobal GBIF DWCAによる2013–2025年の昆虫の写真記録（蛾＝Geometridae＋Noctuidae、チョウ＝Nymphalidae＋Pieridae）と、ヤモリ類＋Scincidaeの写真記録を、同じ物理的GSHHG島・同じ年・同じ0.05度格子で突合。観察年より前の本物のLi–Cao PCNL v3年別画像を使う。
- 二資料に同じ島・年・格子の記録があるのは17,944件。元画像の前年光量と島内判定が双方で一致するのは15,255格子年（431島）。
- 先の空間モデルに使った昆虫写真≥5件、同じ島年のヤモリ・スキンク両記録、島年内に光変動≥0.02を満たす母集団は3,424格子年・50島・209島年。
- 今回さらに同一0.05度地点を2年から撮影し、その地点で過去のPCNLのlog1p値が0.02より大きく変化したものに限定すると、**454同一地点・1,979地点年・30島・181島年**が残る。
- 応答は蛾2科の「写真記録割合」、説明軸はヤモリ対スキンクの「写真記録割合」×前年PCNL。元の写真件数を調整。**地点固定効果と島×年固定効果の両方**を使用し、島単位で独立なクラスタCIを算出。元の生物の個体数や蛾捕食・送粉を観測したわけではない。

## 新しく完了した正・負の対照：同じ格子年で動物写真割合を並列解析

元の13年の昆虫・爬虫類ソースを独立に年前年PCNLとSHA照合し、「ヤモリ写真割合」と「蛾写真割合」を**それぞれ独立した被説明変数**として推定。これは直前の交互作用モデルと同じ資料を利用し、独立した別調査の再現ではない。説明変数は光に加え昆虫・爬虫類の写真件数、島×年FEを調整。真の同一地点モデルには同じ格子FEも吸収した。

| 応答 | 元の50島・3,424格子年の空間比較 β（95% CI） | 同じ格子454地点・30島・1,979格子年の時間比較 β（95% CI） |
|---|---|---|
| **ヤモリ／（ヤモリ＋スキンク）写真構成比** | **+3.049 [+0.384,+5.714], 名目p=.0258** | **−12.314 [−26.950,+2.323], p=.0960** |
| 蛾／（蛾＋チョウ）写真構成比 | −0.178 [−1.886,+1.529], p=.8346 | −3.533 [−17.437,+10.371], p=.6073 |

50島のヤモリ写真空間係数は以前の153島の正の空間関連（+3.267）と方向が整合する。だが、その50島のうち**反復年のある30島だけ**に空間モデルをかけると+4.758 [−5.651,+15.168]、p=.358となり不確実。30島の同一格子時間効果は島均等では名目p=.096、地点年均等では−7.865 [−14.067,−1.662]、p=.0147と源の重み付けに敏感。これらを「年々光がヤモリを減らす」と採用しない。**空間比較50島と時系列30島は異なる条件付き母集団であり、係数の符号差を真のSimpson逆転や時間的進化とは主張しない。**

蛾写真割合については空間・時間どちらも信頼区間がゼロをまたぎ、ヤモリによる生物学的な蛾消失・行動変化・実際の捕食・花粉制限増加を示さない。
