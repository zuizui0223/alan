# ALAN A：夜間送粉依存度×繁殖効果の単一係数プロトコル（2026-11-15）

## 実施状態と透明性

本稿は2026-11-15時点の既存結果（Knop負、Macgregor正、Li正、Lu負など）を見た後に固定した、将来の新規抽出に適用する **post hoc / prospective-to-extraction protocol**。過去にさかのぼる事前登録ではない。既存の「5経路」プロトコルを削除せず、中心仮説Aのみを階層上位の確認対象として狭める。本文と効果量台帳の改訂時は、公開した日・理由・既存結果を閲覧済みかを記録する。

**中心主張**：「光に対して有効送粉能力が低下する夜行性昆虫に、繁殖が限界的に依存し、昼の送粉・自律自殖・他の有効送粉者という冗長経路が乏しい植物ほど、人工夜間光（ALAN）による実際の繁殖低下が大きい」。島の属性そのものを因果処置とせず、島嶼での経路構成の差は別データBで記述してCの予測へ使う。

## A：主要推定対象と反証

- **独立割当を尊重した単位**：独立した夜間照明処理／暗所処理の実験 × 植物種（複数灯色・複数時期・複数種で論文・対照が共有される依存を保持）。論文数 ≠ 実験数 ≠ 花数。
- **単一の確認的繁殖アウトカム**：当初に標識した花のうち、種子を含む成熟果実を形成した割合（flower-level successful fruit set）。照明／暗所の同一定義・同期間・同一母集団に限る。主効果量 y = ln(p_lit/p_dark) とする。完全な二項成功/失敗があれば分散と実験クラスタを復元する。0イベントの恣意的な置換はしない；連続性補正0.5の感度分析と二項階層モデルを別途報告する。
- **予め分離する二次アウトカム**：初期標識花（または明記した初期花蕾）当たり成熟種子数、当初割当個体当たり総種子数、果実当たり種子、花粉・訪花、開花日、幼虫食害。それぞれ同じ測定分母で別パネル。果実/花と「1個以上種子/個体」は同じ二項指標と断定しない。観測種子とモデル推定種子も混ぜない。訪花・花粉を同じ従属変数に連結して独立実験数を増やさない。
- **主要調節変数1個**：V = 1 − D/O（暗所での昼だけアクセス D による結実成績／終日開放 O）。直接昼夜排除から推定する「夜間アクセスの限界的寄与」。Dには自殖と昼の有効送粉という代替能力が含まれるため、それらを重複して別説明変数にしない。D/Oが負・>1のときも元データを保持し、Vを0–1に無断切詰めしない；O=0は未算定。
- **夜行性昆虫への帰属ゲート**：Vは夜間「すべての」訪花者の寄与なので、同種・地点に夜間の有効昆虫送粉の一次資料が必要。コウモリやヤモリが主要送粉者なら「昆虫へのV」とは呼ばない。蛾媒らしい花形、GloBI訪花、夜咲きラベルだけでは帰属不可。
- **光感受性ゲート**：夜行性昆虫が「光に弱い」はVからは出ない。独立した活動／有効送粉実験から光への感受性の方向と照度・波長を記録する。未測定なら「夜間依存の効果修飾」という限定命題として推定し、光感受性を実証済みと表示しない。
- **独立性と地理のゲート**：Vを照明効果の y を見て割り当てない。優先は同種・同集団・同繁殖期の暗所排除（照明比較の成果から独立した測定）。他国・別年の同名種のVは「種レベルの外挿」として別の探索的感度解析に分離。学名の属一致・類似シンドロームだけから数値Vを代入しない。欠測Vは不明であり0ではない。
- **単一の係数**：y_ij = α + β_V V_ij + u_研究 + u_植物系統 + ε_ij（実験割当／共有対照の誤差共分散を保持）。確認予測は β_V < 0。照明色、島・本土、捕食者、開花時刻を確認モデルに入れて自由度を消費しない。高V群で精密な中立・正が繰り返されれば単調な負傾向仮説を弱める。ただしCIが0をまたぐだけでは棄却・支持とも断定せず、意味ある負効果を排除する精度と不均質性を検討する。
- **修飾と因果性の区別**：Vは無作為化されていない。ALANが無作為化されても、種間β_Vは原則、相関的な効果修飾。種・地域・灯具の混同、種子生産への植物生理効果やフェノロジー効果は代替説明。

## 組み入れと除外を、効果の符号を見る前の手続きとして固定

**対象**：全年度～2026-11-15、言語制限なし、査読論文＋明記されたプレプリント。陸上被子植物に自然暗所と夜間人為光の直接操作比較があり、独立した照明割当単位と生殖成績の分母が復元可能な研究。花単位の果実成立はA主要、種子数は二次。非ランダムな照明配置は割当可能な準実験として別デザイン感度。意図的に望ましくない符号を除かない。

**除外**：昼間UV-Bだけ；照明を操作していない都市化／天空光勾配；訪花／柱頭花粉／蛾活動だけ；形態・花色・開花日のみ；胚珠当たりなど処理後の成功果実に条件付けた種子計数を初期花全体の成果と偽る解析；昆虫以外の繁殖だけ。プレプリントは除外しないが出版状態を独立に表示。純粋な照明効果でない観察研究はB/背景用に台帳へ残す。

**重要な誤差管理**：照明を割り当てたサイト／ラン／花株を区別し、同一論文・同種・同実験対照の依存を処理する。光色と光の配置は別処理だが独立論文ではない。成功後に条件付けた種子数、幼虫食害で消失した種子数、0除数、実験前に存在した蕾数と開花花数、交換可能性、照明の隣接暗所スピルオーバー、照明設置地点数を抽出。未報告SEを公表の方向・p値から捏造しない。

**最小解析可能性**：独立研究クラスターk<3では論文ごとの効果。kが十分であってもVの変動・同じ分母・外部由来Vが不足すればβ_Vは推定しない。「10論文」は便利な作業目安であり検出力やメタ解析の成立を保証しない。各論文を1本除く感度分析；研究数が十分な場合のみ選択／小研究効果の診断、効果推定のCIと研究間異質性を提示する。

**反証可能性の整理**：従来の排他的な必要条件「夜間昆虫依存がなければALANは繁殖を減らせない」は、ALAN曝露中の標的花への夜間訪花を完全に防いだ後でも昼間90分の訪花・種子形成が低下する**競合実験**に直面する。この実験は対象植物の自然環境における夜間送粉依存度 V を測っていないため、研究横断の主傾き `β_V < 0` 自体を直接棄却しない。しかしすべてのALANによる種子損失を夜間送粉チャネルの直接喪失だけで説明する**媒介限定解釈は維持できない**。直接植物応答・昼間送粉者への持ち越し・植食が少なくとも競合理論である。

**分析対象を恣意的に変えない**：Aの確認的係数（繁殖logRRに対する独立に測定した夜間アクセス依存度 V の傾き）と固定した主要繁殖分母は変更しない。Grognuzは植物／頭花の種子数という**二次繁殖成果**なので二次パネルへ収録し、Vが未測定のため確認的回帰には代入しない。結果が負だから採用、正だから除外という選別は禁止する。分散は実照明割当・鉢の週またぎ反復・28昼間実験ブロックの違いを計算するまで未確定。

**将来の結論の言い方**：係数が推定できた場合は「夜間アクセス依存度による**全繁殖影響の効果修飾**」として記述する。「夜間昆虫喪失だけが必要原因」と主張するには、照明×夜間アクセス×種子形成の実験的媒介分離が別途必要。島は経路の構成分布の違いというBの記述、Cは未検証予測のまま。
