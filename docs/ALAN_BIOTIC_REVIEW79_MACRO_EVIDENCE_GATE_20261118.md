# ALAN相互作用の全球一般化：既存79論文の再抽出と独立単位のsource gate

2026-11-18。PR #88の新しい補助線。**生態系や生物間相互作用の反応方向が異なる**という結論を、任意抽出した6–7研究の方向カウントから全球的な真理に拡張しないため、公開されている既存レビューの**全研究台帳**へ戻る。

## 元のレビューの母集団を正しく読む

[Seymoure et al. (2023), *Philosophical Transactions B*, DOI 10.1098/rstb.2022.0356](https://doi.org/10.1098/rstb.2022.0356) は、2022-12-21時点のWeb of Scienceをもとにした「movement ecologyとALAN」の調査枠から1,252候補を抽出し、93件の一次スクリーニングを経て、**79論文**で**81の生物間相互作用**を評価した（2論文で各2タイプを扱う）。**あらゆるALAN論文を網羅したシステマティックレビューではない。**

| 対象段階 | 元文献の件数 | なぜ重複回避が必要か |
|---|---:|---|
| 母論文 | **79** | 複数の反応が一つの照明実験から来る |
| 相互作用の検討単位 | **81** | 81の独立ランダム化照明試験ではない |
| 捕食者―被食者 | **56** | これだけが大半で、植物送粉一般に外挿不能 |
| 植食 | **11** | 葉の被害・種子食害・植物への間接影響は別 |
| 送粉 | **6** | 来訪・花粉・結実は同一ではない |
| 分解食 | 5 | 生態系機能に関係するが送粉媒介ではない |
| 種子散布・寄生・捕食寄生 | 各1 | 強い結論の下地に不足 |

原著の集計文面には**75/79で何らかの相互作用の変化が観察**、その一方**「相互作用強度」変化は54論文**とある。**29増強・28減弱**という方向の言及には、種による正負両反応を含む同じ研究や複数相互作用もある。したがって29+28を57独立研究や符号検定の57観測としない。レビューの数値は出版論文側の二次集計であり、source-dataの再カウント前は本解析の新規推定係数ではない。

## 今回の実データ取得

元のオープン[Figshare collection DOI 10.6084/m9.figshare.c.6837630](https://doi.org/10.6084/m9.figshare.c.6837630) に、著者の元データ表 **`Seymoure_etal_data_supplement_rstb20220356.xlsx`** と文献選定方法のDOCXがある。

- `scripts/acquisition/alan_seymoure2023_original_79paper_figshare.py` が公式Figshare APIからcollection→各article→xlsxを取得し、元SHA256・シート名・行数・列名・候補列の構造を原本のまま監査する。
- 現時点で照明処理区ID、研究×生物相互作用の独立性、昼夜・季節別、方向・強度の定義が未取得。元の79×81表が本当にアクセスできるまで、 **陽性／陰性／検出不能の再集計や種類別メタ回帰を捏造しない**。
- 元Excelをソースとして公開し直すのではなく、SHAと研究ID単位の検証可能な集計だけを持ち込む。
- 元データは2022年までのレビュー探索枠なので、2023–2026年のDeitsch/Brown/Guo/Farnworth等を独立性未監査のまま単純合算しない。

## 「生物間相互作用」を比較可能な単位へ揃えるルール

単位を **独立した照明配置（plot/site）×相互作用タイプ×測定段階** とする。反復測定は原研究・照明区の効果量の共分散で扱い、年／昆虫個体／葉／人工餌を独立実験として追加しない。

1. **捕食者応答**：個体数／活動密度、実際の攻撃（代理模型を分離）、餌の近傍への集積、餌個体群変化を別endpointで集める。
2. **送粉者応答**：総訪花ではなく、ギルド別昼夜のVと、同種・和合花粉q、花粉受領、結実・種子出力の測定の有無を別フラグにする。
3. **捕食者の生態機能**：送粉者を食べる負の経路だけでなく、植食者を抑える正の経路、成虫による有効な送粉、蛾幼虫による種子捕食を区別する。
4. **調節候補**：照明の新設／既設、単一光源／灯列、暗い避難場所、湿潤・水辺の餌の供給、森林キャノピー、昼夜の活動性、島／本土。**同じ研究内で両比較があるときだけ推定可能**。
5. **実証レベル**：randomized light manipulation、BACI、within-lamp nighttime distance gradient、非操作観察、総説二次データを分離。モデル出力しかない論文をraw-effect推定済みにはしない。

**中心仮説の新しい表現**：ALANは生物間相互作用の強度を一律に変えるのではなく、光の周囲で「採餌機会・活動時間・危険な上位捕食者・送粉効率」が変わることで、局所で**利用可能な正味の生態機能の経路**を組み替える。

この段階で言える実証は、前回mainに統合したParkinson・Lu・Pageの各異なる段階と、PR #88で示す捕食者／植食者の方向不一致およびEckharttの公刊7街灯GLMM結果まで。個体が減った「原因」を食物網の同時測定なしに断定しない。

## 証拠の状態

- 元研究の出版上の方向カウントは既報。これは「元Excel再計算の新結果」ではない。
- Figshare取得の成否は `.github/workflows/alan-seymoure2023-original-79study-20261118.yml` の**source status**（`RAW_SUPPLEMENT_XLSX_SCHEMA_VERIFIED` / `METADATA_ONLY` / `SOURCE_STOP`）で評価する。
- 研究IDと植物学名・ギルド・地点年の共通支持が足りなければ、ALANによる湿潤植物の種子低下という因果係数は**SOURCE STOP**とする。
