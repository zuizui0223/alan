## 比較は元の照明割当12サイトに固定

短期（曝露夜1–3）の花弁運動記録555行中、Silene noctifloraの閉花開始137観測、Malva moschataの開花開始82観測を取得。同じ**現地サイト×照明処理×日付**で両種の時刻が記録された **46サイト日（照明22・暗所24）**を対応。元の独立照明反復は **照明6サイト・暗所6サイトのみ**。同一サイト日でも花や個体は別。植物の時計時刻はその日の日の出を基準に最寄りの午前・前夜へ循環展開し、夜中の閉花を恣意的に捨てない。

花の時間的重なりの操作的指標は、日の出前150分～後150分の区間で、Sileneの閉じる時刻とMalvaの開く時刻の間に残る正の時間を計算した。各サイト日に各種の時刻の中央値を使い、その後**サイトごとに日付平均**を作り、処理ごとに6サイトを等重みに比較。95%区間は各処理の独立サイトを15,000回再標本化した**記述的区間**であり、原著のペア構造・気温・月相・週・花弁測定誤差の完全伝播ではない。

## 事前の−4.9分推定と新しい全原イベント結果が異なる理由

同じ開始−開始の指標で、日の出±6時間から外れる元イベントを**サイト日中央値を作る前に除外**すると、対象は46→**42サイト日（照明21・暗所21）**となり、照明−暗所の時間差は**−4.85分**へ符号が変わる。原Silene閉花開始の±6時間外は**暗所15観測・照明2観測**であり、これらを捨てることは照明群に偏った選択となる。今までの−4.9分はこの限定的な時計範囲に依存するため、**主結果としては採用しない**。実際の元イベントを保持した開始−開始の主記述は＋10.26分、これもCIは広く0をまたぐ。花弁の段階を変えると−4.88分になるので、**効果方向は固定できない**。
