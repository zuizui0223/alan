# 夜間光と島の植物群集の結果総括（2026年11月13日）

固定主要結果は、元の5年・78地域・10,698地点年で、撮影種中の「旧GloBIに蛾の訪花等の記録がある植物」の構成比が、夜間光に沿って島で −0.527、本土で +1.374 ポイント変化し、差が −1.902［名目95%区間 −3.706, −0.098］となったこと。単位は log(1＋VIIRS) 当たりの百分率ポイント。結果確認後に指定した探索的主要結果である。同じ地点・年・モデルでGloBI v0.11全記録をWCVP照合すると差は +0.750［−1.076, +2.577］。元資料での構成比の差と、その符号の資料依存性を併記する。[原表](../results/globi_v011_fiveyear/comparison.json)・[713種の旧版のみの記録と出典](https://github.com/zuizui0223/alan/blob/0fb76ff/docs/ALAN_GLOBI_713_OLD_ONLY_SOURCE_COMMONALITY_20261112.md)

島・本土共通544種で島の傾きが負の種は283、正は261。負の種を個別判定した場合、多重比較補正後に残った種は0。島負群の白花40/96に対し島正群30/104。白色に筒状等の花形を加えると2/48対2/55、夜間遮断で繁殖低下は各3/6、自動自殖可能は60/124対44/89。全撮影種8,581種を対象とした別ブランチでも、花色・形の両方が使えるのは930種、形態から定義した蛾媒候補の一貫した負の傾きは支持されていない。[種別比較](ALAN_ISLAND_NEGATIVE_TRAITS.md)・[直接形質の独立照合](https://github.com/zuizui0223/alan/blob/c088a80/docs/ALAN_DIRECT_FLORAL_MOTHLIKE_SYNDROME_LIGHT_20261112.md)

副次結果は花粉制限64種。花粉追加による繁殖改善の対数比が1大きいほど島−本土差が −0.01938［−0.03823, −0.00053］。固定2比較のHolm補正pは0.088、更新版訪花陽性30種に限ると区間は0を含む。外部の繁殖実験からみた種の特徴であり、明るい島で花粉制限が増加したという地点内測定はない。[推定値](../results/pl_transport_species_review/contrasts.csv)・[補正と測定条件](../results/mating_light_contrasts/README.md)

長期資料は11種・3地域・94定点を探索し、同一地点の比較に193種地点年を使用した。1＋放射輝度が10%高い年の、NDVI春緑化から開花までの日数差は島 −5.6日［−9.5, −1.7］、本土 +0.2日［−2.2, +2.6］。島42種地点年の34件が Gaylussacia baccata。増光速度と日数の長期勾配との関係は島の1定点を除くと符号が反転した。植物の開花と近傍の訪花候補蛾の成虫が同日記録されたのは17種地点年。飛翔の調査努力を欠き、花・蛾間のミスマッチを特定できない。[長期の原表と方法](../results/long_phenology_11/README.md)

成虫蛾の捕食者→被食蛾→植物は、島または本土で負の371種のうち56種・63経路で種名がつながる。Heracleum maximum ではハチが被食蛾と同じ植物を訪れる。攻撃率、捕食者による代替送粉量、島での歴史的な送粉者交代から現在の自殖への移行は、固定地点群で未推定。[種別経路と実証範囲](ALAN_LAND_NEGATIVE_SPECIES_AUDIT.md)

論文の中心は夜間光に沿う撮影植物の組成変化と、その解釈が訪花記録の出典にどれだけ依存するか。花粉制限は種間の副次結果、開花暦は一部の島定点で観測された機構候補に位置付ける。各解析の母集団、空間単位、応答が異なるため、その間の因果的な媒介は実証されていない。
