**原本実行日：2026-11-15（UTC 14:21、JST 23:21）。** [真正原本GitHub Actions #43723807336 成功](https://github.com/zuizui0223/alan/actions/runs/43723807336)。出力 ZIP artifact #14165981549、SHA256 `9c0ad5671cf7de3bf9c06eefdd20a2e175c2a0b2db804723d9f1122c1be7332e`。元の種数カウントPR #79の703種を再構築してから、当該種の第一段階とブートストラップを実行した。制限付き植物種×地点行をリポで公開していない。

## 問いと観察量

これは文献のALAN実験効果量のメタ解析ではない。**植物種の「他の植物が観察されている写真セル×年で、その種の記録があるか」という相対的記録出現**と、先行年夜間光の間の種別の傾きを推定する。写真非記録を真の不在と呼ばない。1種あたり複数島×年にわたる相対記録確率の一様傾きであり、種の個体群増減・送粉・結実・適応・照明の因果効果ではない。

署名原本：562島、77,647写真セル×観測年、2,012,925植物種×セル×観測年、14,330受理植物種。固定した候補抽出は243島、72,472写真セル×年、703自殖能実測種（autonomous 489、absent 214）。島×年別に十分な写真セルと先行夜間光勾配があり、種が記録されたセルと非記録セルが存在する層のみで解析。

## 原本共変量監査

[Actions #43722952172 成功](https://github.com/zuizui0223/alan/actions/runs/43722952172)：基盤85,318元サイト年は、植物観測UUID、写真ID、accepted種数、原本Li–Cao年次PCNL、座標・年・島を持つ。**人口密度・気温・降水量などの列は全く存在しない**。人口・気候調整済みという誤表示は禁止。従って以下の β は、都市化の代理を取り除いたALAN固有効果ではない。

- モデル：種別写真記録二値値を、同じ島×同じ年の固定効果、前年までのPCNL平均log(1+値)、log(1+観測UUID数)で説明する線形確率モデル。
- 種別に情報がある島×年層だけを使い、島ごとに重み総量が等しいWLS。傾きの単位は**記録確率のパーセントポイント／先行log(1+PCNL)**。
- 可能なら島クラスタCR1標準誤差。独立した島数が少ない場合のCIは評価しない。全種に同じ観測セル・地域環境が使われ、種別βを互いに独立とは扱わない。
- 島単位SHA256パリティによる2分割は隣接島の独立や全球的地域ブロック独立を保証しない。

### 地理的に広く記録された224種の検証

元の「30以上の独立島で記録された種」だけをあらかじめ定めた感度層として扱うと、autonomous **170種で平均+0.660065**、absent **54種で+0.671406**。差は**−0.011341 pp**へ縮小した。同じ固定224種を島2分割で検証すると差は **+0.223967** 対 **−0.163251**（符号が異なる）。

## 肯定結果として採用できること／できないこと

採用可能：同一島・年の実際の光勾配の範囲で703種の個別写真記録傾きは数学的に推定できる。地理的支持と種間の自殖差の「頑丈さ」は実測で評価でき、主要な自殖差は224種の島ブロックでゼロをまたぎ、分割で符号逆転する。

現時点では採用不可：「自殖できない植物が夜間光でより減る」；「蛾媒シンドロームが因果的にALANに脆弱」；「島嶼で既存送粉チャネルが光害を緩衝」；「写真非記録が個体群減少」。これらは異なる形質・種群・機能的実験・都市化制御が必要で、本分析は実施していない。

## 優先する次工程

1. **人口密度・気候・土地利用の原本を72,472写真セル×年に地理的に結合**する。少なくとも人口密度を同時に係数推定し、「照明×自殖」特異性が「人口×自殖」の係数と異なるか負の対照で検査。適切な光残差変動が欠ければ因果的ALAN解析を停止。
2. 出現記録の系統的な選択と観察者の撮影選好を検査。同一種の利用機会（植物全体の同程度撮影努力・適地の生息環境）を担保できないなら写真記録確率と明示。
3. 属・系統の調整、海域などで離れた地理ブロックの完全ホールドアウト、交互作用の事前固定を満たしてから種別β/SEの階層的メタ回帰に進む。
4. 夜間依存は独立昼夜排除実験に基づき検証し、花形・夜咲き代理指標を別層にし、花粉移送・結実との直接接続がない限り機能的送粉依存と呼ばない。
