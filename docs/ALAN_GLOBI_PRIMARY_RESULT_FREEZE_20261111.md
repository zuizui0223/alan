# 主要結果の固定（2026年11月11日）

本研究の主要な観察結果として、既存のGloBI蛾・蝶の訪花等の相互作用61,967件を全出典込みで使用した5年解析の `broad_all_moth` を指定する。結果確認後に行った位置付けであり、解析は探索的である。

2019・2021・2023・2024・2025年の島933地点年、本土9,765地点年、78地理ブロックで、同年の夜間光に対する蛾の訪花記録を持つ植物種の割合の傾きは、島で本土より **1.902ポイント低かった**。島−本土の傾きの差は **−1.901720622055596 pp / log(1＋VIIRS)**、空間ブロックでクラスタ化した名目95%信頼区間 **[−3.7058390326110446, −0.09760221150014758]**、名目 p = **0.039096062160031655**。

## 対象と推定

- 応答は各0.05度セル・観測年で撮影されたWCVP受容種のうち、いずれかの場所で蛾との対象相互作用が記録された種の百分率。各種をセル・年内で一度だけ数える。記録がない種の現地での送粉状態は不明。
- 地点年に写真3件以上・受容種2種以上を要求し、同じ年・5度ブロック内に島・本土の両方がある組を比較する。各組内で両区分の総重みを等しくする。
- 同年4か月抽出VIIRSの対数光量×島区分、年×地理ブロック固定効果。元解析の人口・撮影数・種数・気温・降水・標高の調整と地理ブロック単位の区間推定を使用。
- 固定対象は合計10,698の島・本土地点年に関する公表係数。原表の別フィールド `complete_case_rows` は10,713を記載する。将来の完全同地点再解析では元の行キー・設計行列・重みを突合し、件数のみの一致で代用しない。

## 一緒に報告する検証

iNaturalist由来の相互作用を除いた同地点比較は −0.498 [−1.837, +0.840]。同地点の蛾−蝶の直接対比は −0.778 [−2.701, +1.146]。同じ探索で検討した16モデルのBH補正後の最小q値は0.626。地点間の観察的関連として扱い、蛾に特異的な機構、島での経年減少、現地の有効送粉への影響は未確定とする。

GloBI v0.11全件走査に基づくWCVP再照合は、事前にこの係数を参照値と定めたデータ更新検証とする。種集合の維持・追加・脱落・未解決、観測地点内での分子の変化、新係数と元係数の差を報告する。
