# 島に記録された蛾捕食・送粉動物と、共通の植物

旧GloBIの蛾訪花植物割合に対する夜間光の傾きの差（島−本土）−1.902ポイントを主要結果とする。対象は2019・2021・2023・2024・2025年の島933・本土9,765地点年で、地点キー集合のSHA256を元の解析と照合した。[固定した主要結果](ALAN_GLOBI_PRIMARY_RESULT_FREEZE_20261111.md)

## 対象種と地点年

GloBI v0.11の全出典で、蛾科の獲物への捕食・摂食関係と、植物への送粉関係（pollinates またはその逆向き）がともに記録された80種名を母集団とした。元の0.05度格子を使い、同じ年、同じ島にGBIFの観察がある種を選んだ。人による観察、種名・種キー一致、存在または検出、0超1 km以下の座標不確実性を条件とし、元のGSHHG陸塊と内水面判定を使った。島で条件を満たしたのは57種（コウモリ2、鳥5、トンボ2、ヤモリ1、その他の昆虫47）。全80名をGBIFの種キーに一致させた。*Coleomegilla maculata* はGBIF分類上 DOUBTFUL だが、原名と観察の種名・種キーが一致している。観察が見つからなかった種については、元の島の全地点年を含む検索が最後のページまで完了したことを確認した。1度まで広げて初めて島記録が得られる種は11種だった。[対象80種](../results/dual_role_80/cohort.csv)・[島記録の照合](../results/dual_role_80/island_screen_receipt.json)

固定GloBI v0.11の全24,453,954行から、種名付きで成虫段階の蛾を捕食した記録と、捕食者自身の送粉先を抽出した。蛾の訪花先は−1.902で使用した元の訪花表から取り、両植物名が一意に同じWCVP受容種IDに結び付く場合を採用した。異名も一意に受容種まで解決できる場合に含めた。加えて、その受容種が当該地点年で実際に観察されたことを求めた。主要結果の分子と係数は元の定義のままである。

各地点年で、捕食者と名指しされた蛾の成虫（GBIFでAdultまたはImago）の双方が、植物と同年・同一陸塊・同格子に記録された場合のみを数えた。個々の3者の組み合わせを照合してから地点年を重複除去した。主たる集計は島の元格子で記録がある57種を島と本土の両方に適用する。1度の表でも同じ57種の結果を明示し、広域で選ばれる68種の結果と区別した。

## 共通植物が確認できた地点年

| 空間条件 | 島 | 本土 | 異なる3種の組み合わせ |
|---|---:|---:|---|
| 元の0.05度格子 | **0** | **0** | 該当なし |
| 同じ1度格子かつ同一陸塊 | **1** | **8** | *Dolichovespula maculata* → 成虫 *Cisseps fulvicollis* → *Heracleum maximum*。ハチ自身の送粉先も *H. maximum* |

表は島の元格子に記録がある同じ57種の比較である。島の1地点年は2025年、本土8地点年は対象5年にまたがった。1度格子で島記録が得られた68種まで含む集計でも同じ9地点年だった。9地点年すべてで植物は元の主要結果の分子にも入っていた。0.05度の0件は、該当する観察を元の格子でそろえられなかったことを表す。[地点年集計・全80種の内訳](../results/dual_role_80/summary.json)

57種のうち、種名の分かる成虫の獲物が得られたのは14種（捕食者・蛾の19組）。その蛾に旧訪花表の植物を結べたのは10種。捕食者自身の送粉先と受容植物種が一致したのは次の3候補だった。植物名が曖昧または未解決の記録は採用していない。検索対象の全80種を通して、蛾の訪花先の532名称中450、捕食者自身の送粉先874名称中687が一意に解決した。[候補別の植物名・WCVP ID・原記録判定](../results/dual_role_80/island_cohort_reviewed_links.csv)

- *D. maculata* と *C. fulvicollis* の捕食は、2019年9月9日の原観察に獲物名付きで記載されている。*H. maximum* について、ハチ側の原表には2017年5月20日、網による採集標本1件があり、GloBIでは pollinates に分類された。蛾側で現行APIからたどれた吸蜜植物の原観察は2026年5月21日。固定5年は3種の出現記録に課した条件であり、捕食・訪花・送粉の原記録がその9地点年に同時に取られたわけではない。柱頭への花粉移送や結実に対するハチの寄与量は未測定である。[捕食の原観察](https://www.inaturalist.org/observations/32443214)・[蛾の吸蜜植物の原観察](https://www.inaturalist.org/observations/364954981)・[ハチと植物の原データ](https://datadryad.org/dataset/doi%3A10.5061/dryad.ffbg79cwn)
- アルゼンチンアリ *Linepithema humile* と *Macroglossum stellatarum* は、両者に *Asphodelus aestivus* が結び付いた。ただし、蛾側とアリ側の原観察は互いに同じ出来事を参照し、どちらの行動欄にも死骸食の記載がある。この植物の記録も固定地点にない。[蛾側](https://www.inaturalist.org/observations/186580299)・[アリ側](https://www.inaturalist.org/observations/186584694)
- *M. stellatarum* には獲物欄にも自身を指定した1件がある。種名だけで機械的に結ぶと、捕食者と蛾に同じ種の出現を使ってしまい、元格子で島1・本土13地点年が生じる。原記録から別の獲物個体を確認できず、異なる3種の集計に含めなかった。[自己参照の原観察](https://www.inaturalist.org/observations/357642588)

捕食される蛾と捕食者自身が同じ植物を利用し得る例は1度格子で見つかった。一方、島と本土の主要結果の差を、捕食者が失われた蛾の送粉をどの程度補うかに結び付けるには、同じ植物での蛾・ハチそれぞれの花粉移送量と捕食頻度が必要になる。今回の9地点年から、その補償の量や向きは推定できない。

## 再実行

固定版の入力、元の植物データと海岸線を使う。個々の観察座標を含むGBIF応答はPRIVATE内に保管する。

```sh
gh run download 42963235095 -R zuizui0223/alan -n dual-role-80-edges -D EDGES
python scripts/analysis/alan_dual80_prepare.py INPUTS SIGNED PRIVATE
python scripts/acquisition/alan_dual80_occurrence.py PRIVATE INPUTS/coast
python scripts/analysis/alan_dual80_shared_plant.py INPUTS PRIVATE EDGES results/dual_role_80
```
