# Xiao2025：植物×食害×照明の抽出候補

一次本文：[10.1098/rspb.2024.2811](https://doi.org/10.1098/rspb.2024.2811)。原データ：[Dryad 10.5061/dryad.1rn8pk143](https://datadryad.org/dataset/doi:10.5061/dryad.1rn8pk143)。2026-11-20にMethods・Results・データ記述を確認。

12植物種の温室実験で、照明・養分・食害を操作。植物成長は3明暗区画ペア、食餌試験は別の1区画ペア。288鉢を独立照明反復とはしない。最終生物量は生存284鉢で測定。著者の全種モデルには侵入性×照明×食害の交互作用があるが、区画別効果量の自前抽出は未完了。

原データの説明には`Compartment`と`Total_biomass`があり、区画単位への集約を検証できる可能性がある。Dryad APIで版362399・3ファイルの書誌情報を取得したが、APIダウンロードは401、公開ページ掲載のダウンロードは403だった。未取得を非公開・範囲外とは断定しない。本文のデータDOI表記に誤記があり、上記DOIは同題・著者一致のDryadレコードで確認した。

現在は設計上の採択候補・数値抽出待ち。食餌試験の単一区画対を多数の独立照明反復として統合しない。主たる植物実験は温室層として保持し、湿地対乾燥地の比較に置き換えない。本文のモデル結果を未調整lnRRとして転記しない。

取得メタデータは外部キャッシュ`../gbif_annual/alan_experiment_sources/xiao2025/files_metadata.json`。ファイル本体は未取得。
