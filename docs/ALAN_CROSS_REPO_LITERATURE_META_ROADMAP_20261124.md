## 3. 推奨する正式メタ解析の範囲

**推奨する一つの主題：** 「夜間人工光は、どの相互作用経路をどの生態段階で選択的に再配置するか」。湿潤植物の記録率低下との観察的関連は独立した主マクロ結果とし、光実験メタとの間に媒介を捏造しない。

先に各論文の**共通で実験的に同定できる最小エンドポイント**を決め、以下の**別々の解析レーン**へ置く。

| 分析レーン | 推定対象 | 主要な科学的問い | 主な採択ゲート |
|---|---|---|---|
| **A. 昆虫の誘引・空間移動・水陸境界** | 同じ採集法での明暗`lnRR`、水生起源−陸生起源の`lnRR`差、あるいは河川内E+T/D+Cの`lnRRR` | 光は総個体数よりも分類群・移動経路の配分を変えるか | 走光性捕獲、自然群集密度、水中漂流、真正の羽化を別層にする |
| **B. 捕食・食害・植食者** | 捕食率（攻撃成功/試行）、アブラムシ計数、網数、葉面損傷を別のアウトカムとして`log RR/OR` | 資源の光下集積は捕食者の実際の機能に伝わるか | クモ個体数/網現存数を捕食成功率に変換しない。同一試験で操作・共分散必要 |
| **C. 送粉経路・植物繁殖** | 夜昼の訪花、同種花粉受領、成熟果実、種子／胚珠、種子数をそれぞれ別の効果尺度で | 送粉者交代が実際の繁殖機能を補うか、昼行性の代替があるか | Night-only / Day-only / Open / Bagged の処理条件と同一の分母・物理ペアを特定 |
| **D. 直接的な湿潤性修飾** | 同一エンドポイントの`ALAN×実測水分`、`ALAN×水面距離`あるいは植物EIVの交互作用 | 湿潤植物・水辺での効果が強いか | 同研究内で距離・水分と明暗を交差させる。水生起源＝湿潤植物とは扱わない |

**各レーンで使う具体的効果量：** 2群の正の量は `lnRR = ln(mean_L/mean_D)`。同じ野外実験で2ギルドを測った場合は `Δ = lnRR_A−lnRR_B`（比の比）、標本分散は `Var(A)+Var(B)−2Cov(A,B)`。訪花や獲物数の**生計数**は、可能なら照明の割付単位に対応したPoisson/負の二項モデルとoffset(採集努力)からの係数を使う。果実割合、種子／胚珠、感染率は適切な二項・ベータ二項の`log OR`等を保持し、単純に個体数`lnRR`へ混ぜない。BACIは差の差、同一施設の前後採集は元のペア共分散を保持する。二次文献メタから抜き出した効果量を、原一次研究と重複して再投入しない。

夜間依存と昼間代替の**厳密な機能的バッファリング量**は、同一実験、同じ植物・同じ繁殖分母に限定して `B = lnRR_open − lnRR_night-only`。この差の共分散を回収する。OpenとNight-onlyが異なる研究ならBは作らない。Grognuzの「夜の曝露→翌日種子」は夜のみ送粉者への依存ではなく、carryoverとして別レーンにする。

## 4. 統計モデルと不足データ

解析単位は`report_id → programme_id → site/block_id → treatment×taxon×endpoint×time`の階層。1つの設置設備が複数論文に出てくるときは**同一programme_id**に束ねる。対応・共有暗区の共分散行列`V`を作り、同じレーン内の`y ~ 1 + spectrum + illuminance + context + ... + (1|programme) + (1|site)`型の多階層REML/ベイズモデルへ。式は同一endpoint内で支持される変数だけに絞る。kが小さいときはHartung–Knapp、影響分析、予測区間を優先し、クラスタ数2で多数の調節因子、Egger、相互作用、擬似独立の頑健分散を乱用しない。

**実際に不足しているもの：** 既存のA起源別捕獲k=2、Bアブラムシ修飾k=2・食害k=3、第4の漂流構成k=2はいずれも弱い。元108行のうち有限の同尺度の花粉送達・結実・種子効果が未登録。EIV MOISTを結合できたのは5種・3系列・10対比。現状で湿潤性の大規模メタ回帰やメタSEMによる媒介割合を出さない。<10独立programmeほどの小kで方向を言い切らず、k約10前後から単純な系列平均の可能性を検討し、共通支持が乏しい水分調節メタ回帰にはさらに多くの独立環境反復が必要（**10や20は必要十分な固定閾値ではない**）。

**編集のゴール：** 今は「全論文を精査済み・水生昆虫の選択的応答が一般化した」と書かない。主結果は湿潤種の観察的偏り、原本操作実験は**機構候補の段階別定量評価**。全研究の検索・独立実験採択を終えた時点で、初めて「systematic experimental meta-analysis」と表現する。

**外部の既存合成との住み分け：** Kendall & Nicholson 2025の135研究は昼夜送粉アクセス、Czarneckaら2025 DOI `10.1111/gcb.70569`は波長・照度の広義ALANメタ、Petiteauら2026 DOI `10.1007/s10531-026-03517-3`はALAN×騒音の相互作用メタ。自前の差別化は光の総害ではなく、**資源／消費者／送粉／繁殖が同じ方向に変わらない条件を、同一実験内での段階差として推定すること**。ただしその再現性は未検証であり、既存文献網羅後に主張を再評価する。
