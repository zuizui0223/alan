# Miller2017：温暖化・照明・捕食者の野外実験候補

[一次論文](https://doi.org/10.1098/rspb.2017.1195)、[原データ公開先](https://doi.org/10.5061/dryad.h7k26)、[出版社補遺](https://doi.org/10.6084/m9.figshare.c.3889075)。2026-11-20に本文の野外設計と補遺を確認。

Wisconsinのアルファルファ畑で48囲いに照明・夜間加温・捕食者種を割り付けた要因実験。12処理組合せを4ブロックで反復し、各照明囲いに灯具を設置。捕食者なしの対照もある。アブラムシ数に対する捕食者種別の応答を検討できる候補で、室内摂食試験とは分離する。

Figshareから取得した補遺DOCXは室内試験のANOVA表と温度検証図であり、48囲いの原観測値は含まない。統計量だけから照明／暗区の平均・SDを作らない。Dryadの原区画データを取得・確認するまでは効果量未抽出とする。著者所属機関のPDF取得は404、PMC本文の追加読み込みも途中から確認画面となったため、全結果の全文監査完了とは数えない。
