# ALAN H3：集計で符号が反転する花被覆量と昼間訪花の実測（2026-11-15）

**真正原著**：Giavi, Fontaine & Knop (2021), Nature Communications DOI [10.1038/s41467-021-22011-8](https://doi.org/10.1038/s41467-021-22011-8)、[元著者Zenodo 4540407](https://zenodo.org/records/4540407)。原 data.Rdata 署名MD5 **f60b21d82c163cbb53520fda0bc61985**。2016年の6照明・6暗所を**真の6ペアの独立単位**とし、37調査回、21被覆測定植物、日中3昆虫目を扱う。原データのfloral cover (plab)は原著Methodsで**直径約5cmの円の表面単位を離散的に割り当てた花被覆面積の代理指標**であり、個体数・開花花数・訪花による有効送粉の実数ではない。本解析は著者の植物×照明×昆虫目の混合モデルの再現ではなく、同種・同時に照明／暗所の花と訪花が**両方観測された**サブセットの新しい解釈可能性検証。

## 1. 真の独立標本・選択が非常に非対称

**サイト定義の厳密化**：原著の6組は近隣に対応させた計12の**別々の物理的草地**（照明草地6・暗所草地6）である。ソースの site ID は**サイトペアID**であり、照明区と暗所区が同じ物理地点だという意味ではない。調査回はペア草地を同日に調べた単位である。したがって以下の『同一サイト』表現は『同じサイトペア内の異なる照明／暗所の草地』を指す。

原観測は1,884昆虫目行（同一植物×調査回の花被覆が3目に重複する）。重複を除くと628植物×調査回×処理（照明333、暗所295）、実際のペア site×pair×plant で両処理を照合可能なものは**193ペア**（386観測行、残り**242片側のみ**）。193ペア中**73ペア**は両処理とも3目合計の訪花が0で、これは記録された真のゼロとして含め、そもそも植物とその花被覆が記録されなかった組を0に補完しない。元3目の全訪花／被覆測定と、厳密な共通支持の差：

| 範囲・分母 | 暗所 | 照明 |
|---|---:|---:|
| 元の全628植物×回の実測花被覆機会 | 295 | 333 |
| 元の全測定花被覆代理合計 | **11,733** | **11,785.67** |
| 元の全3目訪花記録数 | **1,164** | **1,220** |

**選択が照明側・暗所側で異なり、対応した同一植物・同一回と「全群落総数」は同じ比較対象ではない。** この差はソース実測の花資源の分布と、植物が観測された条件に依存する。個体数で無理に増やしたり、未観測の植物を「生物学的に存在しない」にしない。

## 2. 元同じ193植物×調査回でも、集計法で符号が変わる

**単純に全植物×サイト×回を合計した訪花数／花被覆代理比**：
- 全628元機会での照明／暗所比 **(1220/11785.67)/(1164/11733) = 1.0434**、見かけ上 **+4.3%**。
- 対応した193機会でも **(889/7829)/(969/9825) = 1.15134**、見かけ上 **+15.1%**。

**元の同一植物×同一サイト×同一回に先に対応させた場合**、同じ同時花被覆の下で訪花が配分されるなら照明へ期待される割合を E_L = (V_L+V_D)×F_L/(F_L+F_D) と置く。実際の照明訪花 V_L と E_L の差を、そのサイトの実訪花総数で割り、6真正サイトを等重み平均する。**独立の6サイトで結果−0.02373（−2.37ポイント）**、サイト単位bootstrap記述95%区間 **[−0.09646,+0.03517]**。193組を一緒に訪花数で重み付けた同一イベント期待値との差も **−0.01534（−1.53ポイント）**で負（全193組の実照明訪花割合 **47.85%**、各組の花被覆による期待訪花割合を訪花数で加重すると **49.38%**）。この解析は**事後測定された花被覆で条件付けた訪花の配分**であり、ALANの植物繁殖への総効果を意味しない。

**同じ193植物機会に由来するにもかかわらず「全件の総和を取って花被覆で割る」→正、「同一イベントで花被覆比例の期待値を計算する」→負**となる。これは植物・サイト・調査回の露出量をどの段階で標準化するかによる**Simpson型の集計符号逆転**。推定対象が異なるため前者が計算誤り、後者が唯一の真の因果効果というわけではない。

真の6サイトの同一イベント比でみると、照明区の訪花割合が花被覆比例の期待を上回るサイトは**4/6**、下回るサイトは**2/6**。個別匿名サイトの符号付き差は、**−0.09025、＋0.05534、＋0.02155、＋0.01718、＋0.03354、−0.17974**。**サイトペア均等平均は−0.02373でも、サイトペア均等中央値は＋0.01937と正**。最も負の1サイトを除外すると平均は**＋0.00747へ符号反転**、全6サイトに戻すと負。サイト単位完全符号反転の記述的割合は **p=0.625**（正式な試験割当の無作為化検定ではない）。**ALANで昼行性訪花が普遍的に増減するという符号はここでは識別できない。**

## 3. 植物組を同一イベントで条件付けた群別結果

指標：各 site×plant×survey の真の訪花合計を固定し、花被覆に比例した照明区の期待訪花割合からの**照明−期待の符号付き割合差**。最低1回の完全に対応した機会がある193組を採用。以下の観測量は夜間の蛾ではなく**昼間の訪花**。

4群のHolm補正後の探索的pは**全て1**。強い負の甲虫サイトがあるものの、花被覆と時系列重複に関する前回の「甲虫の＋0.285」という結果とは**応答定義が違う**。前回は「同一系列内で花の多い回と訪花の多い回が重なったか」の時間分布、今回は「同一回の両処理で花被覆を考慮した訪花配分」。したがって両者の符号が異なることは原データの矛盾ではなく、**昼間の季節的時間配置と訪花密度という生態学的な別過程**を区別すべき証拠。

**対応回数の閾値を変えた感度**：少なくとも1／2／3／4回同じ植物が両処理で調査された193／176／144／117機会について、3目合計のサイト均等差は**−0.02373／−0.03166／−0.03478／−0.02524**で、平均方向は負だが、全て記述95%区間は0を含む。この調査回支持条件は事後的感度分析であって全植物の効果の母数ではない。

## 4. 経路H3の進捗と中止基準

**達成**：同一植物種・同一調査回・同じ2016年照明実験内の**花被覆と昼間訪花の観測機会を直接対応**させ、データ選択・花量による期待、集計単位・サイトレベル異質性が、見かけの符号を変えることを示した。原著のMethodsでは午後13〜17時のサンプルが主で一部午前、サイト平均約15日間隔の7回程度の反復。再解析ではこれを**同じ日内の時間帯プロファイルではなく、季節的な繰り返し調査回**として扱った。

**未達・主張しない**：真の花弁開閉時刻×蛾やハチの**同時刻の活動重複**、同種花粉受領・種子、捕食者媒の補償、島嶼の送粉チャネル移行。花被覆代理は照明自体によって変化し得る**処理後共変量**なので、これで条件付けた比はALANの総効果や確認的な「昼間送粉補償の効果」ではない。まったく別の実験2022–2023 Grognuz花弁時計データと、この2016年Giaviの訪花を同じ日時・サイトとして結合していない。

**再現と保存**：source MD5で固定した2016原RdataをGitHub Actionsで再取得、6真正サイト、37対調査、628観測花被覆、193共通機会、全4ギルド、Holmおよび全サイト除外感度を再計算。原植物×サイト×調査回の生個票はGitHubに再配布しない。既存**Draft PR #78**で研究別PR/branchを作らず、main変更なし。
