## 解析の判定を先に固定

1. **原本同一性**：Figshare article ID 24147963、file ID 42366918、20列の完全な列名とバイト SHA256 を一致させる。独立の未確認ファイルに差し替えない。
2. **単位**：まず DOI を厳密に正規化した「論文」を独立のまとまりとし、DOI欠落では同一著者・タイトル・発行年を暫定キーにする。これはランダム化照明単位より粗い。同一論文の複数相互作用を擬似独立としてプールしない。
3. **生物学的エンドポイント**：既存著者の `interaction_type`、`Consumer_taxon`、`Resource_taxon` を直接保持する。捕獲数、活動量、捕食痕、送粉者訪花、花粉送達、種子成績を別stageとする。
4. **方向**：元Excelの `interaction strength (IS) reduction`、`IS enhancement`、`strength sum` は元コードブックの観測値をまず列挙。空白を0に補完せず、数値・文字・数式キャッシュの違いを監査してから増強・減弱を判定する。
5. **時空間**：`temporal mismatch induced`、`spatial mismatch induced`、`effect sum` を直接保持。強度増減と同時に非排他的に記録される場合は別の独立研究に増やさない。時空間ミスマッチを観測していない研究を「ミスマッチなし」としない。
6. **研究デザイン**：元 `method` の語彙を監査してから「操作照明／BACI／既存光勾配／非操作観察」を定義。反復観測単位、灯具・区画、SEが不明な研究に精度を作り足さない。
7. **選択バイアス**：原レビューは movement ecology と ALAN の文献DBを起点とした検索であり、全ALAN相互作用研究の確率標本ではない。ここから算出する割合は**当該レビューの収録構成の記述**であって、全球における真の相互作用の減少確率ではない。
8. **独立検証**：2023–2026のParkinson／Deitsch／Brown／Guo／Farnworth／Boom／Eckharttと重複する元出版論文があれば DOI と実験IDで除外・階層化してから追加する。

## 優先的に答える科学的な問い

**H1（符号）**：ALANに対する相互作用の向きは、単純な照明量よりも、当事者の光への誘引／忌避・採餌と回避の機会差で変わる。レビュー内の捕食・植食・送粉で、増強／減弱／両方／未同定の頻度を**原著コードと論文IDで**比較する。種間・実験間差を研究の符号検定で意味づけしない。

**H2（時空間）**：強度の変化は、個体数そのものの差ではなく、時間・空間の出会い確率を通じても生じる。原 `temporal`／`spatial` 列の収録範囲と強度方向の共記録を記述し、未測定が多い場合は媒介推定を停止する。

**H3（正味の機能）**：増強された捕食が、植食者抑制を通じて植物を守ることと、送粉者の減少で植物を傷つけることは反対の経路。蛾の成虫送粉と幼虫種子捕食の両面も別に扱う。真の同所・同種・同処理の花粉／種子結果がない限り、 `P_i ≈ Σ_g V_{ig} q_{ig}` の機能的補償は証明されない。
