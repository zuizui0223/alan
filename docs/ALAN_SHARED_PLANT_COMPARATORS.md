# 複数地域で両側に記録され、蛾の体表花粉が分かる植物

元の78地域・5年の共通544種から、①旧GloBIとv0.11でともに蛾の訪花陽性、②既存の研究で蛾の花粉運搬が確認済み、③同じ地域・年の島と本土の双方で撮影された地域が2地域以上、の3条件で抽出した。該当したのは前回の *Cirsium vulgare* と、以下の *Plantago lanceolata*、*Ranunculus ficaria* の計3種。効果量の絶対値や符号を選定条件に使っていない。別に旧版のみ陽性で両側に写った地域年数が最も多い *Artemisia vulgaris* を比較した。地域年数は同じ5°区画を別年に再訪した場合も数え、地域数は異なる5°区画の数である。[全544種の記録・既存の寄与](../results/species_interpretation/shared_544.csv)

## 風で花粉を放出する種にも蛾の体表花粉がある

*P. lanceolata*（ヘラオオバコ）は北米西岸2地域（11_27・12_24、いずれも2025年）と北米北東部21_26（2021年）で、島と本土の双方に撮影記録がある。同年同月にそろうのは11_27の4月。英国の農業景観で採集された蛾の原付表S3では本種の花粉がシャクガ科1個体に記録され、昼には単独性のハチ・カリバチ類の欄に訪花1個体がある。夜は体表の花粉、昼は訪花の観察という異なる方法なので、この1対1から昼夜の送粉寄与を比較できない。本種では実験室の加振と草地での高速撮影により、風の乱れで雄しべが振動し花粉を放つ機構が実証され、豪州ではミツバチの採粉も観察された。蛾の付着花粉が訪花で付いたか、柱頭に有効な他家花粉を届けたかは、この1個体から判別できない。風媒と昆虫への花粉付着を同時に認めることで、「記録された運搬」と「夜に訪花を失った場合の種子損失」を分けられる。[蛾の花粉・昼の観察、原付表S3](https://doi.org/10.6084/m9.figshare.c.4955030)・[風による放出の実験](https://doi.org/10.1098/rsif.2014.0866)・[ミツバチの採粉観察](https://doi.org/10.1038/193196a0)

## 春の同月比較はできても、繁殖に至る経路は未確定

*R. ficaria*（原付表名 *Ficaria verna*）は北米北東部21_26（2025年）と欧州36_28（2023年）の両方で島・本土とも4月に写った。英国原付表S3では本種の花粉を運んだヤガ科が1個体、昼に訪花したミツバチ科も1個体だった。独立した繁殖過程の研究では花粉管の伸長を観察した集団で結実25%、種子の生存性7%を報告した。他の受粉実験と胚珠の観察でも、葉腋にむかごをつくる型では胚嚢・珠心の退化が生存種子を少なくすることが示された。季節を4月にそろえて植物を比較する例として使える一方、元の写真には繁殖型、局所の蛾の活動曲線、種子生存性が対応しない。花粉を運んだ蛾の存在や正の寄与から、夜の送粉が加入を維持したという経路は識別できない。[夜の運搬・昼の訪花の原表](https://doi.org/10.6084/m9.figshare.c.4955030)・[花粉管・結実・種子の直接測定](https://pmc.ncbi.nlm.nih.gov/articles/PMC8772756/)・[生存種子と胚珠の観察](https://doi.org/10.1093/oxfordjournals.aob.a085059)

## 記録地域年が多いヨモギ属との比較

*A. vulgaris* は5観測年すべてで北米北東部21_26の島・本土に写った。残る1組は欧州36_28の2025年で、同じ地域・年・月までそろうのは21_26の2025年9月の1組である。旧版で蛾訪花陽性だがv0.11で陽性ラベルを欠き、採用した証拠台帳にも蛾がこの種の花粉を運んだ確認はない。ポーランドでは同種と同属他2種について開花季節と花粉生産を測定し、属レベルの空中花粉の季節変動と比較した。こうした風媒植物にも正の寄与があることから、光と関連した植物種構成には夜の動物による送粉以外の経路も入り得る。蛾の訪花や一部の送粉寄与が生じないという意味ではない。5年の同じ地域を繰り返し観察できたことと、季節をそろえた独立地域間の比較の広さには差がある。[3種の開花・花粉生産・空中花粉の原著](https://pmc.ncbi.nlm.nih.gov/articles/PMC4871921/)・[蛾の花粉証拠と記録源](../results/moth_pollen_evidence/README.md)
