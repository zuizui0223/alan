# ALAN | 植物観察努力 × 長期夜間光：実測バイアス監査（2026-11-10）

## 結論

**長期夜間光（PCNL）が強い場所ほど、iNaturalist植物観察件数・写真件数・記録植物種数が多い。** ただし「観察件数だけ」を共変量として入れても、前回のGloBI蛾訪花記録陽性植物割合との正の関連は消えない。これは**観測偏りが存在すること**と**観測数1変数でその偏りを完全に除去できないこと**を意味し、光害が蛾依存植物を増やすことを意味しない。

**解釈上の境界**：記録数が明るい地点で多いのは実証された。しかし単なる「記録数1変数の不足」が正の係数の全量を説明するとはいえない。補正仕様によって名目区間がゼロを含むうえ、以下は未調整：植栽・園芸・外来植物の種構成、都市化/土地利用/アクセス性、iNaturalist撮影者と対象選択、GloBI研究対象の地域・分類群偏在、光環境自体の空間スケール。

これは探索的な補正診断であり、仕様違いのp値は独立再現や事前登録済み検定ではない。**光害で蛾に依存する植物が減る／増える**という生物学的仮説には直接答えられない。次段階の判定には独立した夜間有効送粉・生活史・自殖能力、野生/植栽状態と、記録努力に依存しない植物相ベースのデータが必要。

## 研究上の扱い
元の主係数の正方向をそのまま「支持された生態機構」と言い換えない。本文では**観察強度勾配を持つ全球写真記録におけるGloBI蛾訪花陽性種の構成上の空間相関**と記す。新たな十分に支持された野外群集への一般化は保留。
