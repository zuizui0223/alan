# ALAN A｜確認的係数を識別するための最小原資料要求仕様（2026-11-15）

**対象**：既に照明×送粉者アクセスの真正要因実験が存在する Lu et al. 2026 (*J Plant Ecol* DOI 10.1093/jpe/rtag160) と Macgregor et al. 2019 (*Ecosphere* DOI 10.1002/ecs2.2550)。2026-11-15の時点で「研究がない」のではなく、照明別×昼夜アクセス別の繁殖原セル・共分散が手元にない。**著者には未送信**の資料要求設計。

## 最小成果（これだけ揃えば研究内の交互作用が推定可能）

各論文について、実際に照明を割り当てた独立圃場／灯具×実験ランを単位として、以下4つの組み合わせの**同じ繁殖指標**を求める。

| | 暗所 | 夜間照明 |
|---|---|---|
| 昼のみ送粉者アクセス | D0 | D1 |
| 昼夜開放 | O0 | O1 |

- **夜間の限界的な実測依存度**：V = 1 − D0/O0。暗所のみから計算。昼・夜処理の全照明状態をプールしない。
- **自然の昼夜開放状態に対するALAN繁殖効果**：y = ln(O1/O0)。
- **照明×アクセスの研究内交互作用**：Δ = ln(O1/O0) − ln(D1/D0)。
- **不確実性**：少なくとも上記各セルの独立割当クラスタ当たり成功/失敗、または同一分母の平均・SD・n、並びにペア間共分散。暗所O0をVとyで共有するため、共分散ゼロと仮定した傾きは偽の負方向へ偏る。元モデルの係数・SEのみの場合は、リンク関数と基準処理・共分散行列・推定対象を添える。

**絶対に区別する成果単位**：初期標識花のうち有種子成熟果実となった割合、初期花あたり成熟種子数、初期植物あたり総種子数、形成された果実に条件付けた種子／胚珠割合、柱頭同種花粉数、訪花数。段階違いを単一logRRに混ぜない。種子食害でデータから脱落した花を勝手に0種子としない。

- 2024年の**実際の照明5ペア**をIDで対応させる。灯具照明、暗所、4アクセス（完全排除・昼のみ・夜のみ・終日開放）。種×明暗×アクセスで16処理型、5ペアごとに配布されていれば最大80行の集計（この行数・植物の配分は**想定、確認済みではない**）。
- 種子率は**形成された果実内の発達種子数／胚珠数**として明記されている。各処理の受粉開始花数、成熟果実数、総種子数もあれば、より意味の広い初期花あたり成果に接続できる。
- Open-armの*P. kansuensis*種子率に対する照明効果は原著「非有意」だが**点推定・分散未回収**。night-onlyの−56%と混同しない。昼夜開放と夜間のみの同種花粉数では報告値からB_pollen=ln(0.7691/0.4620)=+0.510のみが記述可能（共分散なし）。
- 補足資料の**Table S4b**、各セルの平均・SEM、明暗ペアID、植物ID／年・採花期、正確な模型仕様、ランダム効果構造を最優先で依頼。個体座標や個人情報は不要。

## Macgregor 2019 で要求する具体的な原データ

- 実験年2015、**5照明実験地点×4実験ラン**の配置ローテーション。照明カテゴリ：暗所／HPS終夜／LED終夜／HPS深夜消灯／LED深夜消灯、アクセス：完全排除／昼のみ／夜のみ／終日開放。1実験地点×ランを1処理割当単位として区別する。

- 原著のlighting×caging交互作用は**非有意だがSE未回収**。有意と仮定せず、Table S4/S6の正式な統計検定表と係数・SEを求める。

## データ受領後の厳格な処理

1. 元ソースにSHA256とDOI・版を付与。処理ID・実照明割当IDが不明なら「未認定」として保留する。
2. 四セルの成果分母を統一し、暗所共有対照の共分散と研究内反復を保持。ゼロ成功は保留し、事後擬似カウントで符号を作らない。
3. **まず研究別の照明×アクセスの交互作用Δを推定**。研究横断の傾きβ_Vは、独立した多数の実験でVが異なり、同じオープン繁殖成果yと分散が揃う場合に限る。単一Lu研究の2植物を「世界の2つの独立証拠」としない。
4. 論文数が増えなくても「仮説を棄却できる精度で0か」「研究内の符号が逆か」は報告する。照明色、捕食、島の違いは**副次的な条件・予測**として残し、主係数の小標本へ多数の交互作用を追加しない。
