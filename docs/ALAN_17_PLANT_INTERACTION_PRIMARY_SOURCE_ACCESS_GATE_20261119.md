# ALAN植物相互作用メタ解析への一次原著アクセス優先順位（2026-11-19）

## 独立原著の母集団

[Seymoureら2023年の著者公式Excel](https://doi.org/10.6084/m9.figshare.c.6837630) は原SHA `a4c105c50f7b53cb2c58b287d065b79432b6ec7c308c35b1c4b873e78a4a359e`。集計フッターを除く81相互作用のうち、**送粉6、植食12の合計18相互作用**を含む。同じGiaviらの論文が2種類の相互作用を扱うので、独立の**原著論文は17本**であり、18実験とは数えない。

原reviewの `method` 列に実際の記載があるのは当該18原行のうち**1行**。少なくとも、この表だけで17論文の操作実験・非操作観察を分離することはできない。特に昼夜の訪花数、和合花粉、実際の種子、果実／幼虫の種子捕食、植食者の存在量と食害は、同じ尺度でないため混合しない。

## 次の原著取得ゲート

[原著アクセス監査コード](../scripts/acquisition/alan_seymoure2023_pollination_herbivory_primary_source_access_20261119.py) は、元の18行から**効果方向に依存せず**17論文すべてを選び、論文DOIの存在、Crossrefの正確なDOIメタデータ、Europe PMCの同一DOI収録・OAフラグ・PMCIDを個別に照合する。[原本検証workflow](../.github/workflows/alan-seymoure2023-plant-17-source-access-20261119.yml) の結果に、メタデータしか取得できない研究を含めて正確な「取得状態」を記録する。

- DOIの照合ができても照明操作を受けた独立区画数や生態学的エンドポイントは証明されない。
- Crossrefのfile linkがあることはOA全文が読める証拠ではない。
- Europe PMC非収録は全文が非公開である証拠ではない。
- DOI取得・全文アクセス可能性と、効果量の平均・標準誤差・照明独立割付単位の**三つを別段階**で扱う。
- Source APIに一時的な403/500があっても「生態的影響なし」と再符号化しない。

原レビューの `method` 欄の欠測が大きく、分類群と年代も偏るため、17論文の全てを「独立したALAN×植物実験」としてメタ解析しない。最初に原著個別の明暗処理数／時間スケール／植物種／送粉or植食or種子エンドポイント／原データ・SE・SDへの到達状況を検証する必要がある。

## ここまでの科学的に支持できる解釈

すでに[79原著のギルド・時空間コーディング比較](ALAN_SEYMOURE79_STUDYCLUSTER_GUILD_SPATIOTEMPORAL_RESULTS_20261119.md)では、捕食者―被食者と植食で増強／減少の記録傾向が違う一方、2020年前後の収録年で差が変わることが確認できた。しかし、観測されたギルドの違いと、照明が植物に与える**正味の繁殖効果**は直接結合されていない。

これまでmainの肯定結果は、湿潤性の種群偏りと、別々の照明実験での水生起源昆虫・クモ増加、訪花者の昼夜ギルド交代、および照明なしの機能的花粉送達ネットワーク差。今後のメタ解析で、**相互作用経路の可用性**がALANへの植物繁殖応答の分散を説明できるかを、適格な一次照明実験に限って検証する。
