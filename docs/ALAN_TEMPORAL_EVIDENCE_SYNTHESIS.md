# 島と本土の夜間光応答を、地点差・経年変化・季節内の同期に分けて読む

−1.902は、蛾による訪花が旧GloBIで記録された植物種が撮影種に占める割合について、同年の夜間光との空間的な関連を島と本土で比べた係数である。単位は割合の百分率点／log(1＋VIIRS)。5観測年をプールした関連は、この期間に同じ種の個体数や送粉量が減った速度を表さない。花粉制限64種の結果は種間の副次的な比較として扱う。[固定モデルと年次解析](ALAN_GLOBI_FIVEYEAR_TEMPORAL_DYNAMICS_20261111.md)

## 種を固定した反復観察

## 捕食者の時間系列は別の母集団である

2013–2025年の島の動物写真と**前年**のPCNLを照合した既存解析は、植物写真の同年VIIRSモデルと区別する。50島の空間比較ではヤモリ／（ヤモリ＋スキンク）の写真割合の光係数が+3.049［+0.384, +5.714］だった。同じ454地点・30島・1,979地点年にそろえ、各地点の平均光とその年の平均からの偏差を分けたモデルでは、地点間の係数は+5.645［−4.762, +16.053］、地点内の係数は−4.692［−16.059, +6.676］、両者の直接差は−10.337［−27.928, +7.255］。同じ地点の明るさが増すにつれてヤモリが増え、蛾への攻撃が増えるという時間的経路を示す結果は得られていない。13年の蛾の応答もシャクガ科・ヤガ科対チョウ2科の写真割合に限られる。[空間・時系列モデル](https://github.com/zuizui0223/alan/blob/782b142/docs/ALAN_TRUE_MOTH_GECKO_SAME_GRID_13YEAR_TEMPORAL_FE_20261112.md)・[同じ標本の地点間／地点内の直接比較](https://github.com/zuizui0223/alan/blob/782b142/results/alan_13year_gecko_photo_effort_and_same_site_decomposition_20261112.json)

## フェノロジーのミスマッチが生じる条件

スイスの野生草花帯を照明区と暗区に割り当てた実験では、開花季節を調べた16種の75%で開花スケジュールが変わり、一部では開花開始やピークが10日以上早まり、別の種では花が見られなくなる時期が遅れた。夜に開く種で閉花が遅れるなど、一晩の開閉にも変化があった。昆虫側では、ヤガ科 *Mamestra brassicae* の幼虫を緑色光または白色光に曝した実験で、暗区より早く羽化する成虫が多かった。二つの研究は別の種・環境を扱うので、花とその有効送粉者が同じ方向にどれだけ動いたかは決められない。[花期・花の開閉を測った照明実験](https://doi.org/10.1016/j.biocon.2025.111650)・[羽化と休眠の照明実験](https://doi.org/10.1002/ece3.1090)

花期の前進だけなら、訪花時期も同じだけ前進した場合には重なりが保たれる。ミスマッチの検証に適した応答は、同じ植物種・有効な送粉者種・場所・年での**開花曲線と成虫活動曲線が重なる日数や割合**である。昼夜のずれを主張する場合には、同じ夜の花の開閉時刻・蜜の利用可能時刻と実訪花時刻も必要になる。開花ピーク差と花期長だけでは二つの曲線を復元できない。リモートセンシングは光の時間変化と、葉の展開・老化など地域の季節進行を追えるが、衛星の緑化日から各植物種の開花日や蛾の活動日を割り当てられない。独立研究では、植物と送粉者の時間的重複が大きいほど長期間にわたる相互作用の維持が予測された。元の78地域では四区分の開花ピークを比較できた地域が0であり、同じペアの活動曲線が得られていない。季節のずれは、今回の島−本土差を生む候補機構にとどまる。[衛星で評価された都市の植生季節](https://doi.org/10.1038/s44284-025-00258-2)・[時間的重複と相互作用の維持](https://doi.org/10.1086/738351)・[元の78地域の開花支持](../results/regional_repeated_phenology/regional_counts.json)
