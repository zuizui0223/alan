# 島または本土で夜間光と負の関連を示す植物

## 自殖率、花粉不足、夜間の機能

371種中、蛾の花粉運搬等を確認32種、GloPLで花粉制限に対応55種、昼のみ対終日開放の比較8種。遺伝的他殖率を集約したMoellerらの原表624行を入手し、原配布ファイルのMD5を検証、WCVP受容名と照合した。21種28レコードで mean.tm（研究によって複数集団の平均）が得られ、7種はPLとも重なる。島本土の同地点・同年の自殖率比較は未成立。1を超える他殖率点推定は原値を保持し、自殖率に換算しなかった。栽培条件・自家和合性・訪花者由来の自家花粉比率から野外の自殖率を補っていない。[自殖・他殖率の原資料](https://doi.org/10.5061/dryad.577q1)・[28件の実測推定と原著名](../results/species_interpretation/land_negative_mating_records.csv)

- Asclepias syriaca は島 −0.174、本土 +0.043。PL3件の中央値3.139。遺伝的他殖率の公表推定1.03はほぼ完全他殖と整合するが自殖率は算出しない。別研究の66%は移された花粉塊が同一株由来の割合で、自殖した種子の割合として使えない。夜だけより昼だけで成熟果実が多く、強い負方向を夜間依存に帰属できない。カニグモ操作も種子への影響を検出していない。[花粉塊による推定](https://www.nature.com/articles/hdy199315)・[昼夜・捕食者の既存検証](ALAN_NEGATIVE_TAIL_ECOLOGY.md)
- 両側負で機構を比較する候補に、S. latifolia（夜間遮断時の繁殖低下67%、5研究）、S. nutans（87%、1研究）がある。前者にはPL1件、後者には0件。どちらも各側の名目区間はゼロを含み、同年同地域の両側に種が撮影された例は0。夜間送粉が重要と分かる種と、負の関連に統計的裏付けがある種を区別する。[実験ごとの値](../results/night_exclusion/experiments.csv)

## 捕食者、送粉の代替、シフト

既存のヤモリ2種・節足動物3種の成虫蛾捕食表と元訪花表を種名で結合し、島に記録のある捕食・送粉二役種の確認済みリンクを加えると、負方向371種のうち56種に63通りの捕食者→成虫蛾→植物がある。これは候補となる種の組合せで、発生地点・年、攻撃数・時間が一致するとは限らない。3節足動物は同年・同陸塊0.05°原表に掲載された植物名を照合。ヤモリ2種は成虫と明記された蛾・ヤモリ・植物の地点年を同じ定義で再結合し、経路別の島・本土の地点年総数も元の集計と突合した。全植物の集計を個別の植物に転記していない。78地域の全4区分で野生の成虫蛾の攻撃率を比較可能な地域は0。[全種名経路](../results/species_interpretation/land_negative_predator_chains.csv)・[捕食率の分母と地点](../results/adult_moth_predation/README.md)

## どの種で何を判別できるか

エゾミソハギは、島の負方向・蛾の体表花粉・花粉追加実験が同じ種にそろう候補。島側で確認すべき量は、明暗別に夜だけ訪花を許した花の柱頭に届く同種他家花粉数と、同じ株で昼だけ・終日開放・人工他家受粉した花の種子生産である。三型花柱なので花型と適合する花粉の区別も要る。Silene latifolia は夜間訪花を遮ったときの種子生産低下とPLがともに既知で、照明との対応が不足している。Asclepias syriaca は大きな島側の負傾向と強いPLがありながら昼間の訪花でも結実する。この3種を並べると、夜の送粉不足という説明と、夜間依存を必要としない説明を同じ観点から検討できる。Heracleum maximum は捕食者による補償を問う別の候補であり、捕食者自身の単回訪花による柱頭花粉と、失われた蛾の訪花数の両方が必要になる。
