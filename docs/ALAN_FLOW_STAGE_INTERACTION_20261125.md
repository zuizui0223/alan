## Connectivity mechanism and limits
The original Burgazzi article explicitly considers downstream consequences of the spatial arrangement of stressors: control flume both tributaries untreated, SS separate light and ponding, CS both in same tributary and other untreated. Authors report progressively lower downstream drift export from control to SS to CS, while downstream benthos changes were not clear. This is combined-stressor placement, not a light-only manipulation of connectivity. The original workbook has flume ID and upstream branch in drift, downstream samples in benthos; source-summary CT_up averages CT sections across flume types and cannot reconstruct control/CS/SS total drift by flume. Do not derive downstream point estimates from pooled CT_up. Next direct test should aggregate upstream drift by each flume×week using both tributaries, compare SS vs CS within each of six headers and independently measure downstream benthos; retain raw timing and effort, no extrapolation to actual wetland configuration. Need genuine original workbook for this. The author analysis code GitHub GSBurg/Disconnected does not itself contain workbook. 
The novel contrast suggests hydrological conditions modify differences between drift and benthic count responses to light, consistent with context-dependent aquatic transport, not mediation to terrestrial pollination, not change in landscape patch connectivity, and not an independent confirmation.
