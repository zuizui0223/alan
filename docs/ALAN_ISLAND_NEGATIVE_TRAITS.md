# 島で夜間光との関連が負の283種に共通する特徴

元の78地域・5年の撮影種構成の島側の傾きで負283種、正261種に分けた。符号は各種の点推定で、選択後の有意差検定はしていない。表の分母は、その欄を評価できた種数。従来の主要結果 −1.902、花粉制限64種の副次結果 −0.01938 を維持する。

|指標|島負|島正|
|---|---:|---:|
|花粉制限の対数比が正|38/47|13/17|
|対数比の種間中央値|0.221|0.085|
|蛾の体表花粉・送粉機能などを確認|26/283|27/261|
|花粉制限の測定と蛾の運搬等の両方|14|3|
|夜間遮断で繁殖成績低下|3/6|3/6|
|植物記載の主花色が白|40/96|30/104|
|白＋筒状・高杯形・漏斗形|2/48|2/55|
|上記に深い花筒を加える|0/14|0/20|
|自家不和合（形質台帳）|58/196|46/164|
|自動自殖可能（混合・可変を別集計）|60/124|44/89|
|主に他殖|80/128|72/108|
|絶対自殖または主に自殖|18/128|17/108|
|遺伝的自殖率の種中央値をさらに種間で集約|0.190（15種）|0.148（9種）|

花粉制限資料の被覆率は47/283対17/261で偏る。花粉制限が正は点推定の符号であり各種で効果が有意だったという意味ではない。負群の花粉制限と夜間遮断による低下が重なる種は Silene latifolia のみ。花色の単独集計と複数形質の集計は測定可能な種集合が異なる。夜間の香り、開花時刻、蜜の分泌、蛾が担う種子生産の割合を全種で同じ定義にした資料は今回未照合で、形態から専門化を割り当てていない。[形質群と送粉者を同時調査した一次研究](https://pmc.ncbi.nlm.nih.gov/articles/PMC2701765/)

直接形質は再現済み原台帳の高・中品質、解決済み、単一状態を採用し、同じ植物名で照合。10形質について全状態を[度数表](../results/species_interpretation/island_sign_trait_counts.csv)に収録。自家和合性は元のGloPL関連表で使った出典と直接形質台帳で測定範囲が異なるため別行とした。遺伝的他殖率の記録自体は負17種・正9種、0～1内の点推定から自殖率を得られたのは15種・9種。原研究の地域と時代は固定地点年と一致するとは限らない。[種別繁殖証拠](../results/species_interpretation/island_sign_reproductive_evidence.csv)・[他殖率原資料](https://doi.org/10.5061/dryad.577q1)

地域内の誤差を考慮した推論には既存の[連続形質モデル](../results/mating_light_contrasts/README.md)と[夜間遮断モデル](../results/night_exclusion/README.md)を参照。調査努力・系統・形質欠測を調整した形質間の独立効果は、この符号別記述から判定できない。
