# 北米北東部の全835地点年を分母にした光・土地被覆・撮影季節の比較

対象の5°区画21_26（西経75～70°、北緯40～45°）には、元の5年で島83、本土752の適格な撮影地点年がある。トウワタ属 *Asclepias syriaca* は4／21地点年、アメリカオニアザミ *Cirsium vulgare* は6／7地点年で撮影された。両種の一方または両方が写った37地点年のみに限定すると、明るさ・環境が異なる他の798地点年での撮影機会を失う。そこで元の適格地点年をすべて分母に保持した。[元の全球モデル](ALAN_GLOBI_PRIMARY_RESULT_FREEZE_20261111.md)・[種別の地域寄与](../results/focal_species/ranked_contributions.csv)

## 同じ年の植生・市街地と観察季節

Esri / Impact Observatory / Microsoftの年別Sentinel-2土地被覆9分類のうち、2019、2021、2023、2024、2025年の各画像を年属性で特定した。公式のImageServerで101組の1°区画×年を取り出し、緯度経度0.001°の出力格子を0.05°地点ごとに50×50画素に分けた。緯度による面積差を重み付けし、雲と欠測を除いた面積に対する各クラスの割合を求めた。835地点年全てで有効面積は99.92%以上。10 mの元分類を縮小した衛星サービス出力であり、厳密な10 m全画素集計との差を独立に確かめた。両種の37陽性地点年における市街地率の絶対差は平均0.72・最大3.75百分率ポイント、水域率は平均0.52・最大3.66ポイントだった。道路脇や庭先の細い草地など撮影位置の詳細には、別の近傍集計を参照する。被覆は見える地表の分類で、草刈りや農地・公園の管理履歴を識別しない。[公式製品・CC BY 4.0](https://livingatlas.arcgis.com/landcover/)・[年属性と公的配信サービス](https://ic.imagery1.arcgis.com/arcgis/rest/services/Sentinel2_10m_LandCover/ImageServer)・[年別タイルの識別子・ハッシュ](../results/local_21_26/background_tile_receipts.csv)・[835地点年別面積割合](../results/local_21_26/background_landcover.csv)・[陽性地点の10 m集計](../results/local_21_26/landcover.csv)

各地点年に全植物が撮影された相異なる日を数え、年間の位相のsin・cosを各日で平均した。複数の写真がある1日に大きな重みを与えない。相異なる撮影日は1～22日、中央値3日。モデルは平均的な季節位置と観察日の分散をこの2変数で近似する。月ごとの観察時間、開花・未開花の全株調査、対象種だけの開花日とは異なる。焦点種も全植物の撮影集合に含む。[観察日データの定義](../results/phenology_support/README.md)

## 835地点年内で推定した傾き

応答は100×「その格子年にその種が撮影された」指標／「同じ格子年に撮影された全植物種数」。観察記録に含まれない種の指標は0で、現地個体の不在を意味しない。元の土地分類・自然対数変換・年固定効果・年内の陸塊側の重み・気候、標高、人口密度、撮影数、撮影種数の共変量を使い、この地域に限って得た記述的な傾きを示す。追加した土地被覆は市街地、水域、開けた地表（農地＋裸地＋rangeland）の3面積割合で、樹林等は省略した残余区分に入る。土地区分と季節の効果は両側に共通の加法項とした。全球モデルの係数からこの地域を切り出した寄与（−0.196、+0.140）とは異なる局地推定量である。[全係数](../results/local_21_26/background_local_slopes.csv)・[局地集計コード](../scripts/analysis/alan_21_26_background_slopes.py)

単位は構成比の百分率ポイント／log(1＋VIIRS)。トウワタの負の局地差は追加後に絶対値が13.5%小さくなり、アザミの正の差は63.1%大きくなった。2種の差の開きは1.833 → 1.937ポイント。ここでの13.5%・63.1%は同一標本での係数の変化量で、生育場所が説明した因果的割合ではない。アザミでは追加後に本土の傾きも正になり、正の島−本土差が両側での増加の大きさの差として残った。市街地率とVIIRSのSpearman相関は島0.743、本土0.911で、両者が大きく重なる。独立した5°地域は1個しかなく、全球設計の地域クラスタ区間は計算できない。島側の陽性も4・6地点年に限られ、個体群への照明の固有効果、送粉者の交代、または撮影対象からの選択を識別できない。
