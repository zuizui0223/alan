# ALAN：夜間優占ではなく「夜を失った際の機能低下」を比較する

2026-11-15。PR #77 を基点とする独立 Draft。main と以前の結果を変更しない。

## 1. 今回新しく計算したこと

昼だけ訪花を許す処理 D、夜だけの処理 N、終日開放 O を区別し、**夜間アクセスを除く相対低下 L_N = 1 − D/O** を新たに計算した。これは昼夜排除実験における繁殖指標の対比であり、ALAN 処理の効果・将来の光害損失率ではない。夜間の機能を蛾だけに帰属させる指標でもない。

比較した三つの量：

- **夜間を失う相対低下**：1 − D/O。
- **夜間だけで維持できる成績**：N/O。
- **昼夜の相対的な優劣**：N/(N+D)。訪花個体数の構成比ではなく、各排除処理下の繁殖成績の比較。

例示として D=90, N=90, O=100 なら、夜間だけで90%を維持する一方、夜間を除いた低下は10%。DとNの両方がOに近いことは、いずれか一方が不要という証明ではなく、その実験条件下で一方のみでも高い成績を保つことを意味する。この数値例は仮想であり観測データではない。

## 3. 分母を確認した主な結果

各論文内でL_Nの中央値を計算した後、その研究中央値を研究間で等重み集計した。区間は研究ID単位の4,000回パーセンタイル・ブートストラップ、seed=15。研究内推定誤差・系統共分散・出版バイアスは伝播していない。したがって逆分散メタ解析や、全球植物の無作為標本に対する損失率とは異なる。1研究しかない層には研究間区間を付けない。

| 分母が明示された指標 | 比較組 | 研究ID | L_Nの研究均等中央値 | 95%研究再標本化区間 |
|---|---:|---:|---:|---:|
| 結実割合・果実/花の比率 | 79 | 37 | **0.4000** | **0.0391–0.7059** |
| 1果実/蒴果/莢あたり種子数 | 105 | 44 | **0.2369** | **0.0380–0.3058** |

40%は結実率が40パーセントポイント下がることではなく、終日開放の成績に対する相対低下。種子/果実は、個体全体の総種子数や全花あたり種子数ではない。二つの行は異なる応答であり統合しない。区間は研究間再標本化だけなので、厳密な実験効果の全不確実性を表さない。

分母不明・形質不明を全部捨てて規模を狭めてはいない。元表の fruit set 197組の探索集計は中央値0.3263 [0.1713, 0.5055]、seed set 143組は0.2720 [0.0773, 0.3492]。ただし前者には割合/数/単位未記載、後者には果実/花/個体/胚珠あたりや形成確率が混じるため、**分母をそろえた主結果の代用品にはしない**。全比較はCSVで保持し、分母別の結果を別々に出力した。

## 4. 「昼の成績が高い」場合も夜間を失う損失があり得る

夜間処理が利用可能でD>=Nの比較に限った。相対低下20%という基準は探索的な記述用であり、有意差判定・事前登録した生物学的閾値ではない。

| 元表の応答分類 | D>=Nの比較 | それでもL_N>0.2 | 割合 |
|---|---:|---:|---:|
| fruit set | 92 | **25** | **27.2%** |
| seed set | 50 | **8** | **16.0%** |

同一論文内の比較数の影響を減らした、各論文の該当率の均等平均も保存した。割合を対象植物全体の頻度に外挿しない。明示的な結実割合だけでも8/34、種子/果実だけでも7/38がこの条件を満たす。

逆に、N/O>=0.8の比較でもL_N<=0.2となるものが、fruit set 33/92、seed set 34/95にある。**夜間だけで良い成績を得る能力と、夜間を失うことへの依存は異なる。** これは動的な補償行動や、ALAN下で代替送粉が生じた証拠ではない。

10/20/30%の全閾値診断を保存した。fruit setでD>=NかつL_Nが閾値を超える比較は35/25/17、seed setでは9/8/6。単一閾値で都合のよい結論を選ばない。

## 5. 開花時刻との対応：方向はあるが差は未確定

元表の広い fruit set 分類では、研究均等中央値は夜咲き群0.5522、昼咲き群0.1827。差0.3695の研究単位ブートストラップ区間は **−0.0707–0.5845**。seed setでは差0.2426、区間 **−0.0342–0.5372**。いずれも0をまたぐ。

同じ論文内に夜咲き・昼咲き双方があるのは結実側3論文、種子側2論文にとどまり、主に研究・種をまたぐ比較。**夜咲き群ほど必ず弱いという一般則や、開花時刻の因果効果は実証していない。** 欠測形質はunknownとして保持した。結実の15組、種子の9組は開花時間分類不明だが全体の機能比較から除いていない。

## 6. 完全排除区・既知の照明実験の感度分析

完全排除区Cのある比較では、O>Cの場合に限り `(O−D)/(O−C)` を計算した。結実108組/65研究では研究均等中央値0.4000、種子53組/36研究では0.3609。完全排除区の成績には自律自殖以外の過程や実験操作の影響もあり、C/Oを自殖率とは断定しない。CがOの80%以上の比較を除く感度解析も保存した。

既知の照明操作研究Macgregor_2019を除く結実196組/92研究の中央値は0.3214。全体0.3263の傾向は、この1論文を除いても変わらない。これは全論文の照明処理独立性の完全監査ではない。

Macgregorの原著図はモデル予測値と95%区間であり、前回見つけた他メタ解析集計表の不整合なSDは今回も修正していない。原3CSVを取得できたとはしていない。
