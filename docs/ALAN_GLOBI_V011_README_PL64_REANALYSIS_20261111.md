# README花粉制限×ALAN：GloBI v0.11更新後の同地点再検証（2026-11-11）

**結論：元のREADMEの探索的な負の花粉制限関連は真の元データから小数点以下まで再現した。しかし、GloBI v0.11の蛾訪花陽性記録に限った解析では再現せず、蛾特異的な光害機構としての頑丈な結果には至らない。**

対象は固定済みの2019・2021・2023・2024・2025年の**10,698**写真観測地点×年（島933、本土9,765）、独立した5度地域78、年×地域195。写真・WCVP・GloBI・年内4か月VIIRS・人口などの入力原本をSHAで確認し、同じ年・地域に島本土両側がある地点の均衡重み、気温・降水・標高・撮影枚数・観測種数・人口の調整、同一5度地域クラスタ推定を使用。

花粉制限PLは補助授粉／自然授粉の繁殖成績の公表された対数応答比の**植物種別中央値**であり、元写真の地点で測られたPLではない。各種が写真観測植物種の構成比に寄与する割合について、その種のPL値による「島−本土の夜間光勾配」の変化を推定する。PLとGloBI記録を現地での有効蛾送粉へ読み替えない。

## 数値結果（実際に元データを復元・推定）

元のREADMEの主効果も復元した：GloBI旧出典の撮影植物構成比に関する島−本土の夜間光傾き差は **−1.9017206221 pp/log(1+VIIRS)**、95%CI [−3.7058390,−0.0976022]。元READMEの64種の花粉制限傾き差は **−0.01938004576**、95%CI [−0.0382253,−0.0005348]、名目p=.043993。いずれも公表値に1e−9以内で一致した。

もとの64種のうちGloBI v0.11で蛾訪花の陽性関係が残るのは**30種**、陽性記録がないのは34種。後者は本当の蛾媒の生物学的欠如や昼行性専用送粉を意味しない。元64種のうちPLが計測・同定済みの植物が撮影された元の10,698地点年は、島125・本土778。v0.11陽性30種では島72・本土318、19の地理ブロックで両側に写真がある。記録の絞り込みで比較地理が狭くなることはCIの広さと外的妥当性に影響する。

**外れ値の影響：** PL log応答比の絶対値が2を超える植物は Asclepias syriaca、Lotus corniculatus、Nerium oleander、Silene latifolia、Vincetoxicum hirundinaria。これら5種を除くと元64種の正負の方向が反転し、p=.662。これは**事後的な影響診断**であり5種を分析から永久に除外すべきという主張ではない。元64種の1種ずつ除外では64/64で負だったが、完全版陽性30種の1種ずつ除外では方向が一定せず、30比較の名目CIはすべてゼロを含んだ。独立した64の検定ではない。

元のPL事後比較の名目p=.044は、元の花粉制限と交配様式という2仮説をHolm補正すると**p=.088**。したがって当初から補正後5%水準では確証されていない。

## 他の完了解析との整合性

- 同一2019–2025年・同一地点で蛾訪花陽性植物群をGloBI v0.11へ交換すると、元の島−本土の夜間光勾配差は−1.902から+0.750（CI −1.076〜+2.577）へ変わった。分類集合更新の影響が大きく、植物／蛾の実際の増減ではない。
- 独立GloPL原実験1,419件×1993–2015年の実測歴史的PCNL解析では、花粉制限そのものの光勾配は+0.0107 [−0.0468,+0.0683]、p=.715。さらにGloBIの蛾陽性記録×歴史的光の交互作用は−0.0344 [−0.1595,+0.0907]、p=.589。これらは**別の目的変数・別の標本**であり数値を足したりメタ解析してはいけないが、光による蛾特異的PL影響という中心主張がまだ確認されない点では一致する。
- GloBIが蛾との相互作用記録ありと分類した植物も、同じ島の同じ年に蛾による実効送粉があったことを保証しない。蛾の運搬証拠17種の係数CIもゼロを含み、完全版陽性との交差は8種だけ。

## 次の実証的優先順位

1. **全GloBIから漏れた種を「対照」にはしない。** 花粉制限の主解析は独立に確認した夜間送粉の繁殖利益、少なくとも成虫蛾の花粉輸送・柱頭付着・昼夜遮断実験の証拠がある植物に限定し、その支持島・地域と原本数を最初に確かめる。
2. どの植物種が外部花粉に依存するか（強いGloPL）と、どの送粉者が不足するか（昼・夜・自殖・コウモリ・ヤモリの代替）の2軸を区別する。PLは送粉者の種を識別しない。
3. 既存のPCNL・VIIRSは地表の照明実験ではない。古い年月日の写真欠測・植栽選好・研究対象種の偏りを補正してもなお残る同じ野生個体群の年次結果か、独立の野外実験が必要。
